0.1～0.4 版本怎么理解？

给第一次接触 NR→SR 的用户：数字越大不代表一定更快或更好，主要是处理链路在逐步改进。0.5 目前还没有发布。

默认使用 0.4.6-hotfix.1
0.1

先增强，再交给游戏超分

游戏以 1440p 渲染 → NR 增强 → 游戏自己的 DLSS SR → 4K。

NR 处理 1440p；放大到 4K 仍由游戏原生 DLSS SR 负责。第一次证明“先 AI 增强，再超分”可以跑。
0.2

把增强结果合回原图

NR 处理后，把变化合回原始画面，再交给游戏原生 SR。

仍以 1440p 做 NR，重点解决 HDR、颜色和合成问题。开始处理画面合成和 HDR 兼容。
0.3

让 NR→SR 更稳定

仍是“NR → 游戏原生 SR”，但迁移 NR 效果的过程更稳。

NR 处理 1440p；最终放大到 4K 由游戏原生 SR 负责。NR→SR 开始真正工程化、稳定化。
Beta0.4

NR 可以单独用更低分辨率

游戏保留 1440p → 额外缩一份 1080p 给 NR → AI 修改贴回 1440p → 游戏原生 SR → 4K。

NR 实际处理 1080p，和游戏自己的渲染分辨率解耦。核心飞跃：降低 NR 成本，同时保留游戏原生超分。

简单选择建议：历史游戏仍可选择保留的旧版本；新版选择 0.4.6-hotfix.1。它支持已有原生或模组 DLSS 的 DX11-x64 游戏，也保留 D3D12 SR/RR 路线；不支持无 DLSS 游戏、Feeder、Vulkan、DX9/DX10/OpenGL 或 x86 Legacy。
