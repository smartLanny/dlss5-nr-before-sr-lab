# CP2077 × 帧生成 × NR — 验收矩阵（#126）

固定包：**beta0.4.5**（或主人指定更新包）中文 OTA；addon + `nrchain_nvngx.dll` 同包；保留游戏 INI/ReShade/NVIDIA 运行库。  
游戏：**赛博朋克 2077**；记录精确游戏版本、HDR/SDR、DLSS 档、是否 RR、GPU/驱动。

云端/复测读日志时：启动瞬间 `native-hooks-unavailable` / `installing` **不是终态**。

## 四组对照（对齐 #16）

| ID | 配置 | 要记 |
|---|---|---|
| A | 仅本插件（NR 关 / F6 off） | 能否进主菜单、读档、稳定跑 5 min |
| B | 仅本插件 NR 开（前置 Mode2，默认设置） | NR 是否 active；有无闪退 |
| C | 仅 FG（游戏内 3× 或官方路径），NR 关 | 进游戏/Present 是否正常 |
| D | NR 开 + FG | 进游戏、NR 状态、闪退点、帧节奏 |

每组再拆两条 **FG 来源**（能测几条测几条，表里写清）：

1. **仅游戏内/官方 FG**（无第三方解锁）  
2. **+ 第三方多帧/解锁插件**（客人常用那款，记名称+版本）

## 通过标准（建议）
- A/C：无本插件相关闪退，可进游戏。  
- B：无 FG 时 NR 可 `none/active` 或可解释旁路（非闪退）。  
- D：若闪退，定位是「NR+官方 FG」还是「NR+第三方解锁」；**不要**把两种 FG 混成一条结论。  
- 本单 **needs-evidence** 直到至少有一组 D 的双日志或崩溃包。
