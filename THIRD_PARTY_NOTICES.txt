DLSS5-Feeder and NIGos dlss5-bridge
----------------------------------

The compatibility adapters are reproducible transformations of source-pinned
MIT projects. Their upstream repositories, commits, patch hashes and license
retention requirements are recorded under `compatibility/legacy-feeder`,
`compatibility/vulkan-feeder` and `compatibility/nigos-bridge`. No compiled
Feeder, host, ReShade or bridge binary is stored in this source repository.

AMD FidelityFX SDK
------------------

The optional AMD optical-flow build consumes the separately obtained official
FidelityFX SDK 1.1.4 headers and static libraries. SDK headers, libraries and
binaries are not vendored here and remain governed by AMD's FidelityFX SDK
license. Component packaging retains the official license beside the compiled
Feeder. The NVIDIA Optical Flow SDK is likewise an external build input; no
NVOF SDK header, library or binary is included in this repository.

NVIDIA and games
----------------

The source repository contains no NVIDIA SDK library/header, neural-network
payload, game file, or game asset. Production nrchain_nvngx.dll binaries link
the official NVIDIA NGX SDK loader in object-code form to initialize NGX in
applications that have not initialized it themselves. The SDK is separately
obtained by the builder from https://github.com/NVIDIA/DLSS (pinned build inputs
are recorded in scripts/build-nrchain.ps1). NVIDIA SDK portions remain governed
by the NVIDIA RTX SDKs license at https://github.com/NVIDIA/DLSS/blob/a291cc7d2cc642a51566f3dfd5376f635cd1b284/LICENSE.txt;
they are not relicensed under this project's license. The signed NR runtime is
supplied separately. Product names describe interoperability and do not imply
affiliation or endorsement.
