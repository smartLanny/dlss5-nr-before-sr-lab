DLSS 5 AI 超分管理器 0.4.8-beta.6 · 本地整合测试版

接续已交付的 beta.5，整合 PR #244 的画面控件整理与兼容反馈。
完整 ZIP 请全部解压后运行；便携 EXE 可单独运行。升级前正常退出旧管理器。

画面设置
普通游戏和米哈游客户端继续使用同一套卡片、展开设置和顶部操作栏。
常用画面风格、AI 效果强度和人脸调节放在前面；其余参数在“细节、性能与更多设置”。
“图形接口”和“增强版本”分别对应原有 API 与 Core 选择。
参数修改仍先预览，再确认应用；页面中的设置变化不会立即改写游戏文件。

反馈本次体验
在普通游戏、米哈游客户端或维护页打开游戏设置，点击“反馈本次体验”。
只需回答能否游玩、画面表现和流畅度；不确定可以保留“不确定”。
画面异常时可补充标签和说明。诊断日志默认不附带，勾选后可先预览内容。
预览完成后保存本地 ZIP，再自行交给测试群管理员。管理器不会自动上传。
没有匹配的启动前快照时，报告明确记录当前配置，不能据此证明上次游玩的确切配套。
预览后切换游戏、组件、设置或启动会话，需要重新生成反馈。

运行证据
文件已安装、Core 已加载、NR 已处理、最终画面显示和主观体验分别记录。
显卡清单包含读取到的原始驱动版本；未确定实际渲染显卡时保留未知。
反馈采集只短暂等待；超时后继续原游戏启动，不采用迟到的启动前快照。
米哈游跨进程启动没有匹配快照时仍可手动反馈；不会填入虚假的运行成功。

安装与恢复
本版沿用 beta.5 的安装、恢复和启动路径。新安装默认 Core 0.4.7beta。
新 ReShade 配置默认 Home；已有自定义面板键（包括 =）保留。
米哈游先准备加载助手，再打开已绑定的官方启动器；在启动器中开始游戏。
取消等待不会关闭游戏。修改或恢复组件前请先退出对应游戏。
个人预设与配置按现有事务保护，不能用未知备份代替原始文件。

已知边界
本地整合测试和反馈收包验证不等于真实游戏的画面对照或稳定性验收。
自动上传、游戏退出提醒和实际渲染 GPU 绑定尚未接入。
Batman: Arkham Asylum GOTY 的既有 DX9 R3 卡住问题仍保留为未解决事项。
详细代码来源、修正与验证结果见本轮本地整合记录。
