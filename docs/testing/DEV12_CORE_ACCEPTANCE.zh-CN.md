# dev12 多游戏兼容验收

本版接续 dev11，保留三块风格选择、全屏 F7、新装默认 NR→SR 和已有个人设置。
菜单快捷键为 `=`，F6 开关 NR，F7 采当前全屏原图，F8 生成单个 TXT。

- 街霸 6：原生命令列表创建时登记；仍要求真实 Reset、完整状态和队列证明。
  包装对象与原生对象分别处理销毁，避免读档或切换场景后丢失／残留记录。
- 异环 RR：把本次相机投影声明的标准线性深度转换为 NR 使用的私有深度。
  不支持的投影或资源仍保留游戏原生 RR，并显示原因；RR 输入保持不变。
- 通用兼容：前置颜色输入不兼容时尝试 SR→NR，仍需后置输入与命令状态验证。
  用户保存的处理顺序保持不变。菜单和 F8 区分回退尝试与最近处理记录。

请退出对应游戏后安装本 Core。保留运行库、模型及 INI；仅替换同语言 Core。
遇到异常可退出游戏，恢复安装前备份的 Core。

建议集中测试：

1. 异环开启 RR，确认 NR 状态及 F6 画面变化；关闭／重新开启 RR、读档后再检查。
   无论成功或失败，保留一份 F8。人脸调节的既有缺陷继续暂停排查。
2. 街霸 6 进入实际对战、返回菜单再进对战，检查 F6 与 F8；登记恢复不等于 NR 已执行。
3. 2077 保持 RR 开关、人脸调节及读档回归，确认原来正常的效果没有退步。
4. 其他游戏若出现“兼容处理”提示，反馈游戏名、F6 是否改变画面及 F8。

Present 上的通用 NR 处理尚未接入；本版只在已观察到的 SR/RR Evaluate 边界工作。
本地源码、编译、WARP 与真实游戏结果分别记录；本说明不代表上述游戏已验证修复。
