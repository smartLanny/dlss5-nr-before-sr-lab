# D9 完整模型输入采集测试包

本包属于独立 0.5 D 线的第一批实验基准，版本 beta0.5-dline9 / PE 0.5.1.9。
新增完整输入序列采集；尚未加入新的人脸识别、脸区保护或反射分区算法。
不要把本包当作人脸问题已修复或整帧开销已达标的版本。

## 安装与回退

1. 退出游戏，备份当前 D8 Core 插件和 `nr_before_sr.ini`。
2. 将旧 Core 移到游戏目录之外，再放入本包对应语言的一个 `.addon64`。
   同时只保留一个 D 线 Core。沿用当前 ReShade 和已有 `nrchain_nvngx.dll`；
   本包未要求重置个人画面设置，也不需要替换 NVIDIA 的 NR 模型文件。
3. 回退时退出游戏，移走 D9，再放回已备份的 D8 Core。

## 采集

1. 开启原生 DLSS 和 NR，进入实际游戏场景。
2. 异环选择可清楚看到动漫脸的固定画面；2077选择之前人脸控制有效的固定画面。
3. 打开插件的“反馈与诊断”，点击“采集完整输入序列”。
4. 等待“序列已导出；重放前需校验”。采集会从新模型历史开始，记录连续16次处理。
   不要在这段时间切换场景、分辨率或画面设置。需要中止时点击“停止重放采集”。
5. 文件位于 Windows 文档目录下的 `DLSS5-Replay/sequence-...`。
   每次使用新的序列目录，包含16个 `.nrf` 文件和 `runtime.json`。
   不完整、超时或资源异常的采集不能当作成功重放基准。

诊断记录同次完整原输入、代理、模型输出、深度、运动、可用曝光及合成结果，
包括活动范围、参数和历史身份。单序列上限8 GiB；采集会额外占用GPU/CPU资源，
可能短时影响帧率，不能用采集期间的耗时判断日常性能。不会自动上传数据。

## 当前验证边界

完整本地构建与53项验证通过，包含实际 WARP 采集、独立文件读取以及既有合成回归。
真实 NVIDIA 模型已在独立进程完成裁剪输入实验；游戏中的完整序列尚待采集和重放校验。
只有同运行时、同完整输入的模型输出对照通过后，才可将后续参数实验称为忠实重放。
本包没有完成异环或2077人脸修复，也没有完成“相同NR设置下整帧GPU中位数/P95增幅≤5%”验收。
