# 0.4.7beta：DLSS5 Core测试包

本版由维护者已在鬼武者配合官方REFramework过测的beta0.5-dev16改名而来，
统一使用0.4.7beta名称。画质算法、处理模式、默认值与兼容修正保持一致。
本轮重新核对源码、编译和文件版本；改名前的游戏通过保留原记录，
新名称不代表增加了游戏或性能验收范围。

处理方式为左右两个选择块：NR→SR、SR→NR，当前选择高亮。开启RR时自动使用
后置，保留玩家保存的选择。风格仍为默认、自然、电影三个选择块。

新配置和一键恢复默认：前后置NR比例100%、模型强度1.2、光照保护0、
额外增强1.0、色彩保护开启。已有个人设置继续生效；需要套用上述默认时，
可点击菜单中的“一键恢复默认画质”。F6切换开关，F8保存当前报告。

这是独立D3D12 Core测试包，保留游戏原有的兼容组件，不包含NVIDIA模型、
运行库或替换INI。鬼武者使用已验证的官方REFramework组合；更新时同时
核对根目录与框架有效缓存中的Core，保留个人设置和可还原备份。

只保留一份活动Core。历史版本测试包及其哈希保持原样，新包有独立的来源和哈希。
