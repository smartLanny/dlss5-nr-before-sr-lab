# beta0.5-dline6 分层输入与人脸对照测试

本版接续 D5。维护者已确认异环的“完整亮暗”有效，但细节分层的反射调节不明显；
人脸调节在异环中随设置组合表现不稳定，在《2077》和《黎明行者之血》中似乎
持续有效。这些是维护者的游戏反馈，不扩展为所有角色、场景或参数通过。

这版提供查明原因的工具，没有更换反射算法，也尚未修复人脸识别。D5 的完整
亮暗、D4 细节分层及原有兼容路线保持；不会自动改变个人配置。

## 人脸对照

1. 保留出现问题时的设置，把人物脸部放到画面中央，尽量固定镜头。
2. 用“图像补充”里的“模型前后对照：画面中心”保存一组对照，另按 F8 保存报告。
3. 点击“模型细节”中的“恢复模型基准”。它只恢复模型强度1.2、局部明暗1、
   整体细节1、默认风格、界面保护，并开启人脸调节、皮肤强度设为0。
   光影参数、完整/分层模式、前后置路线、颜色、工作比例及光照保护均保留。
4. 等模型重新运行、画面稳定后，在相同镜头再保存中心对照和 F8。
5. “撤销模型基准”可恢复刚才的七项模型设置；之后再改其他配置会使这次撤销失效。

中心对照复用既有采集：三帧中心区域及一份概览，包含同次合成的原图、模型
输入、模型输出和合成结果等分析数据。它不是自动人脸遮罩，画面中心也不是
自动识别选区。不同组按先后顺序取得；请保留镜头、曝光变化的实际情况。
F7快捷键和原有“全屏原图”“七组画面对比”保持原行为。

这能区分“模型已经改变脸部”和“最后合成放大了变化”，并判断仅恢复模型参数
是否足够。皮肤结构0只请求独立结构调节，不代表整张脸的明暗、颜色和风格都
回到原图；没有拿到可信遮罩前，不把这两件事混为一谈。

## 检查可用分层输入

F8新增检查当前NGX调用可见的UI、UIAlpha、控制遮罩，以及已核对名称的RR
材质/反射导引资源。只记录接口返回状态和可验证的元信息，不采样这些新资源、
不向模型传入新遮罩、不增加模型推理。

“本次入口未提供”和“当前类型无法检查”分别记录。当前入口没有发现资源，不
能推断整个引擎或Streamline其他阶段没有它。存在资源句柄也不代表它已经成为
可用的反射、人脸或UI选区；还需核对内容、坐标、当前帧与生命周期。

按当前游戏设置保存一次F8即可。若本来就在测试RR，RR开启和关闭各一份有助于
区分两种入口；本版不要求为了采集改变图像路线或打开RR。

## 验证与回退

成功构建、CPU/WARP、实际菜单和游戏效果分别记载，以同包来源记录为准。
这版的人脸改善、可选资源实际命中、中心采集和性能均需要实际游戏结果。
包只包含一种语言的Core、自有桥接及说明/许可证；不含个人INI、NVIDIA模型、
ReShade或Manager更新。退出游戏后更换Core；出现问题可恢复备份D5并保留报告。
