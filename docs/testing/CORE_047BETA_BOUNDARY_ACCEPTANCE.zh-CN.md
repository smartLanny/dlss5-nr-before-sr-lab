# 0.4.7beta-output.2 输出边界诊断

上一份 F8 已确认采样帧的实际 Output 收到了 NR 修改，但普通走动时仍无明显
效果并偶尔闪烁。本版补充原生 SR 调用期间及 NR 之后的只读事件观察，记录
纹理状态声明、复制方向和渲染目标绑定。它仍是诊断版，未宣称修复画面。

按现有设置在正常场景启用 SR→NR，运行约10秒后保存一份 F8，提供 TXT 路径。
无需重复七组 F7，也不要求改画面参数。事件记录可能没有覆盖到内部原生调用；
零命中会明确保留为未观测，不能当作纹理状态正确。

模型、合成公式、引导、默认值、队列等待及依赖不变。Core 包保留原有配置，
备份上一版；没有新模型、安装器或 DX11/Vulkan 配套。
