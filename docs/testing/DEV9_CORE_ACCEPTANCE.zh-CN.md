# 0.5-dev9 本机测试说明

本版简化中文菜单和悬浮说明，修正 RR 自动后置时 AI 色彩状态一直等待的问题。
它尚未修好异环的 RR 深度适配，也没有证明人脸控制已恢复独立效果。

- “NR 工作比例”改为“NR 渲染比例”：控制 AI 渲染的分辨率，越高通常细节越完整、显卡开销越大。
- “NR 色调跟随”改为“AI 色彩强度”：0 保留游戏原色，调高采用更多 AI 颜色；不负责增加细节。
- 算法实验、分层强化、皮肤识别实验和实验 HDR 调色收进开发者选项；已保存的设置保留。
- 高光映射留在色彩与 HDR；高强度颜色与亮度保护仍默认开启。
- 调整颜色不再自动开启实验 HDR 调色。RR 的处理方式和 NR 是否实际参与画面分开显示。

请先退出游戏，再用本包 Core 替换原 Core，并保留备份。一个游戏只放一个 Core。
沿用现有配置、ReShade、NVIDIA 运行库和配套 nrchain；本包不含 NVIDIA 模型、
运行库或 DX11 carrier，也不是 Manager OTA。不要把这个包用于 BL3 的 SR-only 测试。

## 本轮只需两项

1. 2077：查看菜单是否清楚；固定场景用 F6 关/开一次，确认此前正常的效果没有回退。
2. 异环：进入场景、开启 RR，等两秒按 F8。新报告会保留深度类型和投影数据，供下一步适配。

异环这一步预期仍显示“NR 未生效”，不是要求用旧版反复证明已有问题。
人脸控制在 RR 关闭时也无效已记录，暂不要求重复拉动同一滑块。
在同一台机器测试时，只需提供报告路径或告诉助手已经生成报告。

新代码通过双语完整编译、CPU 回归和 WARP 合成检查；尚无本版游戏画面或性能验收。
本机交付目录另有回退脚本，会保存测试期间配置后恢复测试前 Core 和配置。
