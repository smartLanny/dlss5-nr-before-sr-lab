# D15 集中游戏验收表

本表只安排一次集中回测。先完成本机《赛博朋克 2077》《异环》《绝区零》和受控无 DLSS 基线的快验，再用其中一个可重复场景完成公平画质与性能对照。只有快验出现对应症状，或原问题环境已经可用时，才执行后面的专项复验；不用为了每个问题编号重新跑完整矩阵。

安装、恢复及语言选择沿用包内安装说明。本表不要求重新安装游戏，也不要求把日志发送到外部服务。用户填写操作与观感；源码、帧身份、提交和资源字段由工程结合这一批材料填写。
