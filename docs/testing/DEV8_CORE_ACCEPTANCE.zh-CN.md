# beta0.5-dev8：独立 Core 验收包

这是接续 #172 的 0.5 设置/回退收口候选，不是稳定版，不替换 Manager 默认 Core。
本包只交付本项目 Core 与 nrchain，**仅供已有 D3D12 DLSS 路线的手动对照**。
没有 carrier、ReShade、NVIDIA 运行库/模型、INI 或游戏文件；不是 Manager OTA，
不要将它导入需要完整 multi-API 载荷的升级入口。DX11 新 carrier 另由 A 线验证。

## 变化

保留单次 NR，默认效果倍率 1.0。无配置的新装 NR 工作比例为 100%；已有合法
配置保持原值。越界、非有限或格式不完整的工作比例不再静默钳制，保留上次合法值。
NR 比例不是游戏实际渲染比例，不会因此自动改变游戏 R。

0.5 的 Lanczos-2 输入、Catmull 亮度恢复和颜色 EditField 均保留为独立实验，
默认关闭；恢复推荐会清除这些实验请求及分层隐藏增益。
“恢复推荐”保留已有主动推荐的 Quality / 75% 语义，不等同新装 100%。
输入滤波真正改变时重建对应历史；推荐/普通设置继续走既有保存与 generation 流程。

## 安装与回退

完全退出游戏，备份现用 Core、nrchain 和 INI。中文版和英文版二选一；
不要让两个版本或旧 Core 同时加载。只替换本包两个二进制，保留用户 INI 与
现有 NVIDIA 运行库。不要为 D3D12 安装 DX11 carrier，也不要覆盖其他 MOD。

回退时完全退出游戏，移出本包 Core/nrchain，恢复备份；如测试中保存了配置，
同时恢复备份 INI。不要用反复热卸载 DLL 清除隔离状态。

## 维护者集中验收

固定同一场景、R/N/O、模型、风格和强度。先保持三个新算法关闭，以 F6 对比
本项目 NR 与原生参考；再逐次仅开启一个实验，最后测试需要的组合。
检查实验开关保存/重启、恢复推荐、输入滤波切换后的历史、读档/切窗/尺寸改变。
不要将算法开关的保存成功当成实际执行，核对 F8 请求与实际状态。

分别保留 SDR/HDR 的人脸、薄边、亮部和移动镜头对照。F8 单 TXT 为默认反馈，
视觉问题再补 F7；**出现安全旁路、崩溃或无效果，必须保留并提交 BUG 反馈**，
不要为继续运行而绕过保护。不要重复提交已经归档的旧版 RR 测试。

性能与图像/详细日志采集分开；对固定参考和候选分别预热，记录源帧 GPU 中位、
P95/P99 与显存。同设备/驱动、同 R/N/O 下，中位和 P95 的增幅都必须不超过 5%。
不使用插帧后的 FPS 抵消 NR 成本。

## 已验证与未验证

已完成本批 Windows 配置/推荐/接线检查、生成源码双语完整链接、11 个生产
SM5 着色器入口与 13 组组合 WARP 合同。WARP 使用构造的神经平面，不执行模型。
八组 all-off 参考来自冻结的 #172 源 shader；测试的历史打印名仍含 dev6-off，
不能据打印名推断本批使用了 dev6 二进制。

**本批没有 NVIDIA Feature18、真实游戏画质/性能或 5% 门槛通过结论。**
没有新增多次 NR、人脸分割、FG/MFG 后端或游戏兼容性声明。未宣称 Hosted CI 通过。
构建身份、两项内层二进制 SHA256 和来源见 build-info.json；文件逐项见 SHA256.json。
维护者明确验收前不合入 main，不覆盖历史 tag。
