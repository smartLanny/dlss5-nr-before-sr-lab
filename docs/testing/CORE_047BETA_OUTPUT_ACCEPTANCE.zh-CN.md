# 0.4.7beta-output.1 后置输出校验候选

queue.3 的本轮反馈是前置看起来恢复，后置仍弱或无变化并偶有闪烁。
本候选增加实际输出纹理的稀疏读取，把模型/合成值与真正写入的结果分开记录。
它是诊断候选，尚未修复或确认后置画面问题；模型、合成公式、设置默认值和
queue.3 的完成等待机制不变。

在相同场景启用 SR→NR，停留几秒后生成一次 F8，提供 TXT 路径即可。
目前已有完整七组图，无需重复 F7。F8 的 outputProbe 是写入后、游戏继续使用
之前的采样证据；最终呈现仍需结合画面判断。

Core 包不包括个人设置、模型、厂商运行库、DX11/Vulkan 配套或安装器。
更新时保留现有设置与依赖，备份旧 Core。没有自动安装或发布权限变更。
