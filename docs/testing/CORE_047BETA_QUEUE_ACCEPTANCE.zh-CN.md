# 0.4.7beta-queue.2 共用队列与状态候选

本候选接续一次性命令列表的队列准入修正，并修正状态面板按帧交替显示
“运行／跳过”的问题。按共用机制实现，不检查游戏名称，不更改安装器载荷。

- 面板整段使用约一秒的近期活动。NR 与输出提交都增长且发生队列等待时，
  显示“间歇处理”，不声称每一帧都执行了 NR。
- 修改设置、切换处理生命周期或长时间关闭面板后，清除旧活动。
  持续没有新提交时，显示等待或该观察窗口的失败原因。
- 每次评估的瞬时原因及计数仍保留在诊断和 F8；安全准入条件没有放宽。

维护者对前版的实际反馈是状态面板闪烁，游戏画面不闪烁，且 F6 前后仍看不出
变化。前版同一配置窗口有 36 次新的 NR 和输出提交，但这些计数不证明最终显示
或画质改善；该画面问题仍未解决。面板修正不能替代画面验证。

通过源码、编译和完整规定验收后才生成 Core 专用测试包。它不包含个人 INI、
厂商模型、DX11/Vulkan 桥接器或 Manager。游戏内与 NVIDIA 模型结果需单独记录。

测试时先检查面板是否稳定显示实际状态，再固定镜头用 F6 对比。若仍无变化，
在“反馈与诊断”的图像补充中使用“七组画面对比”，比较关闭 NR、前置与后置
的最终全屏原图；采集完成或取消后恢复原设置。F8 仍用于对应的运行计数。
