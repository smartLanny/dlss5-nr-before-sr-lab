# D8：常用增强、一次配置迁移与兼容反馈

“额外增强”移到“模型强度”下方，范围为1–4倍。1保留基础效果，超过1放大
模型产生的变化；需要减弱模型处理时调整“模型强度”。人脸细节仍保留原有
0–2模型参数含义，0不等于整张脸回到游戏原图。

## 更新后的设置

- 旧额外增强在0与1之间的设置一次调整为1，不自动换算模型强度。
- 旧额外增强为0时，改为1并关闭总开关，以保留停用意图；需要启用时按F6。
- NR Jitter传递默认关闭，旧设置也关闭一次。此后你可以手动开启，后续启动
  不会再次强制关闭；游戏原生DLSS使用的Jitter保持不变。
- 菜单会显示旧设置迁移结果。保存失败时说明设置仅在本次运行有效，并提示
  检查目录写入权限；配置文件中的其他画质数值继续保留。

## 人脸问题与本版边界

维护者确认异环调整整体细节强度后，人脸调节会失效。两次D7诊断共18组均
完整，实际模型参数已应用，额外增强始终为1。基准设置下人脸开关响应明显，
提高局部明暗或整体细节后响应减弱，差异已出现在模型输出中。本版不通过
自动降低整体细节或重置画质来冒充修复。

额外增强的人脸隔离需要可复用的空间脸区。当前只有模型内部人脸控制请求，
尚无验证通过的模型遮罩输出；诊断框和第五采集平面都不是人脸遮罩。
本版保留已有AutoMask/Skin，不把离线识别候选自动接入游戏，不增加第二次NR。
因此本版尚不能保证“额外增强只放大脸外区域”。离线研究和运行时能力分别记录。

## 自动后置兼容

前置画面格式、颜色或可读条件未满足要求时，现有安全回退会尝试SR→NR，
并独立检查后置条件。菜单显示实际后置路线、前置拒绝原因及F8反馈提示，
原先选择的前置偏好保留。没有确认近期处理时，明确显示仍在尝试。

未知队列、命令状态、运行时隔离等共用故障不会因为切换路线而被绕过。
本版没有把所有安全旁路改成强制后置，也没有合并ABC正在开发的新修复。

## 建议验证

1. 查看额外增强位置、1–4范围以及首次迁移提示；确认模型和人脸独立数值保留。
2. 若手动重新开启NR Jitter，保存并重启后检查选择是否仍然保留。
3. 继续使用“反馈与诊断”中的人脸自动对照。固定路线后观察整体细节1与2的
   对照，不把两次不同路线、分辨率或动画时刻的截图当作同帧证据。
4. 若出现自动后置或仍然无效果，按F8收集反馈并记录画面现象。

异常时退出游戏，使用本次备份中的D7回退脚本。回退保留当时的个人配置；
迁移后的Jitter默认值不会因回退二进制而自动恢复为旧值。
