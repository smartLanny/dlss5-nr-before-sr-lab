passes; every auxiliary raster follows the second-pass ratio. Only its first
input is reduced. Later layers read the preceding complete answer at that same
raster. The final low-resolution residual subtracts the pinned first reduced
input from the final answer in the decoded domain, retaining all accumulated
edits. Each feature, parameters, output and history remain independent.

Three/four-pass preferences survive. A versioned save preserves a disabled
second switch without re-enabling it during subsequent reload. Author and links
remain visible outside the settings tabs.
