# 0.4.7beta-ds1.1：死亡搁浅1独立修复候选

该候选针对死亡搁浅1每帧创建并丢弃命令列表，无法建立两次提交历史而持续跳过NR的问题。
新列表只有在前一轮NR上下文和所用资源已由精确完成信号证明结束后才可准入；
实际提交时再次验证，并在实际队列上记录新的完成信号。

仍在执行的未知队列工作保持原生画面。已有稳定队列的正常重叠路径保留，
队列迁移、重复提交、未提交即销毁和失去生命周期证明仍按原规则拒绝或隔离。

该包独立于安装器任务正在交付的0.4.7beta，不替换其固定组件。
更新时只替换一份活动Core，保留原有依赖与所有玩家设置，并保存可还原备份。

进入死亡搁浅1相同场景，分别选择前置和后置，按F6对比，再按F8保存当前报告。
除观察画面外，报告应核对queue.retiredAdmitted、NR成功与实际合成提交计数。
本候选的本地验证不替代实际游戏验收。
