# dev16：处理模式选择块与默认画质

处理方式改为左右两个可选块：左侧NR→SR，右侧SR→NR。当前选择高亮，
点击即提交；开启RR时显示并固定后置，但保留原先保存的选择。
采用dev14已修正的ImGui布局接口，三种风格继续保留原来的三个选择块。

新装与一键恢复默认画质：NR渲染比例100%、模型强度1.2、光照保护0、
额外增强1.0，开发者色彩保护保持开启。已保存的个人设置继续生效。
单独调整光照保护仍在原菜单位置，不移除该选项。

本包是独立D3D12 Core验收包，不是Manager OTA，不包含NVIDIA模型/运行库。
游戏需保留原有兼容组件；已验证的鬼武者组合还需REFramework。更新时同时
核对框架使用的Core副本和实际配置位置，保留个人设置与可还原备份。

复测重点：按=开菜单，左右切换前后置、用F6对比，确认保存后重进仍保持；
开启RR时确认自动后置与此前的选择保存不冲突。恢复默认应显示光照保护0、
模型强度1.2和NR100%。遇到异常用F8保存当前报告即可。
