# 0.5 D11：双次 NR 与通用亮暗对照实验

本候选在 D10 基础上加入两个默认关闭的实验，供维护者在游戏中自行对比。
不合并 main/stable，不宣称画质更好，也没有通过游戏整帧 5% 性能资格。

## 菜单

- **双次 NR 叠加（实验）**：启用第二次 NR，手动选择 25%–100%；提供
  100%、75%、精确 2/3、50% 按钮。比例是第二层相对第一层的每边尺寸，
  不是像素总数。第二层使用独立 Feature、参数和历史。
- **通用亮暗／HSL 残差实验**：总倍率、反射／辉光（通用增亮）、阴影／结构
  （通用压暗）、饱和度、明度。开启时独占现有分区参数；关闭即可回到引擎导引分区。
  这两个方向控制整体 RGB 改动，不是独立识别反射或辉光的语义遮罩。
- 推荐设置恢复为单次 NR，关闭通用实验，并恢复五项倍率为 1。

通用实验参考 Magpie 的公开控制算法，自行实现 RGB/HSL 数学，未复制 GPL
实现代码。相同的是总残差、线性亮度变化符号分类、整像素方向倍率和相对原图的
HSL S/L 改变量。此处应用于 D 的归一化模型存储域，再经过原有最终画质和颜色保护，
因此不承诺与 Magpie 的 SDR 输出逐像素一致。非有限值和超出归一化范围的样本保留
给已有保护处理。

[Magpie 参考版本](https://github.com/SAOG0721/Magpie/blob/ac1cc8b0f2efc78323898395cc1336bcbecdc276/src/Magpie.Core/DLSSNRFilter.cpp#L335)

## 双次 NR 路径

100%：第一层结果 P1 直接作为第二层输入，最终消费者读取 P2。
较低比例：完整 P1 面积缩小为 L1，独立第二次 NR 输出 L2；在相同颜色域内计算
`decode(L2) - decode(L1)`，以 FP32 保存小图上的有符号残差，融合到既有最终读取。
保留第一层大图纹理；第二层没有改动时返回 P1，避免重复叠加第一层效果。
不增加全尺寸残差图、不重复原生 SR、不复用旧帧残差、不按负载自动调档。

辅助纹理按槽限制 256 MiB、全池 1024 MiB，包含尚未安全退休的辅助代际；
模型内部显存不在该数值内。已有其他辅助资源继续使用自己的预算。
创建仅录制 Create，必须观察到对应队列的非零完成 fence 后才能 Evaluate。
导引无法匹配、资源不足或等待队列时保留单次 NR，并显示原因。
若第二层不透明调用失败，停止该链后续 GPU 录制、保留依赖并返回失败，需重启游戏；
不在可能损坏的命令列表上继续合成或重试。

## 诊断与对比

- 菜单显示实际两层尺寸、第二层录制次数、辅助显存和完成后的 GPU 样本。
- GPU 分项包含 NR1、缩小、NR2、小图残差、合成、原生 SR 和链路总时长；
  使用实际队列时间戳频率和对应提交 fence。暖机、F7/F8/重放采集和旧配置样本
  不进入当前稳定窗口；窗口最多 120 个样本，中位数和 P95 仅代表这条链路。
- 双次 NR 生效时使用 **采集双次 NR 对照（F7）**，同时保留原有 F7 诊断。
  额外文件位于“文档 / DLSS5-Dual-Capture”：同一次录制中的 P1、L1、L2、
  第二层实际绑定的深度/运动资源、最终合成、参数、父子实例和比例元数据。
  这是一个已暖机的观察帧，不能当作从冷历史开始的完整模型重放。
- F8 TXT 包含两层状态、实际尺寸、调用计数、父子实例、显存、GPU 分项和通用倍率。
  CPU Evaluate 返回成功和 GPU 完成分别记录，不能把它们当作游戏/插帧帧数。

建议先在相同场景比较单次、双次 100%、双次 50%；然后固定 NR 设置，分别比较
引擎导引分区与通用控制。游戏效果、真实 NVIDIA 双层历史稳定性、显存和整帧性能
需要实际运行验收。CPU、编译和 WARP 通过均不能替代这些结果。

安装时只替换已核对的 Core，保留个人 INI、ReShade、桥接和 NR 模型；旧 Core
保存在游戏目录外。默认关闭新增实验，维护者自行开启。此文件不是自动安装授权。
