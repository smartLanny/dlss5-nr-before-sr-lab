# beta0.5-dline4 异环整合测试

这版将 0.4.7 ABC 兼容修复合进 0.5 D 线，保留两条分支及旧测试包。
包括异环 RR 深度/设备识别、原生录制登记、首轮录制、有界前置转后置回退。
其他游戏的适配前提仍按原报告；鬼武者的已通过组合包含官方 REFramework。

菜单保留风格前移、光影组位于模型细节下/高级画质上，路线改为左右选择块。
RR 自动后置时不改写个人保存的路线。光照保护在 0.5 新装/恢复默认仍为0.2。
更新时保留现有个人 INI，不自动重置画质或更改游戏内 RR。

异环可先固定场景关闭 RR 确认 NR，再开启 RR 检查自动后置是否运行。需要运行
状态时保存 F8。为单独比较反射，先选“原样效果”，保持辉光抑制0，再把反射
从0%调到200%；同时改多个参数会互相抵消，不能据此判断单项无效。

“模型新增提亮/压暗”控制模型额外产生的大范围明暗改动：100%保留，0%去掉
该部分，超过100%增强，并非游戏整体亮度。辉光抑制100%会去掉宽亮，所以此时
提亮滑块不会改变这部分。反射只处理已有细亮残差，不识别反射材质。四分区
预览显示分类本身，不随增强值改变；比较画面时应退出预览。

人脸发黑、恢复默认后人脸调节有效而改其他画质后不明显，仍是待确认问题。
本次兼容整合不把它称为已修复；F8 参数一致也不代表模型识别到人脸。若复现，
固定镜头留下有效/无效各一份 F7/F8，并记录中间只改变的那个选项。

本地构建、CPU/WARP、父分支游戏通过和本整合包的游戏表现分别记录。此包不是
稳定发布或 Manager OTA，不包含个人 INI、NVIDIA 运行库或运行时肤色保护模块。
异常时退出游戏恢复上一 Core，保留该次反馈与原有游戏运行库。
