# dev10 全屏采集测试版

F7 保存当前完整游戏画面，保持 ReShade 截图的原始分辨率，不裁切、不缩小。
“反馈与诊断 → 图像补充 → 七组画面对比：全屏原图”依次保存关闭 NR，
以及 NR→SR、SR→NR 各 50%、75%、100% 的画面。每组一张截图，并带该组设置。
开启 RR 时，NR→SR 组会明确跳过。结束或取消后恢复原设置。

采集时保持镜头和场景不动；如菜单挡住人物，按 `=` 收起菜单。七组约需半分钟，
可以再次打开菜单看完成状态。各组顺序采集，不是同一帧；文件是完整显示截图，
不包含内部 GPU 原始平面。F8 继续提供单个反馈 TXT。

“人脸调节”和“人脸细节强度”回到普通画质菜单。全新安装默认开启 NR→SR；
用户保存的关闭状态、前后顺序和其他设置继续保留。NR→SR 可以减少相对后置 NR
的计算成本，不代表开启 NR 比完全关闭 NR 更快。开启 RR 时保留兼容性约束。

本版修复菜单轮询覆盖临时采集设置、导致七组对比中途超时的问题。双语完整编译、
453 项采集控制检查、16 张 4K PNG 原字节打包、88 项 Win32 配置迁移检查及
13 组 WARP 合成检查通过；真实游戏的新 F7 流程尚待运行确认。

异环人脸调节无明显效果仍是 [#162](https://github.com/smartLanny/dlss5-nr-before-sr-lab/issues/162)
已知缺陷，按维护者要求暂停排查。本版不是人脸算法或异环 RR 深度适配修复。
当前不要求继续提交人脸专项对比。2077 人脸调节有效的维护者反馈保留。

安装仅更换 Core，退出对应游戏后操作；保留现有模型、ReShade、运行库、配置及
`=` 菜单快捷键。测试包不包含第三方模型，不是 Manager OTA 或正式发布。
