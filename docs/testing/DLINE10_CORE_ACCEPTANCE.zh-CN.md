# D10 精细分区测试包

版本 beta0.5-dline10 / PE 0.5.1.10。用于独立 0.5 D 线的 DX12 测试；
不替换稳定版、不修改游戏的 DLSS 渲染比例，也不增加 NR 推理次数。

## 安装与回退

退出游戏，备份当前 Core 和 `nr_before_sr.ini`。将旧 Core 移到游戏目录之外，
放入本包对应语言的一个 `.addon64`；同时只保留一个 Core。
沿用当前 ReShade、NR 模型和个人 INI。包内的 `nr_face` 文件夹与 Core 放在同一目录，
其中的可选识别组件只有手动开启独立人脸实验后才加载。

回退时退出游戏，移走 D10，放回备份的 Core；保留个人 INI。
本包不自动安装、不自动上传数据。

## 精细分区

在画质菜单开启“使用引擎导引精细分区”。这会替代旧五项光效调节；
旧值仍保留，关闭开关即可恢复旧控件。模型强度、整体细节、人脸细节等模型参数不变。

- 宽范围增亮、细节增亮、宽范围压暗、细节压暗各有明暗和颜色倍率。
- 引擎镜面区域有独立明暗与颜色倍率；纯颜色改动另有倍率。
- 1 倍为中性，0 倍去掉该区对应改动；颜色倍率以现有颜色跟随量为基础。
- 选区由原始 NR 输入/输出和可用引擎信息计算，倍率不参与选区。
  使用“选区预览”检查覆盖范围，再调倍率。

通用分区使用原图边缘和可用深度；RR 还能使用法线。
镜面区域必须同时有可用镜面反照率与反射射线命中距离，缺失时不启用该区。
它限定反射表面上的模型改动，不等于单独取得了引擎的反射光照图层。
预览中的绿色为镜面区域，橙/红为宽/细增亮，浅蓝/蓝为宽/细压暗，紫色为纯颜色。

## 前后置与分辨率

支持 NR→SR、SR→NR 和 RR→NR 的现有 DX12 路线。
引擎导引在原生 SR/RR 调用前保存，分区在有界低分辨率网格计算，
最终恢复到对应路线的原画面尺寸。深度、图像边缘及正负改动用于抑制跨区域混合。

开发者选项中的低分辨率亮度/色彩合成也可在后置使用；
它们会选择共用合成候选，可能改变插值观感。通常先保持默认关闭，
只开启精细分区检查效果。亮度场的 Catmull 恢复仍要求颜色跟随为零。

## 独立人脸实验

默认关闭，正常路径保持模型原有的人脸控制能力。
需要自行试验时开启独立人脸保护：可限制脸区额外增强不超过同次 NR 的 1 倍结果，
也可分别降低脸区明暗与颜色改动。它不修改模型的 Skin 参数。
识别、跟踪和实际游戏观感由维护者自行验收；遮挡、运动或导引缺失时可能没有覆盖。
后置且运动向量含抖动的情况暂时停用独立脸区跟踪，以免使用错误的抖动补偿。

## 证据与反馈

随包 `build-info.json` 记录准确源版本、构建验证与能力边界，`SHA256.json` 校验内容。
GPU 模拟器的合成及资源契约验证不等于真实游戏或 NVIDIA 模型画质验证。
“相同 NR 设置下整帧 GPU 中位数/P95 增幅不超过 5%”尚待真实游戏数据，不能据此宣称已达标。
F8 保留单文件反馈；D9 的完整输入序列采集仍在“反馈与诊断”，仅排查时使用。
