# beta0.5-dline2 独立后置候选验收说明

本候选在 D1 完整设置界面上增加后置光影控制，PE 版本为 0.5.1.2。
它独立于首包，不是正式发布或 Manager OTA；不自动安装到游戏。

前置与后置都提供反射增强、暗部结构和辉光抑制，以及原样效果、自然耐看、
减少辉光三个候选预设。原有模型风格、人脸调节、NR 工作比例、AI 色彩、
本组撤销和 F7 采集配置保持继续保留。预设只更新本组系数及其指定的 AI 颜色，
不会改变模型、处理顺序或游戏兼容条件。

辉光抑制只处理 NR 新增并被该方法分到宽亮区的成分；它不关闭游戏本来的泛光，
也不是人物识别。四分区预览使用橙色宽亮、蓝色宽暗、黄色细亮、紫色细暗；
修改差预览显示全部最终 NR 效果相对原图的差异，包括颜色与保护。预览仅本次
运行有效，可随时退出，不写入个人配置。

后置沿用原来的颜色、曝光和亮度计算；用户已选的独立色度后置仍沿用其原算法。
本版不新增 RR 游戏适配，不包含 #206。某游戏原有 NR/RR 无法运行、条件不满足
或被旁路时，新增光影控制同样不会改变画面；F8 中保留具体状态，不把设置请求
当作已经执行。肤色补充算法仍只有独立夹具，本候选没有把它接到游戏运行链。

开始验收时保留已用 Core 的副本、个人 INI 和原有 NVIDIA/ReShade 运行库，
只使用与候选身份对应的 Core 与自有 nrchain。固定同一场景、视角、模型和
NR 比例，先比较本组中性，再比较单项和三个预设；分别记录前置与后置。
关注人物周围宽亮雾、反光细节、暗纹、运动稳定性和帧时间。需要反馈时用 F8，
需要画面对比时使用 F7；未取得的模型/图像证据不作成功判断。

源码、双语构建、WARP、真实 NVIDIA/游戏、性能与发布是不同结果。具体通过
范围以候选 manifest/validation 和 CURRENT_STATUS 为准；没有记录的检查
仍未验证。异常时恢复先前 Core，保留该次 F8，不覆盖原有证据。

本次维护者异环验收已选择关闭游戏内 RR，暂不合并 ABC。专用安装起始为后置、
原始光照保护 0.2、新控件中性，保留其余个人设置及 dev14 备份。先用固定镜头
比较“原样效果 → 自然耐看 → 减少辉光”，记录人脸亮度及背景变化；再切换前置
作同场景对照。0.2 是维护者在旧候选上有效的缓解值，不代表 D2 已修复人脸变暗。
通用压缩包不带个人 INI，也不会替其他用户强制选择该起始配置。
