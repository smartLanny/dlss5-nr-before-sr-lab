# beta0.5-dline3 异环反馈候选

这版沿 D2 接续，调整菜单与反馈记录，保留前后置光影算法及人脸调节含义。
菜单顺序改为快速设置、模型风格、处理方式、模型细节、光影与细节、高级画质。
光影高级选项仍在光影组内，不再与主控件分散。

辉光抑制减少模型新增的大范围提亮。反射增强只调整模型已有的细小亮部变化，
暗部结构只调整模型已有的细小暗部变化；它们不会识别材质或自动补出新细节。
四分区预览显示原始分区，不随增强倍率变化；比较滑块效果时应先退出预览。
原样效果、自然耐看、减少辉光三个预设保持 D2 数值。

F8 单 TXT 补齐光影请求值及预览状态，完善历史成功 NR 的人脸、风格和细节
参数记录。请求不代表画面效果；快照不可用时不填入看似有效的默认参数。
不增加图像读回，也不改变采集时的画质设置。

维护者报告 D2 辉光抑制可见，反射增强与暗部结构不明显；人脸变暗在后置更明显。
恢复默认后人脸调节曾有效，改变模型风格或其他画质项后又变得不明显。这些仍是
待验证的画面问题，D3 不将反馈记录补全称为算法修复。人脸调节只请求模型单独
处理皮肤细节，整体光照、颜色和强度仍会影响脸部。

本轮继续独立 D 线，异环先关闭游戏内 RR，ABC 暂不合并。更新保留个人 INI。
如果再次出现人脸调节变化，固定镜头，记录恢复默认后的有效状态，以及只改变
一项模型风格/画质后的无效状态；两次 F7 和各自 F8 有助于检查同一张脸与参数。
新控件单项对照可分别比较 0% 与 200%，保持其他项及镜头不变。

正式游戏/NVIDIA 验收与性能结果以实际记录为准；本地构建与 WARP 不代替它们。
异常时退出游戏，恢复上一 Core，保留该轮反馈。此包不是稳定发布或 Manager OTA，
不包含个人 INI、NVIDIA 运行库、新 RR 适配或运行时肤色保护模块。
