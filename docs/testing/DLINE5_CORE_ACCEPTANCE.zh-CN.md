# beta0.5-dline5 完整亮暗控制测试

本版接续已合入 0.4.7、且维护者确认异环 RR 通过的 D4。新增完整亮暗模式，
前置及实际后置合成都可选择；保留旧细节分层模式。深度原型尚未接入运行时，
没有新模型、额外 NR 调用或残差时域历史。

光影组顶部选择“完整亮暗”后，“亮部增强（含反射）”影响模型产生的整个变亮
部分，“暗部增强”影响整个压暗部分。100% 保持、0% 移除该方向的亮度改动、
200% 增强；总有效强度仍受已有上限及光照、边缘、近黑、HDR 保护约束。
它不是反射材质或人脸识别，颜色跟随仍由独立的色彩控制与准入决定。

“细节分层”保留 D4 的规则：反射/暗部结构主要调整细亮/细暗成分。
两模式可在同一镜头直接对照，不需要重建 NR 模型。高级菜单的模型新增提亮/
压暗和辉光仍有效；辉光100%删除宽亮，也可能压掉宽大反射，不适合用来验证
完整亮部控制的最大作用范围。

建议固定镜头、模型风格、工作比例和光照保护，按以下顺序测试：

1. 在光影组选择“原样”，保持辉光为0、宽亮宽暗为100%，然后选择“完整亮暗”。
2. 分别对照亮部增强0/100/200%，观察反射及大块变亮区域；只改这一项。
3. 单独对照暗部增强0/100/200%；0应减弱模型新增压暗，200会加强压暗。
4. 用相同数值切换“细节分层”作比较，再单独增加辉光抑制。
5. RR 开启时测试实际后置；关闭 RR 后可分别测试前后置。需要状态记录时保存F8。

已有 INI 缺少 `LightControlMode` 时保持旧模式，更新只替换 Core 并保留个人
设置。组预设及“本组恢复中性”保留当前模式；撤销恢复切换前的模式及数值。
整个画质“恢复默认”采用完整模式1，但安装不会自动执行画质恢复。
F8 记录请求模式，逐帧采集元数据另记合成记录的模式，不把请求当执行证明。

本地编译、CPU/WARP、实际菜单与游戏测试分别记载。具体成功状态以同包来源
记录为准；继承的 D4 RR 通过不自动变成本包游戏通过。人脸发黑或改模型风格
后人脸调节变弱仍是待解决问题，本版不宣称修复。

异常时退出游戏恢复备份 D4 Core，保留当前 INI、游戏运行库与此次反馈。
本包只含中/英文 Core 之一与自有桥接、说明和许可证，不含替换个人 INI、
NVIDIA 运行库/模型、ReShade 或 Manager OTA。
