# D11 双次 NR 与通用分层接入记录

本批接续 D10 的隔离工作树。D10 已交付维护者实机测试；D11 尚在内部构建与验证，
未宣称游戏、真实 NGX、画质或性能验收通过，不合并 main，也不发布正式版本。

维护者提供的双次 NR 关键代码为原创新实现。本次保留其独立 Feature、参数和历史，
1/2 次选择、25%–100% 有理比例、100% 直接 P2、低分完整场景输入和匹配增量合同。
为避免最终多邻域采样反复展开颜色转换，低分路径在 N2 上额外保存一次 FP32 匹配
增量及有效性；最终恢复仍融合进现有读取，没有额外 N1 图写入，也没有第二次 SR。
原始 L1/L2 保持不变。该实现与包内逐次计算参考需要数值和实际 GPU 对照。

第二层只在独立创建的确切 fence 完成后 Evaluate。创建纹理、参数、描述符和原始
导引引用随完整上下文退休。任何不透明第二层失败都会隔离该命令列表的全部依赖，
返回错误并停止当前后续合成、SR 或状态恢复，不在同一列表上尝试补救。

辅助纹理单独预算每 slot 256 MiB、全池 1 GiB，包含在用和退休的辅助代次；
主层原有附加资源预算维持不变。此数值是有界分配上限，不是性能或显存占用目标，
不包含 NVIDIA 内部不可见分配。上下文/slot 数量仍为原有 16/8。

## 通用分层对照

参考固定版本 Magpie 的公开方向/HSL 数学方法，使用自有实现，未复制其 GPL 源码：
[DLSSNRFilter.cpp](https://github.com/SAOG0721/Magpie/blob/ac1cc8b0f2efc78323898395cc1336bcbecdc276/src/Magpie.Core/DLSSNRFilter.cpp)。
总倍率后按线性亮度差正负选择整段 RGB 改动，再相对原图调节 HSL 饱和度和明度。
Reflection/Glow 是共同的通用亮变化类别，没有两张反射/辉光语义遮罩。

D 在自己的归一化模型存储域中执行此对照，并保留原有最终合成及 HDR/颜色保护。
低网格编辑构造在模型网格应用，直接合成在恢复后的采样点应用；这不是完整复制
Magpie 的缩放、SDR 截断及最终输出链。超出归一化范围的样本保留既有合成。
实验默认关闭，启用时替代引擎分区和旧光效控制，模型参数不因此改变。
