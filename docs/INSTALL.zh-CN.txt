DLSS 5 AI渲染超分版 beta0.4.1-r2 社区测试版
作者：@野生的装机宅 Bilibili
官方发布地址：https://space.bilibili.com/941799

第一次安装

新装默认最终效果强度 1.2、颜色跟随请求 0.75，并开启模型 HUD / 文字保护参数。滑条显示实际请求值，没有隐藏倍率。已有明确设置（包括 0）会保留；未知 HDR 颜色跟随实际仍为 0。

先选与显卡对应的完整包。游戏需要支持 D3D12 和原生 DLSS 超分，并已安装能加载 addon 插件的 ReShade / RHI。只在允许使用此类插件的离线、无反作弊环境中使用。

完全退出游戏，把完整包里的九个文件解压到 ReShade 实际读取插件的目录。通常是游戏真正的 64 位程序和 ReShade DLL 所在目录；设过自定义插件目录的，以自己的设置为准。

九个文件是：
一个以 .addon64 结尾的插件文件
nrchain_nvngx.dll
nvngx_dlssnr.dll
nr_before_sr.ini
Collect-Feedback.cmd
collect-feedback.ps1
Collect-Crash-Feedback.cmd
collect-crash-feedback.ps1
说明.txt

这些文件要放在一起。移走旧版或另一语言版的本插件，不要同时开两个会处理 NR 的插件。启动游戏后，在 ReShade 插件面板确认版本为 beta0.4.1-r2。

已经装好且能正常运行的玩家，可以用小更新包，沿用原来的大 DLL、桥接 DLL 和配置。具体按小更新包里的说明操作；小更新包不能用于首次安装。

怎么用和对比

先用默认设置。F6 是本插件总开关，关闭后可观察游戏原来的 DLSS 超分画面。

对比效果时，固定机位，自己切换开关或设置，每次只改一项。等画面重新稳定后，在每个设置下分别按 F8 收集一包。默认“采当前问题”只截一张当前画面，不会切换设置；只有在高级反馈选项中明确选择对比，程序才会临时切换内存设置。

遇到问题，按 F8

停在能看清问题的位置，按 F8，或点击面板里的“一键采集反馈包”。保持机位，等待面板提示完成。

它会收集一张当前画面截图，并尝试加入连续 16 个 NR 处理帧、一张独立概览、画面信息、请求和实际生效的设置以及日志。NR 关闭或旁路时可能只有截图和日志，包会明确标为部分完成。处理帧来自 NR 运算，不保证和显示截图是同一帧。

采集最多等待约 30 秒，之后还要等后台打包，磁盘慢时会更久。提示“部分未采到”也可以反馈，包里会写明缺了什么。

feedback.zip 通常保存在系统“文档”里的 DLSS5-Feedback，每次有独立文件夹。如果无法在“文档”创建目录，F8 会尝试系统临时目录。请以面板显示的路径为准，也可以点按钮复制路径。

游戏无法启动怎么办

如果只是进不了游戏或没有画面，双击 Collect-Feedback.cmd。它只收集日志、设置和版本信息，不会收集转储。

如果要报告闪退，闪退后双击 Collect-Crash-Feedback.cmd。两个 collect-*.ps1 必须和它放在一起。它会从最新 ReShade.log 严格确认唯一的游戏 EXE 完整路径，只收集最近 72 小时内符合身份规则的 Windows 1000/1001 摘要、已有 WER 报告和已有转储；带 AppPath 的记录必须与当前游戏路径一致。独立 CrashDumps 不含来源路径，只能按精确 EXE 文件名和时间筛选，包内会标明这个限制。工具不会开启转储、修改注册表或上传。转储可能包含进程内存和本机路径，发送前请自行决定是否分享。两种工具都不需要管理员权限，输出在“文档”的 DLSS5-Feedback。

发反馈时请附上 ZIP，并说明游戏名、显卡型号、HDR 还是 SDR、遇到了什么问题，以及希望看到什么效果。文件只保存在本机，不自动上传，也不会自动切换画质设置。日志和截图可能包含安装路径及画面中的叠加信息。

这次改了什么

修正了《赛博朋克 2077》使用四通道半精度浮点运动向量时，默认 NR 画质档位安全旁路、看起来完全无效的问题。新路径只读取这种明确格式的 XY 运动信息，未知格式仍会旁路。本机短时运行确认 NR 持续提交；这不等于已经判断画面更好。

稳定版默认不再在空 PSO 命令状态中强行插入 NR，降低《极限竞速：地平线》所报闪退回归的风险；反馈包没有转储，因此实机仍待验证。模型界面修正参数也改为运行库实际读取的无符号类型。它只有在游戏提供独立 UI 层时才可能保护文字，不能自动识别已经混入画面的字幕。

修正了一类游戏渲染状态尚未设置时，插件被误判为不能运行的问题；修正了无效曝光值的处理；面板会提示颜色跟随等选项当前实际生效的值和受限原因。

这些改动不代表所有游戏都已修好。效果偏弱、蜘蛛侠的人脸和 HDR、鸣潮的颜色与曝光、龙之信条 2 的崩溃仍需要新版本反馈。遇到滑条变化不明显，请保留同机位的对比包，不要只凭“已应用”判断画面一定会明显变化。
