# beta0.3.3-dev-r3：修复候选与受控对照

本轮从 `015d05df61118773c5466c0dbe0608ea2abaa90d` 开始。首个候选只加入
确定性合同修复和诊断，不改变默认合成，不新增“效果优先”调色。
旧蜘蛛侠及反馈表材料来自巫师 HDR 修复前版本，不能用来判定 r3 仍然失败。
用户已确认巫师 3 的 HDR 在前一修复版生效；r3 的新变更仍需要回归实测。

## 本轮变化

- 无新增独立 hook 的模块发现不再改变 observer epoch；两个延迟模块先解析、
  按实际操作入口去重，再通过同一次 queued transaction 发布。实际目标模块 PIN，
  失败/null Create 不污染观察状态，未知非空 Release 继续严格保护。
- Color/Depth/MotionVectors/Output/ExposureTexture 的 typed getter 失败或为空时，
  尝试受限的原生 D3D12 untyped getter；失败调用留下的输出指针不作为有效资源。
- 动态尺寸 A→B→A 不复活旧历史；guide 的格式、尺寸及创建合同变化重建，
  坐标、MV.Scale、深度解释变化 Reset。每个 Reset 必须成功 Evaluate 才能消耗，
  成功 Reset 后重新预热。原生 SR 的参数和 MV 数值单位保持原合同。
- R8 覆盖 stale HDR 标记需要两项曝光标量明确存在且为单位值，没有曝光纹理；
  普通 SDR 的缺省标量行为不变。
- 日志加入成功创建实例号、成功 NR 评估帧号、已绑定配置和完整调参快照。
  新实例预热后第一次有效 ColorDiag 必须输出；延迟回读不能覆盖更新的面板快照。

## 如何做一次可解释的画质对照

1. 记录候选 addon 和 NR runtime 的 SHA-256、驱动、输出分辨率、DLSS 档位、
   游戏 HDR 开关。外部参照固定 RenoDX/RHI **4.70**；不同插件分别安装测试。
2. 在同一存档、镜头与光照下先做 A→A，观察场景自身噪声和时域差异。
   优先暂停镜头运动；另录运动片段检查头发和细线闪烁。
3. 默认组使用强度 1、LocalTone/LocalStructure 1、Skin -1、AutoMask 关闭、
   合成强度 1、Lighting Match 关闭。玩家高参数配置另成一组；不覆盖原 INI。
4. 每组分别测试关闭、SR→NR、NR→SR；再单独测试强度 1→2→1、自然→电影→自然。
   一次只改一个变量。每次切换等待面板“已应用”和“预热完成”，并使用相同成功评估等待量。
5. 点击“采集一次 NR 各阶段”，或按 `F7` 独立请求阶段图。
   `F7` 不保存显示截图；日志记录阶段请求是否被接受。
   一个进程只允许一个未完成阶段请求，重复按键不会增加请求；默认不开启。
   GPU 完成且相关 command list 释放记录引用后，后台写出四张 PFM 和 metadata.txt。
   采集目录位于日志旁。失败查看日志；不等待 GPU，不改变 NR 参数。
6. 按主键盘 `-` 或小键盘减号另取显示截图。文件名 `REQ` 表示请求设置；日志同时
   记录最近应用的实例和配置。显示截图含 Present/FG/后处理影响，不是同一 NR 帧证明。
   `F7` 阶段图与 `-` 显示截图必须分别读取身份与元数据，不能当成同帧证据。

阶段图是原始浮点采样：original 在源存储域，proxy/neural 在模型输入编码域，
composited 为写入目标格式量化**之前**的值。不能直接跨域比较平均亮度。
采样采用整数步长，不作插值；每边至多 1024 像素，GPU 与回读缓冲合计至多 64 MiB。
完整取样尺寸、步长、曝光标量、原始格式、子矩形、有效颜色跟随强度都在元数据中。

**NR→SR 的阶段图止于原生 SR 之前。**没有已验证的游戏 Output 到达状态时，
不能为了诊断猜测资源 barrier。原生 SR 后细节是否减弱需要独立显示对照，
不能从本轮四阶段图直接下结论。SR→NR 的 original 则是已经过原生 SR 的输入。

## 实机验收表（本轮尚待提供匹配哈希的结果）

| 游戏／项目 | 验证动作 | 判定 |
|---|---|---|
| 巫师 3 | HDR Off→On→Off；两个处理顺序；F6 多次开关 | 后续 NR 可恢复，无永久误旁路，无新增肤色／高光退化 |
| 蜘蛛侠 2 | SDR/HDR；关闭/NR/NRSR；固定人脸及头发运动片段 | 区分旧版退化是否消失、模型过强、合成丢失或 SR 后变化 |
| 自然／电影 | 两种风格往返、参数完全相同，并与固定 4.70 参照分别对比 | 实例和 style 确实切换；图像差异按场景记录，不预设必须更大 |
| 强度 1／2 | 往返强度测试，优先使用曾报告问题的存档 | 参数应用与视觉响应分开判定；不能把成功 Create 当成效果通过 |
| 燕云 | R8、切场景／显示模式、RTX30/40 对应 runtime | 首个旁路原因明确；可用时成功评估且可见；未知合同保持原图 |
| 通用 | DRS A→B→A、Reset失败、RR、F6关闭 | 不复用陈旧历史；Reset重试；RR原路径；关闭后零 Feature18 |

日志可以证明参数、实例及资源合同，截图可以定位外观，视频用于证明闪烁。
当前社区反馈不足以宣称“蜘蛛侠已修复”或“NR 强度／风格失效已复现”。
