原生测量定义：

- FPS = 1000 / 最近最多240次前台回调间隔的算术平均（ms）。
- 曲线可切换每回调的即时FPS与间隔ms；不丢弃普通卡顿；失焦/超过10秒间断清空。
- GPU指标为NVML设备总体。power以mW换算W，可能是驱动时间窗平均，非精确瞬时游戏功耗。
- UI隐藏且未固定性能条时停止传感器采样。监测开销仍需实测，未承诺零开销。
