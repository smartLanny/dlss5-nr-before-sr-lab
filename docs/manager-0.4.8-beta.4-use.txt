DLSS 5 AI 超分管理器 0.4.8-beta.4

完整 ZIP 请全部解压后运行；便携 EXE 可单独运行。升级前正常退出旧管理器。
管理器默认以普通权限运行。受保护目录的变更在预览确认后请求一次 Windows 权限，
本次操作结束后界面继续以普通权限运行。游戏、启动器和既有备份按原事务分别核对。

本版变化
- 新安装默认 Core 0.4.7beta；已有安装保持原来的固定配套，升级仍需预览并应用。
- 未设置过 ReShade 面板键时，新安装默认 Home。已有自定义键（包括原来的 =）保持原样。
- 普通游戏的“放弃修改 / 预览并应用”紧邻顶部启动按钮，滚动时也能看到。
- 007 First Light 的已核验原生集成加入支持目录；RTX50 按游戏和驱动支持开放 2–6×及 Dynamic。
- 米哈游游戏移到独立侧栏页面，按当前状态只突出下一步操作。
- 修正 Windows 路径大小写导致的米哈游原事务校验失败，以及恢复后仍显示安装完成的问题。

米哈游游戏
打开侧栏“米哈游游戏”，先读取 HoYoPlay / Starward 已有安装记录，再核对实际正式游戏 EXE。
支持原神、崩坏3、崩坏：星穹铁道、绝区零的受支持正式客户端；测试服不自动匹配。
游戏与启动器可以位于不同文件夹或磁盘。唯一可信的客户端、渠道和启动器关系自动保存。
有多个候选或证据不足时，只确认无法自动确定的部分；游戏程序和启动器可分别手选。
游戏或启动器更新时重新核对身份。没有新的唯一证据时，保留原路径供重新确认。

首次使用：发现客户端 → 确认尚未确定的绑定/API → 预览 → 应用 → 启动游戏。
图形 API 不等于引擎支持的所有后端。Unity 中出现 OpenGL 导入，不能据此认定游戏正在使用 OpenGL。
无法确认时显示待确认；已有手动选择保留。可在“启动器、配置与维护”中修改图形 API，
选择变更后需再次预览并应用配套，才能按新路线启动。

管理器先准备加载助手，助手就绪后才打开已绑定的启动器。使用 HoYoPlay 时，
在它的界面点击对应游戏的启动按钮；管理器随后核对实际产生的游戏 EXE 与进程身份。
使用 Starward 时，先在 Starward 注册其 URL 协议，管理器核对绑定后通过协议请求启动。
不会改为直接运行米哈游游戏 EXE。客户端需要管理员权限时，仅本次后台助手请求 Windows 权限。
取消等待不会关闭游戏。最长等待五分钟；超时或失败保留绑定及恢复记录。

“ReShade 已加载”“Core 已加载”“NR 处理成功”分别核验，助手就绪不代表 NR 已完成。
画面与快捷键设置在本专页内打开。卸载、恢复和修复也在“启动器、配置与维护”中预览。
安装报错时不能显示可启动；有未完成操作时先恢复该操作。卸载后保留客户端与启动器选择。

007 与原生超分、补帧
游戏菜单开启游戏自身的 DLSS / FG；管理器预览并应用驱动覆盖；ReShade 菜单调整 NR。
RTX50 的 3–6×或 Dynamic 需要对应游戏集成与驱动支持。选项可配置和读回成功，不代表实际倍率已验证。
RTX50 不需要 RTX40 MFG Unlock 插件。RTX40 的兼容插件是独立组件，不能代替游戏原生 FG 集成。
管理器不会给本来没有 DLSS / FG 的游戏装成原生集成；缺少证据时，功能保持待确认或不可配置。

配置与恢复
每游戏的组件、配置和恢复记录独立保存。同一实际加载目录只保留一套受管 Core / 桥接器。
更改前先退出游戏。预览核对文件列表；个人预设、滤镜、纹理和配置不应被整目录覆盖。
原件只有在所有者记录和摘要一致时才可恢复，未知 .bak 不会被当成原件。
本版兼容以前自动添加“=”的安装记录；恢复时使用该次安装的默认键记录，不套用新 Home 值。
手工改动导致摘要不符时先处理冲突；不会修改收据摘要来宣称组件已验证。

已知限制
Batman: Arkham Asylum GOTY 的本机 DX9 R3 测试由用户报告约 30 FPS 后卡住、没有观察到效果，
按失败记录。本版没有宣称修复该游戏，DX9 后续诊断与米哈游流程分开处理。
受控程序的 NR 计数不能替代真实游戏稳定性和画面对照。本版真实游戏验证结果以交付验收记录为准。

反馈请保留同次运行的游戏 EXE、API、Core 版本、活动配置目录、日志和画面对照结果。
管理器安装包与手动游戏插件更新材料用途不同：受管安装请使用管理器预览、应用和恢复。
