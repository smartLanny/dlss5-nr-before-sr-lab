## 尚未完成

融合收缩的源码录制路径从每对4次调用变为3次；其新 GPU 输出、发布顺序和完整 NR→SR 画质尚未验收。
Pack＋expansion 主循环融合尚未实现，因此不能声称已经压到每对2次调用，也不能声称达到完整NR降低10%的目标。

已恢复的 pack、gate、epilogue 数学和暂停前的56组收缩正确性证据见 `NVFP4_DEV14.md`。
这些证据不替代融合内核、真实游戏、HDR/DRS和性能门槛。早期计时受其他 GPU 工作负载污染，不用于选择赢家。

当前 Auto 的编译内合格策略表为空，选择 Auto 仍保留 FP8并显示原因；任意旁置 JSON 不能绕过该门槛。
下一轮恢复图形测试后，应先使用独立宿主验证融合输出/计数器，再测实际 M640 与其他尺寸、完整链路和五轮交错A/B。
未来合格策略还需记录真实 NVIDIA 驱动构建身份，不能拿 CUDA driver API 版本当作驱动610.62。
