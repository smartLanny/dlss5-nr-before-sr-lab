3. 基础通过后分别增加多层、HDR、FG，再检查 F6、改变分辨率/DRS和正常退出。
   条件一次只变一项；没有覆盖的场景写未测，不扩大验收范围。

## #313：9/26 历史实验修复与当时验证

原私有 SR owner 可在列表 A 尚未提交时，继续在另一列表 B 上调用同一个私有
Feature1。相同 direct queue 身份并不保证这两条列表之后按 A→B 顺序提交。
CPU 回归在原代码中编译成功，运行于预期的前序提交检查失败。

本轮在 owner 和外层 post transport 分别增加前序未提交时的准入限制。外层在
Encode/barrier/slot 采用前拒绝；只保留已有候选，不额外持有新导引或另建模型。
已经提交但仍在 GPU 执行中的前序不被阻塞，不增加 CPU fence 等待或 Flush，
三组独立 scratch slot 保留。重复源帧先拒绝，不额外重置良好历史；真实跳帧
仍遵循原 Reset 策略。若调用者先批量录制多个源帧再提交，私有支路会保守拒绝后续帧，
这是明确的兼容取舍，不能伪造提交回执绕过。
