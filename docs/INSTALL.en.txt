First installation

New installations start with final effect strength 1.2, colour follow 0.75, and the model HUD/text-protection parameter enabled. The slider is the actual request with no hidden multiplier. Explicit existing settings, including zero, are preserved; effective colour follow remains zero for unknown HDR inputs.

Choose the full package for your GPU. The game needs D3D12, native DLSS Super Resolution, and ReShade / RHI with addon support. Use it only in offline environments that allow these addons and have no anti-cheat.

Exit the game completely. Extract all nine files into the directory where ReShade loads addons. This is usually beside the game's actual 64-bit executable and the ReShade DLL. If you configured a custom addon directory, use that directory.

The nine files are:
One addon file ending in .addon64
nrchain_nvngx.dll
nvngx_dlssnr.dll
nr_before_sr.ini
Collect-Feedback.cmd
collect-feedback.ps1
Collect-Crash-Feedback.cmd
collect-crash-feedback.ps1
Instructions.txt

Keep these files together. Remove the old build or other language version of this addon, and do not run two addons that both process NR. Start the game and check for beta0.3.7 in the ReShade addon panel.

If you already have a working full installation, you can use the small update package and keep the existing large runtime DLL, bridge DLL and settings file. Follow the instructions in that update package. It cannot be used for a first installation.

Using and comparing the effect

Start with the defaults. F6 turns this addon on or off. With it off, you can compare against the game's original DLSS Super Resolution output.

Keep the camera in the same position and change only one setting at a time. Let the image settle, then press F8 once for each setting. The three screenshots all use the current settings; the program does not switch settings to create an automatic before/after comparison.

Press F8 when something looks wrong

Stop where the problem is visible, then press F8 or click Collect feedback ZIP in the panel. Keep the camera still until the panel reports completion.

It collects three display screenshots and attempts to include images from the NR processing stages, image information, requested and effective settings, and logs. The processing stages come from one operation; they are not guaranteed to share a frame with the display screenshots.

Collection waits up to about 30 seconds, then background packaging still needs time. A slow drive may take longer. A partial bundle is useful too; it records what could not be collected.

feedback.zip normally appears in Documents/DLSS5-Feedback, in a separate folder for each capture. If that directory cannot be created, F8 tries the system temporary directory. Use the actual path shown in the panel, or click its copy-path button.

If the game will not start

For a startup problem without a crash record, double-click Collect-Feedback.cmd. It collects logs, settings and version information without collecting dumps.

For a crash report, double-click Collect-Crash-Feedback.cmd after the crash. Keep both collect-*.ps1 files beside it. It derives one exact game EXE from the newest ReShade.log, then collects only matching Windows event 1000/1001 summaries and existing WER reports or dumps from the last 72 hours. It does not enable dumps, modify the registry or upload. A dump can contain process memory and local paths, so decide whether to share it. Both tools need no administrator privileges and write under Documents/DLSS5-Feedback.

Send the ZIP with the game name, GPU model, HDR or SDR setting, what went wrong and what you expected. Files stay on your computer until you share them. The collector does not upload automatically or switch image settings. Logs and screenshots may include installation paths and visible overlays.

What changed in this version

The stable build no longer forces NR insertion while the command list has a null PSO, reducing the regression surface behind the reported Forza Horizon crash. The submitted bundle had no crash dump, so game confirmation is still required. The model UI-correction parameter now uses the unsigned type actually read by the runtime. It can help text only when a game supplies a separate UI layer and cannot discover subtitles already baked into the picture.

This version fixes a case where an unset game rendering state incorrectly prevented the addon from running. It also fixes invalid exposure-value handling and shows the currently effective value and restriction reason for options such as Colour Follow.

These changes do not mean every game is fixed. Weak effects, Spider-Man faces and HDR, Wuthering Waves colour and exposure, and Dragon's Dogma 2 crashes still need reports from this version. If a slider seems ineffective, collect both settings from the same camera position. A setting marked as applied does not guarantee a large visible change.
