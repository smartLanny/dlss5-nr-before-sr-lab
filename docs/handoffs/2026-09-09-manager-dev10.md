# Manager dev.10 本机交付

Manager `0.4.6-hotfix.7-dev.10` / Windows `0.4.6.10`，默认原生 DX12 Core `0.4.7beta`。
范围与二进制来源见 [集成说明](../MANAGER-047BETA-20260909.md)。Vulkan 使用独立固定 R5 配套。

## 界面与自动准备

“兼容修复”内并列 D3D12 和“卡普空 RE 引擎兼容”，常用操作使用实心按钮。
精确匹配的 OnimushaWotS.exe 一键安装/更新时自动准备 REFramework。
旧安装先准备组件归属再更新根 Core 与已确认缓存，新安装先生成 Core 配置归属再准备组件。
兼容准备失败时明确保留核心事务的成功事实，并在提示及兼容区域显示失败原因。
主安装、镜像升级和卸载共用原事务；RE 专用中断恢复不被普通设置恢复绕过。
