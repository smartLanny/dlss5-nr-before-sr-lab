# Manager beta.7：启动前状态与两套 Core 测试入口

本轮接续本地 beta.6 提交 `f8b59e903e31c6623966fdfd456d35ca98762897`，管理器版本为 `0.4.8-beta.7`，Windows 文件版本为 `0.4.8.7`。

## 问题与行为

33 号远征队的旧 SR 记录保存了 M 模型和恢复基线，但没有新启动设置接管记录。旧界面只看“没有待应用修改”，显示“设置已就绪”；启动守卫随后正确拒绝启动，要求先明确迁移。

本版在轻量安装检查中读取该游戏的设置归属、迁移和未完成事务记录，区分已安装与启动前待处理。增强页完成读回后提供更新的判断。页面展示原因和现有设置/恢复入口；有新修改时仍先处理草稿。只缺少读回、没有阻止项的正常配置显示“启动时检查设置”，点击启动继续经过原有守卫。

该检查不在卡片加载时读写 NVIDIA 驱动，不自动迁移旧 SR，不删除旧恢复基线。已有新 SR 接管记录时，不再被残留旧策略误阻断。历史启动失败保留诊断用途。普通与米哈游页面使用同一启动设置状态。
