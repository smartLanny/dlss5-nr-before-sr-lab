## 已确认的问题

1. 云端两个 Actions job 尚未运行任何步骤。检查注释说明账户付款或 Actions 支出额度阻止启动，父提交的 job 同样失败；workflow、依赖和锁文件没有发生 PR 差异。因此不能把云端红灯当作测试断言失败，也不能把它算作已通过。
2. 原 PR 在启动前无总时限地等待反馈元数据。已增加短时限，超时继续正式启动，并取消晚到快照的发布，防止把启动后的数据标成启动前证据。
3. 父版本的 HoYo 原生路由测试未指定其已准备的 DX11 配套，错误选择缺少 carrier 的默认稳定夹具。父版本与 PR 同条件复现 `DEPLOYMENT_PACKAGE / carrier`；本地只修正测试的版本选择，不降低生产载荷验证。
