DLSS 5 AI 超分管理器 0.4.7-beta.1

打开管理器
完整解压版：先解压整个文件夹，再双击“DLSS 5 AI 超分管理器.exe”。保留 resources 等配套目录，不要只取出 EXE。
便携版：双击 portable.exe，等待解压与界面初始化。
安装版：运行 Setup，按提示选择安装目录。
管理器默认使用普通权限和 Chromium 沙箱。写入受保护的游戏目录时，在“设置 → 启动与权限”明确选择“以管理员身份重启”。Windows 取消授权或新窗口启动失败时，原窗口会保留。

一键准备
选择实际游戏 EXE 和图形 API，然后点击一键准备。按游戏与显卡条件准备 NR、超分和补帧，并列出各项结果；已有配置会保留。
超分默认请求质量档及适用的推荐模型。请在游戏设置中开启 DLSS；写入请求不等于游戏已采用。
RTX50 满足条件时请求原生 2 倍补帧；仍需游戏本身支持并开启帧生成。
RTX40 使用 MFG Unlock 0.6.1，默认跟随游戏倍率。需要 x64 DX12、已有 Streamline FG、310.x 或更新的 DLSS-G 和完整 ReShade Add-on 支持。它不会给没有原生 FG 的游戏添加 FG。
游戏内按 ReShade 菜单快捷键（默认 Home），进入 Add-ons → MFG Unlock。管理器修改配置后需重启游戏。倍率请求只提高较低的游戏倍率，不会把游戏已有更高倍率降低；跟随或恢复配置不等于关闭游戏帧生成。
旧 RTX40 补帧套装需要点击“迁移并准备 MFG Unlock”。旧动态目标不会自动转换，已有共享加载器和其他插件按恢复记录保留。

没有原生 DLSS 的游戏
首批 Feeder 试验路线面向 RTX50、64 位 DX12、明确 sRGB 的 RGBA8 画面。提供成品帧 NR 后处理，导引由画面和深度估算，效果与原生游戏输入路线不同。
当前不支持 HDR、BGRA 格式、x86、DX9/10 或 OpenGL Feeder。文件准备、实际加载、NR 处理完成分别显示，不会把配套目录里的 NVIDIA DLL 当作游戏原生超分或补帧。
Vulkan 使用已有的独立固定试验配套。切换图形路线前先卸载已安装配套。

准备或迁移中断
游戏必须完全退出后才可修改或恢复。未完成的一键准备会保留记录，在游戏卡片点击“恢复未完成准备”；补帧迁移记录在超分补帧区域恢复。不能确认文件归属或文件已被外部修改时，会保留文件与备份并给出原因。
Feeder 文件操作中断时，卡片提供“恢复并卸载 Feeder”；它会先经过 Feeder 专用归属检查。若一键准备记录仍在，再继续恢复该次准备。REFramework 的专用恢复也可在准备未完成时使用。
补帧组件复制、迁移或恢复中断时，在补帧区域点击“恢复未完成组件操作”。即使此时超分补帧设置显示待恢复或游戏能力暂时不可用，该入口仍可使用；检测到外部替换文件时会停止恢复并保留记录。

仍然打不开时
先运行“启动诊断.cmd”，无需打开管理器即可导出精简诊断。
如需临时验证已知的沙箱启动问题，把 portable.exe 或已安装的管理器主 EXE 拖到“兼容启动.cmd”，阅读提示后输入 Y。只对本次启动关闭 Chromium 沙箱，不改系统策略或默认快捷方式。不要拖入 Setup 或游戏 EXE。
兼容启动降低子进程隔离保护，仅用于排障；再次直接打开原 EXE 恢复正常模式。
Setup 安装器的 System.dll 崩溃与管理器启动问题分别处理。遇到 Setup 问题可使用完整解压版；本版本不把目标电脑尚未复测的故障标记为已修复。

验证范围
这是一份供验收的测试候选。组件与请求已通过自动化检查，实际画质、帧率和长时间稳定性仍需具体游戏验证。RTX40 游戏内 MFG 与 NR 联合运行，以及此前无法打开的目标电脑，都需要对应设备复测。
