# 允许成熟输入桥回退，NR 主链保持自有 Core

维护者允许在本项目桥接器不能稳定工作时，先用其他稳定桥接器跑通实验，并按需要参考或选用 Luma。复用对象是输入取得、API 传输和兼容能力，主 NR 仍由本项目 Core 执行；已有原生 DLSS 游戏继续现有路线，Opti 不成为默认统一依赖。

BL3 可作为首个实验游戏，但维护者已说明仍在下载；历史 build/EXE 指纹不能当作当前安装可用。Luma generic 的现有 DLAA/R=O 接点只作为内部阶段，真正超分支持必须另外证明 R<O。

## Consequences

- 先接续现存 provider/carrier 与适配代码，不为保持单一技术路线而重复造桥。
- 每个外部组件进入配方前核对来源、精确版本、角色及实际允许的分发内容；采用外部桥不等于采用第三方 NR owner。
- 外部 NR 可以作为明确的对照，但不计为自有 Core 路线里程碑。
- 输入不完整时标明质量等级和未支持项，不把 synthetic guide 或未经观测的 TAA 槽位标成真实原生合同。
