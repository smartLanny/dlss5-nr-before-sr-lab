# 默认采用性能优先的单次强化，多次 NR 仅为实验路线

维护者选择默认继续推荐单次 NR 强化逻辑，并希望在可能时取得更接近叠层的观感；默认单次 NR 相对固定参考版本的 GPU 开销增长上限为 5%。多次 NR 只作为测试选项，第一步限制为两层、相同工作尺寸、单视图，并核实后层采样相位和独立历史，而不从 Reset-only 样本直接泛化为游戏时域级联。

这个选择保留可控的默认成本，同时允许用双 NR 对照研究哪些效果可由一次推理后的有界强化近似。效果相似性仍需证据，不能预先声称单次与多次等价。

## Consequences

- 默认推荐不能通过增加真实 NR 次数实现；实验叠层必须显式开启，并报告额外成本与实际支持范围。
- 后层相位、guides 或历史未验证时，不能用每帧 Reset、盲目清零 jitter 或复用第一层参数冒充连续时域正确性。
- 分割模型同样只可能属于实验功能，当前延期；先研究更直接的人脸 mask 原理与现有开关缺陷。
- 保留既有参考、关闭路径和默认行为，算法增量留在 0.5 实验线；维护者验收前不合入 main。
