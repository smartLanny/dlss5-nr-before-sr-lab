## 颜色与人脸默认

总开关下方仍为“颜色优先｜保守颜色”，下面是 AI 色彩强度。
**新配置或尚未选择颜色策略时默认保守颜色，强度 1.0。**
主动选择颜色优先时，其尚未保存的默认强度为 **0.7**。两种策略分别记住强度。
旧配置已保存的策略、旧 HDR 许可及强度继续按原兼容规则读取，不强制覆盖。

策略决定颜色修改是否获准，强度决定获准后采用多少。两者仍共用现有合成器。
保守颜色对证据不足的 HDR 输入不采用颜色修改；已经允许的 SDR 等输入仍受
强度控制。因此强度 0 不等于过去关闭 HDR 许可，也不是全画面饱和度归零。
游戏显示 SDR 不能证明游戏内部纹理都是 SDR，实际原因以界面和 F8 为准。

每层原生皮肤遮罩和文字/UI 保护默认开启，皮肤结构 0.4、模型强度 1.5。
独立人脸检测另在实验页，默认关闭，与原生遮罩无联动。关闭时不加载检测
模型、不调度新增检测；已经提交的工作仍安全收尾，不承诺瞬间归零显存。
#302 的鸣潮近脸斑点/变暗没有在本包宣称修复。

独立实验；省电缺省关闭，勾选不等于实际暂停。快捷键在开发者页设置。

## 最短测试

1. 先保留现有 INI，确认保存值没有改变。若另建新配置，确认保守颜色 1.0；
   首次切颜色优先为 0.7，切回与重启均分别保存。独立人脸保持关闭。
2. 燕云按原先容易闪烁的场景短测，先保持原层数/比例/模型，闪烁时留 F8。
   双层与单层另作同设置对照，勿同时更改色彩/模型/FG 后归因。
3. 鸣潮 #254 继续只开游戏 RR 与 NR，关闭旧缺投影后置实验，保存修后 F8；
   只有实际 NR 成功和后置采用增长才算接通。原生 RR 安全旁路保留。

掉帧/疑似爆显存时留同次 F8 的 processMemory 与 contextMemory；
一次短采样不是显存峰值，也不等于 NGX 内部历史开销已经全部解释。
