# 当前过测候选改名为0.4.7beta

维护者认为本轮范围不足以命名为0.5，明确要求当前候选改名为`0.4.7beta`，
并要求GitHub同步时保留其他内容的正确性。本次接续已过测的dev16（#215），
只更改当前产品标识，不重新解释历史版本或扩展功能范围。

- INI只改版本注释，所有默认值、既有玩家设置策略、菜单、算法及兼容行为保持一致。

源码审计将新版本文字逆替换后与父提交逐字比较，CPP和INI完全一致。
