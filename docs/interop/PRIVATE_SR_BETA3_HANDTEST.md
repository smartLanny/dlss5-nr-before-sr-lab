# Beta 3 私有 SR：以后手测清单

本批软件验证完成，游戏画质、稳定性、性能仍待测。现在不要求启动游戏，由维护者统一安排。

**默认关闭。首版仅接受原始 jitter 已知且为零的 D3D12 原生 SR 后置输入。**
常规带 jitter 的游戏帧会拒绝，保留原 NR 最终结果；不要修改游戏 jitter 来强行通过。
RR、Present、HDR、FG 及不明队列不进入此路径。已有修改量防闪开启时，私有 SR 拒绝运行，保存的防闪设置保持。

1. 保留旧 Core 包与配置。退出游戏后，只替换一个语言版本的 Core；旧 Core 放到插件搜索目录之外。保留其他组件、模型和设置，记录候选身份。
2. 在原本可用的场景保持私有 SR 关闭，保存基准 F8 和画面；固定分辨率、工作比例、层数、HDR/FG 与镜头。
3. 单独打开“私有修改量 SR”，查看 F8 的 `requested.privateResidualSR`、`requested.privateSR.configurationGate`、`guideReason`、`lastEvent`。
4. 首次创建、资源等待和拒绝都不算生效。只有同一配置窗口内录制、提交、合成/采用计数增加后，才比较静止、移动、停镜与遮挡：细节、文字边缘、闪烁、拖影、颜色及帧时间。
5. 关闭后确认没有新增私有录制，已有资源在 GPU 完成且录制结束后退休；再开启检查重建。遇到卡死、闪退或持续异常，保留首次 F8/同次日志，停止这一轮并回退旧 Core。

非零 jitter 等拒绝记作“当前不支持”，旁路后的高 FPS 不算性能提升。多层总修改量已做受控测试，但真实多层 NR、游戏性能及新增降噪 3% 开销目标都没有通过结论。
