# 0.5.2 Beta 10：补齐多层创建的低内存保护

相对 Beta 9，修复独立后续 NR 层绕过严重提交压力保护的问题。低余量时延后该层创建，保留已有主层工作，避免在已知严重压力下继续调用厂商创建；按父层计数或配置变化重试，不虚报完整多层采用。已有模型与关闭路径不增加这项查询，真实不透明失败的安全隔离保留。

另外减少 R11G11B10_FLOAT 与 FP16 原始颜色切换造成的不必要模型重建：NR 实际输入/输出仍是 FP16 时，保留模型并重置历史。只放行这对浮点格式；资源槽仍按原有格式、身份和完成证明安全更新，其它合同保持严格。

1 GiB 下限不是模型内存预测或所有 OOM 的保证。Beta 9 实机低余量下的错误码为 PlatformError，厂商内部失败分配没有独立证明。Esc 进入动画中 NR 短暂消失、菜单展开后恢复的问题尚未定位。现有重建日志补充具体导引格式及绑定尺寸变化，不改保护；需要动画结束后立即采集的同进程 F8 与时间点，不能宣称本包一并解决。

继承相对 0.5 D21 的既有功能，以及 Beta 8/9 的真实 SR/RR 计时、原生路线报告、首层 RR 绑定、匹配纹理复用、持久化降层安全回收和有界管线缓存。普通均衡恢复仍为建议，现有实验保持独立；关闭的图像实验不创建其资源或提交其 GPU 工作。不修改用户已保存配置或运行库。

重启后的 Beta 9 SR/RR 两套九组各有五组 600 个有效局部 GPU 样本；时域三组仍未采用。私有 SR 整体优势、全面降噪/拖影与整帧成本门槛均未获证明。后置 RR 原生 MV、私有 Feature13、私有 SR 与外部历史叠加仍不准入；失败的四点空间方案不加入产品。

本包构建、硬件与部署结果见随附交付回执。仅供维护者本地验证，保留旧 Core 回退；不启动游戏、不发布在线 OTA、不改 Manager 默认版本。
