## 已完成的实现

- **#2/#202：资源解释与 LDR。** 确定类型、成功原生调用观察和严格唯一合同共用同一解析结果，贯穿准入、创建、复用、重绑和 F8。未知或冲突继续保留原生 SR；已声明 LDR 中的 HDR 专用曝光纹理不再独立造成错误拒绝。
- **#229：typed 曝光与存储精度。** 1×1 typed R8_UNORM 曝光按归一化首通道读取并查询实际能力。PRE/POST 期望值按实际 FP16/R8/R10/R11 UAV 存储解释；量化边界不唯一、参考不可比较和实际输出非有限分别记录。
- **#203：自动恢复与一次 F8。** 新证据在正常调用中取得并触发后续正常尝试，不额外执行 SR/NR。恢复账本关联当前解释、描述符、返回值、实际提交与存储证据；确定失败保持锁存，旧读回与历史成功不替代当前未知。Compatibility Verdict 给出当前阻塞、历史失败、缺失证据和下一步。
- **#223/#107：生命周期与所有权。** 各 NGX 层保留 Create/Evaluate/Release 身份和代次，严格区分外部 Feature 18 与私有 NR。外部所有权、并发变化和失败 Release 维持保护，退休按匹配代次执行。
- **#205：样本与后续 Output 观察。** 后置存储和观察窗口按同一目标与采样身份关联；关闭后的记录保持不变。原生事件、提交回执与未覆盖行为分别显示，现有未知不被转换成未经证实的资源状态修正。
- **RR 判定范围。** 本批技术恢复认证仅覆盖已确认的普通 SR（Feature 1）。已解除的无 Feature 1 身份阻塞回到等待状态；无关通知不能清除已分类失败，切换 RR 也不能借用旧 Feature 1 成功。RR 继续使用现有专用诊断。

## 验证边界

CPU 已执行真实资源/查询函数、生命周期 hooks 与注册表、命令/退休逻辑、恢复账本、Compatibility Verdict 和 F8 序列化的回归。负对照覆盖错误的作用范围、失败清除、旧成功继承、缺失提交/存储证据及历史错误路径；预期失败必须命中指定检查，编译失败不算负对照通过。

WARP 已执行软件 D3D12 的实际 typed 资源读写、R8/R32 曝光对照、PRE/POST 存储、正常/错误目标、量化边界和完成/回收检查。这些测试使用构造输入及模型输出平面，未执行实际 NVIDIA NR 模型，也不能替代游戏 SR 消费、后续处理和最终呈现的验证。

组件和集中源码回归已经完成的项目保持其各自的源身份。统一包最终验收数量、菜单结果和载荷哈希单列于上表；旧版本的游戏通过或失败继续保留原版本归属，不迁移为本候选结果。
