Research candidate, not automatically installed. Exit the game before replacing

## Colour below the master switch

**Colour priority | Conservative colour**, then AI colour strength.
Priority admits unverified HDR colour and defaults to 0.5 for new configurations.
Conservative admits established input contracts and defaults to 1.0. Both use
the existing compositor and remember separate strengths. Explicit saved values
remain unchanged. Policy controls permission; strength controls adoption after
permission. It is not whole-image saturation.

Zero strength disables colour contribution for all inputs. It is not equivalent
to the old HDR permission being OFF: verified SDR could still use colour then.
The old permission remains compatible with saved INIs, without a third editor.
An SDR display may still receive an internal HDR rendering path; inspect actual
status rather than inferring the input contract from the display setting.

## Five pages

- Picture: route, one 50–100% chain scale, 1–5 layers, final extra enhancement,
  and directly visible per-layer controls. New layer defaults: intensity 1.5,
  skin 0.4, native mask/UI protection ON. Sliders commit on release.
- Lighting: three mutually exclusive methods; presets/reset preserve AI colour.
  Reference white requires a matching HDR input path. Edge guard is not an
  anti-halo filter.
- Experiments: N2, RGB candidates, optional face protection and two energy modes.
  RGB still has reported halos. Both energy modes default OFF; enabled does not
  mean paused or saving power.
- Developer: mechanisms and separate NR/image/report bindings, F1–F12 or OFF.
  Duplicate keys are refused; release a reassigned key before using it.
- Feedback: F8 text and F7 current view by default, plus comparison capture.
  Captures can alter transient history/timing; do not use capture time as normal
  performance measurement.
