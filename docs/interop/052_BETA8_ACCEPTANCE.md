## 为什么需要这一批

维护者于 2026-09-28 18:38:58–18:43:06 的异环原生 RR 测试使用 Beta 7 `80dcc999`：九组流程结束并恢复设置，前六组共 18 张图；普通 NR 和私有 SR 的 GPU 有效预热及采样均为零，三个时域组未通过采用。私有 SR 的调用活动不能替代有效计时。静态局部审核没有证明同档私有 SR 明确优于普通恢复，不能据此判断运动拖影。

本次独立源码核对确认两个计时缺口：首次生命周期登记前读取 token，以及真实后置 RR 分支缺少原生调用前后的两个验收时间戳。既有受控宿主没有覆盖这两个真实入口条件；旧受控画质和生命周期证据保留原有范围。

- 计时资源在槽位可修改时准备，NR 登记成功后绑定精确源帧、配置和生命周期身份，再记录 GPU 时间。失败路径保留资源所有权及完成证明要求。
- 原生 SR 与后置 RR 都覆盖四个时间戳；原生 SR/RR 调用本身不计入局部插件区间。此前导引快照和跨队列工作未完整覆盖时，不输出插件总量或整游戏帧成本。
- 准备、时间戳、提交、等待、身份与排除原因分别记录；没有有效样本时也必须能够定位失败阶段。请求恢复模式与实际录制模式分别报告。采用计数明确属于包含预热和异步发布的全组观察，采样期采用保持未验证；计时 complete 只表示 600 个完成 fence 的局部 GPU 样本，截图另需新采用证明。
- 时域拒绝带入口、Feature、源帧、资源归属、生命周期和细分来源原因。后置 RR 原生 MV 继续拒绝；AMDOF 仍缺少深度拒绝，但原有颜色、越界、切镜和残差保护保留。
- 公开 DLL ABI、九组定义、180/600 有效源帧样本、20/60 秒上限及结束/取消恢复合同不变。原生无 NR 组没有插件 GPU 工作，标为不适用。

## 空间实验与冻结门槛

先固定同源 B 和同一组 P/N，比较现有关闭、均衡四点、精细十六点和旧保边恢复，并记录其它颜色与暗部设置。明确区分受控夹具与真实 Feature18 输出。

再固定同一 B/Z，对照原样 Z、精确面积缩小加双线性、载体恒等解码加普通恢复、真实 Feature1，以及唯一新增 B 引导的有符号修改量四点恢复。所有中间图和输入哈希保留。新增候选只使用现有颜色权重、FP32 修改量和相同奇数网格，不叠加锐化、时域、输出高频或第二种补救核。

冻结判定：已知干净真值的有效修改保留 95%–105%；已知真值 ROI 噪声 RMS 至少降低 15%；细线积分对比至少为同档普通恢复 98%，连续性不得变差。近零修改单列。零修改、透明度和区域外必须保持；无效输入回退 Z。无真值的游戏截图不计算跨时刻像素误差。

实验未过门则不添加产品开关，不改默认恢复。通过受控门槛也只允许默认关闭的独立候选；游戏收益和整帧新增成本 ≤3% 仍待维护者证明。


补充已有恢复对照：同一组合成 P/N 在 Beta 7 生成的生产 HLSL 上完成四模式 WARP 测试，运行时编译着色器，未消费预编译 CSO。固定 17×9→34×18、DirectValue、色度强度 0.5、RGB 恢复关闭、暗部保护开启时，边界右侧串扰为：关闭 0.0129395、均衡 0.000488281、精细 0.000732422、旧保边 0.000488281；同时记录了实际模式 flags。180 个完整编解码用例通过。这是受控 P/N 的既有恢复接线核对，不是真实 Feature18 P/N、游戏画质或性能证明。新四点算法失败的判定不因这项对照而改变。
## 单一空间候选的判定

严格逐步 binary32 参考已完成。固定种子 73219、129×97→64×48 的已知真值暗部/文字/发丝夹具中，B 引导四点修改量恢复将 RGB 误差 RMS 从 0.00167104 降至 0.00074749（降低 55.27%），全体有效修改积分保留 98.45%。但细线区域的 **NR 修改量积分**仅为普通恢复的 58.85%，未达 98% 门槛；修改量局部对比超过阈值的最长连续段为 1/47，普通恢复为 10/47，干净真值为 47/47。该指标衡量 NR 修改的保留，不等于原生 B 中的可见线条全部消失。

独立 6sol 图审认为候选更干净、原有可见线条仍在，与上述修改量指标的对象不同。按预先冻结的规则停止此候选，不调阈值、不叠加保护、不添加产品开关。普通恢复保留，私有 SR 继续作为对照。

同帧 Beta 7 B/Z/载体/尾差的离线归因中，暗部文字发丝 ROI 相对 Z 的 MAE：浮点面积缩小加双线性 0.00038141，载体恒等恢复解码 0.00037026，新增四点 0.00008955，已捕获真实 Feature1 为 0.00294860。这里是与 Z 的差异，不是有真值的质量排名；恒等分支是 CPU 浮点及 FP16 存储近似，未声称 GPU 位级一致。真实 Feature1 旧捕获仍属于 Beta 7 源码身份。

原 r1 使用 Python binary64 的结果和误标保留为历史证据；冻结判定采用纠正后的 binary32 r2。人工空间夹具与静态图审不证明游戏去噪、时域稳定性或整帧成本。
