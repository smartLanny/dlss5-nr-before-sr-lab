## 内存证据与归因边界

最后创建前本进程可提交量为 78,245,888 字节（约 74.6 MiB），系统 commit 为 70,682,185,728 / 70,760,431,616 字节。同秒 Windows System Event 2004 报告虚拟内存不足。

00:41:01、即 RR 开启前约 7 分 46 秒，系统已发生一次同类资源不足，提交余量约 22 MB。不能把全部压力归因于 RR、Beta 8 或某个 Core 泄漏；现有证据也不能给出失败分配的大小。物理内存空闲不等于可提交额度充足，以上不是显存账目。

旧 NR 的部分完成 fence 与 ReleaseFeature 成功记录存在，说明退休并非完全未运行。新 RR 创建时旧 SR 下的全部实例是否已释放、厂商缓存和其它系统占用的贡献，仍需独立证据；不以本报告宣称已查明增长来源。
