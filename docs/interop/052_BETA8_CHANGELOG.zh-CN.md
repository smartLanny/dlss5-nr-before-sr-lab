# 0.5.2 Beta 8：相对 0.5 D21 的更新（维护者测试候选）

维护者测试候选；游戏画质和整游戏帧新增成本 ≤3% 尚未通过。准确源码、验证与安装状态见随包 DELIVERY.json 和 Beta 8 验收记录。

## 本轮变化

- 修复一键验收的真实入口计时：资源准备与生命周期绑定分开，后置原生 RR 补齐计时区间。没有有效样本时记录具体失败阶段，避免把调用成功误当采样成功。
- 补充时域拒绝的来源与调用身份；缺少同源证明继续拒绝，不放宽原生 RR 运动向量准入。
- 记录请求和实际恢复模式，区分局部插件 GPU 时间、完整处理成本与整游戏帧时间。九组按钮继续按有效源帧预热、计时和截图，结束或取消恢复设置。
- 对照已有均衡/精细/旧保边恢复，并独立验证有符号修改量空间恢复。新候选虽降低合成噪声误差，但细线 NR 修改保留未过门，已停止该实验，不加入产品或新增开关。

## 从 D21 延续

保留独立的一至五层 NR、整链一次工作比例、光影/颜色和暗部设置，以及 Beta 7 私有 SR 的奇数网格、微量与零修改保护和 AMDOF 实际分配预算修正。私有 SR 与外部时域互斥；普通恢复保留基线身份，私有 SR 没有普遍质量优势的证明。

已有私有 SR/时域实验保持候选规定的默认值，现有 INI、jitter、运行库与 Manager 默认组件不自动改写。工具不切换游戏 SR/RR/HDR/FG。私有 Feature13、跨 RR 修改量与 NVOF 不属于本次新增能力。游戏由维护者测试，先异环、2077 最后；保留 Esc/切镜、Present、地图省电和多层暗部验收。

D21 比较起点：`cbfb33919696a2840ed5154c91abaea56228b661`。Beta 7 原包及回退保留；本轮不合 main、不发布在线 OTA。
