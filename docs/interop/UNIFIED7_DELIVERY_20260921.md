## 实际改变

1. **持续运行时切换与关闭防闪**：回收依据防闪自己的录制引用、提交、最后完成
   凭据和 P1 描述符租期，避免无关 NR 新录制一直阻止旧防闪实例退出。
   保留提交到 Signal 之间的占用、仍可重放列表、未完成 fence 和隔离保护。
   Reset/Present/维护入口可处理关闭及离开后置路线，不依赖下一次防闪 Prepare。
2. **原生运动**：在原生 SR 可能改变输入之前保存安全快照，支持合法同尺寸 MV。
   必须有实际尺度、相位、区域、源帧及设备/队列证据；F8 区分未提供、无效、
   当前接线不可用和实际采用。默认回退尺度不能取得有效身份。
3. **所有后增强入口 25–100%**：原生 SR 后置、RR 后置及独立 Present 的配置、
   UI、生成器、采集和 Manager 合同一致。前置仍为 50–100%，新默认仍为 100%。
   各层统一实际对齐尺寸，整链乘一次；不能把像素数比例当成总显存/帧时收益。
4. **Reset 因果记录**：实际成功主/辅助 Evaluate 按层记录来源、代次、连续历史
   和有界原因事件。该 schema 的位 64 是 RR 占位深度；曝光延迟另记。
   本批没有放宽 Reset、游戏导引或未知状态安全规则。

防闪仍只接入可证明来源与队列的 DX12 原生 Feature1 SR 后置 SDR。
前置/RR/HDR/Present/Provider 可运行其原有 NR，但没有因此获得时域稳定器。
防闪关闭时不新增该功能的捕获/推理；NR 运动代理缓存、NGX 内部历史及驱动
分配不属于本功能纹理账目，关闭不保证进程总显存立即回到首次开启前。

### 更正 unified6 的过强表述

旧模块/内部 Detach 夹具没有证明生产 Core 可以取消未提交 NR 或自动恢复
NR 列表重放。Core 最外层会隔离这些工作，本批保留该边界。
合法持续帧的切换/OFF 回收与不安全操作的隔离分别验证；不能把防御性
Signal 凭据修补写成已经证明的游戏 UAF 修复。旧交付文档和交接已加更正。
