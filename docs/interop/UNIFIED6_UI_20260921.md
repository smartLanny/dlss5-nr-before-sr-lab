# unified6：残差累积首包

五个页面、原有颜色策略、模型参数和统一尺寸规则保留。新防闪默认关闭。
保守颜色仍为新配置默认；颜色优先独立默认 0.7。已有保存值不覆盖。

## 实验 → 残差防闪

- 关闭：不准备新光流、时域历史或防闪调度。已有工作等实际完成后安全收尾。
- 原生运动：读取已经准备且来源、单位、相位可证的原生运动图；缺证据则不执行。
- AMDOF：对未增强基底估计运动，与模型自己的导引分开。
- 整链：稳定整条链相对原图的最终修改。
- 后续层：第一层按现有最终合成规则生成锚点，仅稳定后层相对它的新增修改。
  不重跑第一层；会额外合成 P1 并保留一张纹理，不代表更省算力。
  单层或锚点缺失时保留当前候选，不自动切换范围。

首包只接 **DX12 原生 SR 后置、可确认的 SDR 域、同设备且同队列**。
前置、RR、HDR、身份不明的 Present 暂不执行本稳定器；原有 NR 路线仍按既有逻辑运行。
只有选择开关不算已经执行，查看实际状态及 F8 的 temporal.submitted 增量。
原生运动需要 Core 已准备的非 jittered 运动图，并非所有游戏都满足。

基础权重按真实源帧间隔变化。0.65 是可靠性先验，60ms 是半衰期参数，
对应 39ms 有效半衰期；不是固定混入 65% 历史。超过 250ms 重种。
预热、镜切或匹配失败不累积旧修改。开发者页保留固定 0.5 历史权重对照。
尚未加入 Adaptive、累积+、低频重建、HDR、NVOF 或私有 SR/RR。

## 短测试

1. 原设置防闪关闭运行，确认 NR 实际连续采用。保留相同层数、模型和尺寸。
2. 在支持的后置 SDR 路线依次试原生运动、AMDOF；双层再比较两种范围。
   看静止纹理、转头、横移、遮挡显露、切镜；同时观察闪烁、拖尾和细节。
3. 关闭再开、改变层数或工作比例。记录同次 F8、帧时间和显存 Usage/Budget。
   保留已完成工作不等于立即回收全部模型内存；槽满/预算不足会拒绝新增防闪。

F8 区分录制与提交，提交不等于 GPU 完成；纹理和 SDK 账目不等于进程总显存。
燕云 #246 仍需修后 F8 才能确认接入修复；本功能不代替缺失的游戏证据。
鸣潮 RR #254、99%/100% 色差、RGB 亮边和 RR+FG 性能不因本包自动记为修好。

## 安装及回退

退出游戏后备份并替换一份 Core 与配套 nrchain，保留 INI。完整人脸后端随包保留，
独立人脸和两个省电模式的新默认仍关闭。附带 AMD SDK 许可证；无需额外安装 AMD 驱动。
异常时退出游戏，移出本批文件并恢复 unified5 原包及原 INI。
开发方未自动安装、未发布稳定版。Windows、WARP、受控 NVIDIA、游戏结果分别登记。
