# 0.5.2 Beta 2 panel candidate

This local candidate depends on the unmerged #308 Beta 1 branch. It does not
integrate #313, change rendering algorithms, defaults or saved settings, or
claim that Beta 1 game acceptance has completed. Its distinct Beta 2 identity
keeps new binaries separate from the published Beta 1 hash and game evidence.

The main panel now reads the actual display version. ReShade's add-on list,
the PE resource and generated package identity use the same release identity,
with the exact build identifier retained in feedback. The old fixed 0.5.1
panel title and uniform3 add-on name no longer identify a later generated build.

Experiments / Colour comparisons uses two adjacent choices for model input
and three for recovery. Each button has its own bilingual tooltip describing
the operation, history behavior and experimental/diagnostic limitations. The
same configuration fields and single edit transaction remain in use.

Slider, track and active colors follow the user's ReShade theme. The local
NTE theme adjustment is recorded separately from this Core candidate.

Validation and delivery receipts are recorded by the canonical
scripts/build-unified-candidate.ps1 run. Source checks, complete compilation
and game acceptance must be reported separately. No public release or Manager
pin change is part of this task.
