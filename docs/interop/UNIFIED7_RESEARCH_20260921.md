# 三方研究的实施记录：unified7

报告中的字符串用于寻找合同，不能证明算法、实际运行路径或收益。
当前五层同尺寸、暗部保护、编译期颜色 shader、原生 UI 参数及预算检查已经存在；
不能再把它们作为待新增能力。以下研究与普通画质默认分开。

## 颜色：实际存储后的微小编辑

`validate-colour-nonzero-gpu.py --research-matrix` 在最终生成的 EncodeV2/
CombineV2 上运行，采用实际 FP16 P/N，观察 100/99/75/50/33/25%、
AI 色彩 0/0.7/1、三种恢复模式，包含暗部渐变、饱和色阶跃和 HDR 高光。
810 组观察覆盖零编辑、微小正负编辑和正负色彩修改，奇数子区为 257×129。

GPU 检查验证有限值、alpha、来源/输出子区及实际存储；错误来源偏移必须被
负控发现。微小编辑可被当前保护减弱，不强行要求超过大编辑的阈值。
记录实际修改量，不把数值检查通过改写成画质优胜。

在 `ae4afb9b` 的受控 NVIDIA 检查中，暗部微小编辑的最大输出变化约
0.0000343；该输入未复现暗部巨幅跳变。HDR 和饱和边缘仍须按域和输入能量
解释幅度，不能跨域比较绝对 RGB 数。该试验没有真实 Feature18 输出、
曝光时间序列或原生 SR 的 O，不能关闭 99%/100% 或 RGB 光晕问题。
不新增保护滑条，也不替换合成算法。

## Reset：成功 Evaluate 的独立统计

`nr_reset_observation.h` 在现有锁下记录实际成功主/辅助 Evaluate，按五层
分别计数，保存最近 32 次 Reset 及最近成功调用的来源、实例、模型/配置/历史
代次、实际尺寸和连续历史长度。不新增每帧 GPU 读回。

此 schema 的原因位是 1 创建、2 游戏、4 历史、8 颜色、16 导引、32 重试、
64 RR 占位深度。曝光延迟单独计数；`sourceToCanonical` 是该调用实际采用
的缩放，不冒充来自游戏曝光纹理的同步读回。失败 Evaluate 不计为连续成功；
其他 Reset 枚举不能用同一张位表解释。
仅增加观测，尚未放宽游戏 Reset、导引或未知状态规则。

## Preset：只比较有证据的 0

Opti v0.8.4 的 Config.h（blob `51906c6572cf49df803475d15a06fa161e5fcb2a`）
将 DlssNrPreset 默认设为 0，创建前再写入 `DLSSNR.Hint.Render.Preset`。
这足以支持未指定/显式 0 的对照，不能支持扫描任意值。

`validate-nr-preset-observation.py` 在现有完整 Core 的受控 Feature18 宿主中，
用实际 Create 参数块各运行两次并核验参数读回、实际 P/N/E 字节。
不修改产品默认、签名或菜单。宿主固定单层、相同模型和 SDR 输入，
占位导引且强制 Reset；进程用时包括启动/捕获，不是纯模型 GPU 用时。
结果由独立 observation.json 登记；相同输出只说明该条件下未观察到差异。

最终 `a627f28b` 完整 Core 的四个独立进程已完成：实际 P 一致，两组 N
分别可重复，未指定和显式 0 的 N 字节相同。不能由此宣布键无效或所有模型
档位等价；本包继续不设置此键，不加入普通菜单。

## UI：保留现有探针，区分四件事

- `nr_optional_layer_probe.h` 已区分 getter 不存在、读取错误、成功空值、
  成功非空；NGX 边界未提供不等于游戏或 Streamline 没有 HUD 层。
- `nr_source_frame_runtime.inl` 已处理 `DLSSG.HUDLessSubrect` 等来源证据。
  指针存在仍不是可安全使用的格式、状态、帧身份或寿命证明。
- `DLSSNR.UICorrection` 是模型创建参数，保留逐层默认与类型检查。
- 原生皮肤遮罩和独立人脸检测属于不同机制，不联动。

真实带 HUD/HUD-less、UICorrection 开关的同源模型输出比较仍待对应捕获。
本批不根据字符串切换输入图或声称 UI 保护效果已经量化验证。

## 自有纹理寿命：先确定消费者

| 资源 | 首次写入 → 最后读取 | 本批处理/后续边界 |
| --- | --- | --- |
| slot.source 未增强基底 | 合法捕获/快照 → 最终合成、时域及捕获 | 不借给会覆盖基底的中间层 |
| slot.proxy / neural | 输入准备 / Feature18 → 下一层与最终消费者、P/N 捕获 | 先列实际消费者；模型历史不混用 |
| slot.result | 合成 → 防闪/写回/采集 | 私有传输实验允许 Encode 后单独 Compose 回 Z，不能同 dispatch 读写 |
| motion_proxy | 原生调用前快照 → NR/稳定器及重放 | 防闪 OFF 不代表 NR 所有导引缓存都释放 |
| edit_field / edit_horizontal / lanczos_intermediate | 对应恢复 pass → 下游恢复 | 只有最后消费者与描述符租期已完成才考虑复用 |
| 辅助 spatial 的 input/second/delta | 各层输入/输出/累计残差 → 最终选择及采集 | 同尺寸路径已有部分免残差，不假设每张 delta 都无消费者 |
| 稳定器 originals[2] / residuals[2] | 源帧更新 → 下一源帧累积 | 四张独立历史，不能与 NR 或私有 SR 历史共用 |
| 稳定器 snapshot / first | 当前候选 / P1 合成 → 当前稳定 dispatch、列表重放 | first 仅后续层使用；保留 P1 描述符租期 |
| 私有 carrier / tail | 最终编辑编码 → 私有恢复/最终加回 | 纳入新增峰值；FP32 尾差不等同于已做时域处理 |

本批修复防闪实例被无关 NR 新录制长期阻止回收，不宣称已完成整链临时缓冲池
或减少模型历史。活跃、退休、隔离与进程预算分别记录。借用游戏 SR 资源仍需
格式、访问、尺寸、最后消费者和保留 B 的独立证明。
