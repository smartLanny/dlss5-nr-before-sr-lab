# unified9 菜单与短测试

顶部固定显示版本、实际状态、路线和尺寸。操作在五个平铺页面内。

画面：NR 开关 → 处理顺序 → 颜色优先/保守颜色 → AI 色彩 → 工作量 → 最终增强 → 各层参数。
新层原生皮肤遮罩/UI 保护开启、皮肤结构 0.4、模型强度 1.5；保存的旧值不改写。

光影：普通亮暗、精细分区、修改类型三个方式互斥。普通亮暗的大范围增亮显示旧 Broad×(1−Glow) 的实际乘积；只查看不改 INI。编辑该控件才统一为单倍率。光影预设、重置、撤销不改 AI 色彩。
旧版分项在已保存开启时直接显示于光影页，可退出并撤销；其数值保留，不偷偷迁移为另一算法。开发者页不再重复编辑明暗倍率。

低分 RGB 的普通插值/边缘引导配对是空间恢复实验，不是双层 HDR 或防闪；旧 D21 合成与同尺寸情形不采用该低分实验。运动量换算仅影响兼容入口，既不生成运动，也不选择 MV/光流后端。
额外增强软限制、颜色增益保护与始终存在的数值/色域边界不同；不保证多层模型本身的过饱和被消除。

RR 缺投影候选新配置/缺字段默认开，明确保存的 0 保留。仍需安全来源/资源，只有投影缺失允许占位深度并逐帧 Reset；不可读/不支持投影仍旁路，原生 RR 不变。勾选不等于 NR 已采用。

短测试：
1. 切五页核对顶部；在窄窗口调整比例和两种颜色强度，松手应用后不回跳。
2. 检查各层 mask 保存、重新启用与重置；旧层关闭值应保留。
3. 普通亮暗选择预设，大范围倍率应对应变化；AI 色彩不变。已有旧组合可退出并撤销。
4. 集中验收后检查 TXT 关联与配置恢复；文字完成不再被要求同时完成图像归档。

游戏测试由用户继续。此包不声称修复 99/100 色差、闪烁、爆显存或新增防闪/私有 SR 路线。
