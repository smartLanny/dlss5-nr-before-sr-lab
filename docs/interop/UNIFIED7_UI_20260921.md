# unified7：切换回收、原生运动与后增强 25%

五页菜单与每层独立参数保留。后增强的统一工作比例现在可选 25–100%，
涵盖原生 SR 后置、RR 后置和独立 Present；前置保持 50–100%。比例整链只乘
一次，各层同尺寸。显示对齐后的实际工作尺寸，不能把 25% 理解为总开销只剩 1/16。
旧配置保留，新配置仍为 100%。

## 实验 → 残差防闪

默认关闭；原生运动与 AMDOF 明确选择，整链与后续层明确选择。后续层需要
至少两层和有效第一层锚点；缺失时保留当前安全候选，不自动切换范围。
切换等待期间继续使用当前 NR 结果。已提交工作、仍可重放的列表和隔离工作
不会因为关闭开关就提前释放。

本包防闪仍只接 DX12 原生 SR 后置 SDR、同设备且可证明队列的入口。
新增同尺寸原生 MV 的安全快照接线；单位、相位、区域及帧身份不满足时仍拒绝。
界面/F8 区分未提供、无效、接线不支持及实际采用。AMDOF 不替换模型导引。
前置、RR、HDR、Present 和外部 Provider 的 NR 仍按既有逻辑运行，
但尚未采用本稳定器。私有 SR/RR、NVOF、累积+和低频重建尚未开放。

关闭态不启动新的防闪计算；回收仅针对本功能资源。运动代理可能由 NR 导引
继续缓存，NGX 模型历史也不属于防闪纹理账目，不能据此预期总显存立即清零。

## 短测试

1. 保持原有模型、层数、颜色和 FG，防闪关闭。后置依次选 100%、50%、25%，
   检查保存值不回跳、显示实际尺寸正确、NR 持续执行。尺寸或预算不满足时记录原因。
2. 在支持的后置 SDR 路线依次选原生运动、AMDOF、关闭；双层再切换两种范围。
   连续操作后查看实际状态，观察横移、转头、遮挡显露、切镜的闪烁、拖尾和细节。
3. 同工作量比较关闭/原生/AMD，并保存同次 F8、帧时间及进程显存使用量/预算。
   不把 25% 与 100% 的差异算成同画质性能优化。

F8 的 `resetObservation` 记录实际成功 Evaluate 的 Reset 原因、源帧和历史长度。
该枚举的 64 表示 RR 占位深度；曝光延迟是独立字段。此项不改变 Reset 策略。
提交计数不是每像素采用历史、GPU 完成或游戏验收的证明。

## 默认与回退

保守颜色默认 1.0，颜色优先独立默认 0.7；保留保存值。独立人脸、防闪及
两个省电模式默认关闭。完整人脸后端保留，原生皮肤遮罩与它无联动。

退出游戏后仅替换一份 Core 和配套 nrchain，保留自己的 INI。包内模板仅供
首次安装；旧文件备份放在插件搜索目录外。异常时退出并恢复 unified6 包和原 INI。
开发方不自动安装或发布稳定版。#246/#254 仍需对应游戏修后 F8；本包不能据
菜单或受控测试宣称游戏闪烁、99%色差、RR+FG 性能或显存问题已经解决。
