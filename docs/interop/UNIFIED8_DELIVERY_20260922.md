# unified8：集中验收与有限防闪扩展

研究目标继续为 `next/0.5`，由 #294 协调、草稿 #300 集成。没有安装游戏或发布稳定版。
完整构建源码：`5c10a0b72dbe68b0285fe1db0a316db33b065e1c`。
二进制显示 `beta0.5-dline21-unified8`；后续文档提交不改变这一构建身份。

## 本包实现

- 反馈页增加集中验收：当前设置基准、颜色/比例、原生/AMD 防闪三组方案。
  临时配置不写 INI、不切模型；实际采用、至少三秒及 Reset 后 64 次成功评估后计时。
  每组计时 20 秒，文字报告和可选深采随后执行；取消或停止 Present 会恢复设置。
  旁路、预热超时、换实例、缺失采集和记录容量不足均保留原因，不自动判画质通过。
- 前置深采增加同一次原生 Feature1 输出 O，保留旧四平面文件并附 JSON/NRO。
  源帧、配置、区域、命令记录、队列与真实完成凭据必须匹配；未知状态明确缺失。
  O 是原生存储位，不宣称已知 transfer/primaries。P/N/E 沿用旧采集定义，跨阶段
  比较仍须核对采样网格、曝光与颜色域，不能仅用格式名推导线性光度。
- 9 个辅助着色器入口改为构建时编译：Present 5、双层空间处理 2、导引快照 1、
  RR 深度 1。保留真实 PSO 创建，并分别统计辅助编译、PSO 与模型 Create CPU 时间。
  其他区域/人脸着色器不在这九项内；不宣称整个 Core 已无动态编译。
- AMDOF 新增有限前置 SDR 整链及 RR 后置 SDR 整链/后续层入口。
  原生 Feature1 后置 SDR 仍支持原生 MV/AMD 两种后端与两种范围。
  具体格式、区域和最后消费者要求见 [路线合同](UNIFIED8_TEMPORAL.md)。

所有模型与颜色默认不变：保守颜色默认 1.0、颜色优先独立 0.7；旧值保留。
防闪、私有重建、独立人脸、两种省电默认关闭。一至五层共用一个 WorkingScale，
后置 25–100%，前置 50–100%，不因本包减少实际模型工作量。

## 模型、颜色与资源研究

两套 NR DLL 按显卡适配使用，取消 DLL A/B。受控 NVIDIA 检查固定本机适用的
310.8，SHA256 `e16bcf15e16e13f527491cdf7845b2fe6521a738d8f7c9c721866a8496e1fc8e`。
参数 A/B 仅指同一模型内的一次强度设置变化，不是模型文件对比。

模型创建签名/退休与导引 Reset CPU 15 项通过；真实调参输出结果单独登记。
既有非零颜色研究覆盖 100/99/75/50/33/25%、AI 色彩 0/0.7/1、暗部、饱和边缘、
HDR 和 FP16。默认颜色算法未改；不宣称 99/100 色差、RGB 亮边或纹理差距已修复。
Preset 已有明确取值对照保留，不扫描未知值，不新增普通菜单。
HUD 稀疏探针不等于逐帧供给率，UICorrection 不等于保证每个游戏 HUD 不被处理。

[自有缓冲寿命审查](nr_owned_scratch_lifetimes_20260922.md)未发现可立即证明安全的
新增合并。后层已有直接输入共享；同时仍使用的 raw/source/result 与不透明模型引用
不合并。新增显存节省记 **0**，不借游戏 SR 资源，不混用模型/光流/私有 SR 历史。

原生 O/新增时域各自的人工场景与真实模型试验不能替代真实游戏运动、RR、FG、HDR。
本次真实模型宿主仅覆盖前置SDR，RR后置仍为构造模型/原生帧的WARP证据。
CSV 是 ReShade 回调间隔，不是显示/补帧 FPS；显存为进程使用量/预算的每秒采样，
采样峰值不是精确峰值。CPU 计时不等于 GPU 推理时间。NR 成功不自动等于最终画面采用。

失败记录保留：初次导出缺辅助工具，以及早期导出/UI 接线和依赖集合夹具错误。
已补实际生成工具存在性测试，并从独立生成目录编译成功全部九个辅助入口；
最终完整构建使用新目录，没有手工补文件后冒充可复现生成。

另保留真实冷热测试首轮失败：宿主在切参数后漏调正常的上下文 Collect/Drain，
旧实例已完成却停在待销毁表，后续创建被正确拒绝。私有夹具补上原生产维护调用后
六进程通过，未放宽任何生命周期检查、未修改生产代码。测试源码修正另作后续
提交；二进制与全部生产输入继续固定为上述构建提交。

冷热实际结果：A=1.2、B=1.7，六进程、每段十张完整 FP16 N；两次 A→B→A 均
创建三个实例并释放两个旧实例。80 组完整平面对照逐字节一致，包括50组重复设置
和30组冷热比较。本人工低变化场景中 A 与 B 本身输出也一致，因此不证明强度
效果、一般收敛或所有参数有效，详见 [模型边界](UNIFIED8_MODEL_BOUNDARIES.md)。

与 unified7 对比，26 份核心 CSO 及完整 HLSL 哈希全部相同；旧 810 组颜色研究结果
作为同一 shader 的既有证据保留，不记成本轮新跑 810 组，更不冒充真实模型画质通过。

## 明确暂缓

- 前置原生 MV、前置后续层、RR 原生 MV 与 HDR 时域：相位、P1 或颜色域合同仍缺。
- 私有残差 SR 未接 Core，不展示可用菜单。本轮实验分支 `013a5a76` 对已有五例真实
  NR→私有 SR 输出分类：均为有限 FP16 小越界，越界像素约 0.35–1.11%；没有改写、
  统一夹持或大量回退像素。七项 CPU 与六类共 30 项派生负控通过。这不是输出质量
  通过；真实运动、遮挡显露、导引相位、连续历史与最后消费者仍缺。
- NVOF、#259 前置旁路、#258 跨 RR、私有残差 RR 留到后继阶段。
- 燕云 #246、鸣潮 #254 仍需对应游戏修后 F8；本包新增 RR 防闪不等于修好了 RR 接入。
