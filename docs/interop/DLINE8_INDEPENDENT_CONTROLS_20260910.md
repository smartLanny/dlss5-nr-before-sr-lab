# D8：独立画质控制与有界兼容反馈

接续D7，维护者要求额外增强移到模型强度下并使用1–4范围，Jitter旧设置统一
关闭一次，优先核验原模型脸区复用。最新实机反馈将异环人脸响应问题明确关联
到整体细节调整；维护者同时暂停合并，D继续独立完善反射及各类分离控制。

## 本次落实的运行时变化

额外增强只改变用户控件与持久偏好迁移，不缩窄内部零效果数学、诊断或F6
旁路合同。旧小于1的值迁到1；旧零值先保留关闭意图，再发布新值和完成标记。
模型强度、局部明暗、整体细节、Skin和既有七参数基准/撤销保持各自语义。

Jitter使用独立一次性版本标记，旧偏好和新默认关闭NR传递。完成迁移后手动
开启1必须跨重启保留。标记最后写，失败记录明确状态；不反复在配置轮询或
诊断恢复中覆盖本会话手动值。原生DLSS参数及既有后置零Jitter合同不变。

兼容回退仍只在四个已有前置Color准入出口产生。新增明确原因分类与校验，
禁止未知原因或已活动前置再选择后置；后置仍独立准入并等待原生SR成功。
UI使用同锁快照区分尝试和近期记录、说明原因并提示F8；F8同步记录分类。
本版不放宽队列/命令状态/生命周期/外部NR所有权，也不声称新增通用后置回退。

## 人脸证据与未完成能力

两包各9组完整、实际参数一致，T全程为1。原设置为后置1.78/1.64/1.77，
恢复默认后为前置1.2/1/1，跨包存在路线和网格变化。各包内部基准Off/On0
响应明显，Tone2和Structure2响应减弱，变化已见于同次模型输入/输出平面。
单次首尾重复只是漂移参照，不是噪声界限；不得断言模型内部mask消失。

目标脸区应保持同次模型结果的1倍完整合成C(1)，脸外采用C(T)，包括颜色
预算，而非只改亮度倍数或把脸恢复成原图。现有AutoMask/Skin是模型控制，
尚无可复用输出遮罩合同。第五RAW平面、被写成1的采集alpha以及顺序差分都
不能充当脸区。可靠遮罩未取得前，不发布脸区隔离有效的承诺，不自动替换
维护者报告在2077中稳定有效的模型机制。

匹配310.8运行库的有限CPU参数组装核验显示：AutoMask开启、Skin非负时，
Skin与LocalStructure仍共同进入人物相关派生控制。此依赖支持继续按整体细节
触发条件调查，不能提升为已读取GPU遮罩或已确定模型缺陷。没有获得可复用的
空间遮罩类型、内容或生命周期合同，故本轮停止运行时脸区接入。

低成本离线比较已覆盖全部18组同帧proxy/NR输出及后续显示图，生成30张图和
逐样本哈希、计时。肤色候选在原proxy人工脸内块覆盖94.98–99.63%，但也选中
手、暖背景和UI；以NR后颜色分类最低仅18.75%。YuNet默认阈值0.9全漏，一次
降低到0.6后全屏缩图检出主角及UI肖像，512区域仍全漏。原输入全屏未采集，
不能将较晚显示帧的脸框移用到RAW，也不能把同一角色18帧当成泛化基准。
候选均未接入产品；CPU离线耗时不是GPU或游戏帧预算。

当前有明确语义的模型画质控制仍是已公开的强度、局部明暗、整体细节、皮肤、
风格、AutoMask及界面保护。其他资源/配置键未形成独立反射、材质或光照强度
合同，不据名字添加虚假旋钮。私人图像、第三方模型和反汇编证据留在私有区。
YuNet固定官方提交`47534e27c9851bb1128ccc0102f1145e27f23f98`、MIT模型，仅用于
离线比较，不作为本项目产品依赖。
