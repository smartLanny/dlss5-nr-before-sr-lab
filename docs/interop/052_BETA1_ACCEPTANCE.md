# 0.5.2 Beta 1：导引输入检查候选

本候选接续已整理的0.5.x main与#308，保留0.5.1 UI1全部颜色、光影、
多层、人脸、AMDOF、退休保护，以及「低分辨率细节增强／均衡／精细」
和独立「去除暗噪」。没有改变这些画质算法、模型参数或保存配置。

## 实际变化

空渲染/工作尺寸在读取资源前拒绝；MV.Scale按原有N/R换算之后，再检查
是否为有限、非零数值。异常输入保留原生输出，不永久隔离后续合法帧。
状态明确提示按F8提交反馈。F7补充图像包的frame metadata新增guideDomain，
区分渲染网格、NR工作网格、MV存储/有效区域和实际换算；不推断为原生引擎
导引，不新增GPU读回。原有N/R换算、正负方向和有效值运算顺序未改。

本补丁针对构造的边界条件和可检查性，不宣称已修复某位玩家的脸部黑点、
GPU利用率或闪烁。去暗噪仍只稳定最终结果中极暗候选在高增益下不可信色度，
保留已选亮度；不是逐层时域滤波，不保证消除纯黑亮度斑点。

## 版本与交付

运行时身份0.5.2-beta.1，界面0.5.2 Beta 1，PE 0.5.2.1。
完整流水线保留累计验证、双语/人脸/AMD、重建UI/WARP，以及原始与最终生成
导引函数的正例、三种反例和真实JSON序列化检查。打包必须检查最终导引证据
与Core/类型/serializer的哈希，缺失、过期或反例没执行都不能生成游戏包。
源码与包装SHA、文件哈希以对应build-info.json/发行清单为准，不重标旧UI1。

本文件初次提交时整包验证待执行，不能据此推断已编译、已发布或已实测。
后续实际结果见#308与完成回执。测试用受控数据不等于真实模型或游戏验收。
托管CI未启用，不记为通过。UI1只经过初步试用，也不是全面验收基线。

## 人工必须完成的最小验收

退出游戏后备份旧Core及桥接到搜索目录外，只保留一份语言Core和本包nrchain。
保留原INI、ReShade和适用显卡的NVIDIA运行库。D3D12不额外安装DX11 carrier。
本候选不自动部署，原UI1和Inbox1作为回退保留。

先选一个原生SR游戏、一个原生RR游戏，同场景同配置：NR关闭→单层100%→
99/70/50%，再两层。检查没有持续guide-contract-invalid、黑帧或NR无效，
颜色、光影与原版本一致。两项新画质开关各自对照，不同时改模型/比例/FG。
随后分别检查HDR、FG、窗口尺寸/DRS变化、F6及退出。视频与F8保留同次进程。
F7补充采集应能解析guideDomain，包含R/N及MV源区域；采集开销不计入帧率。

失败时退出恢复备份并提交F8及简短复现。持续旁路必须反馈，旁路高帧率不是
性能提升。记录实际整数尺寸、模型/驱动/显卡、层数、路线及Core哈希；旧Perf10
或不同进程/场景记录不能当本候选验收。无需为本边界检查重新录全套历史矩阵。

## 与未完成研究的边界

脸区识别、性能/VRAM按原Issue分别验收。NAS第二份备份与两处目录链接仍需
本地权限处理，不能为完成清理绕过工具访问限制。
