## 已实现的组合行为

1. 保留一至五层独立参数、Feature/参数块/历史；整链一个 WorkingScale，各层同尺寸。前置以原生输入为基准，后置以重建输出为基准。旧辅助比例归档并提示工作量变化。
2. 合入辅助实例历史复用与父子退休：同创建合同的历史变化只请求 Reset；真正的尺寸、模型或输入合同变化仍退休。每个子实例用自己的录制、提交、fence 和绑定判断释放。
3. 显式不带回性能支线已撤回的唯一 wrapper 猜测映射；Core 身份仍须现有可靠的对象/代次证据。
4. 提交批次中，仅对准确缺少生命周期 token 的 Direct 列表省去一次接口查询；保留队列学习、各独立消费者和不确定回退。32 条有界提交诊断不挤占现有事件记录。详见 `SUBMIT_BATCH_20260920.md`。
5. 每层“默认｜自然｜电影”横排三段单选。拖动只改变预览，松手提交；强度直接显示，细调折叠，单层重置保留整链设置。
6. 常用页顺序为启用/状态、处理顺序、统一尺寸、层数/参数、最终增强、AI 色彩。高级光影和参考白归组，颜色机制研究折叠；活动预览仍能看见和退出，F7/F8 集中反馈页。
7. 两种省电缺省关闭，保存的 INI 不改写；实验页分别显示等待、确认、暂停和恢复，不能用勾选状态宣称节能。
8. 颜色保持 quality1 默认，旧 RGB 保存值保留并提示回归；N2＋旧合成仍为实验。完整人脸后端要求固定 ORT、模型和许可证，禁止把无后端构建混作完整包。

## 已识别而未宣称修好的问题

- 当前没有实测游戏整帧/FPS/显存下降数字；无 NR 采用的高帧率不算通过。
- 旧 99%/100% 色差、RGB 非零亮边与人物结构差距分别验收。CPU 数学和受控 GPU 编辑不替代真实模型 N，也不替代游戏原生 SR 后的 O。
- `PrepareContextUseLocked` 的等待仍有保护语义。等待前已有来源/导引录制和借用资源，不能直接在函数内解锁；具体两阶段准备和占用凭据方案见 `UNIFIED_FENCE_WAIT_CUT_20260920.md`。没有证据证明当前存在可直接修正的 native/proxy 映射丢失。
- 冷启动 #293、切镜恢复 #296、显存 #298、性能 #277、颜色 #274 保持独立。没有关闭功能缺陷 Issue 的授权性结论。
- 此版本尚未接入实际私有 SR、跨 RR 编辑或 AMDOF 残差累积。它们默认关闭的要求不等于功能已经完成。

## 下一实验顺序

先完成本组合的构建与同工作量 Q/Q＋P 对照，再按顺序接入重建后低分残差私有 SR、#259 前置残差旁路、#258 跨 RR 编辑。共享真实源帧、颜色、区域和生命周期设施；原生重建保持一次，私有 SR 是额外独立调用，整链最终恢复一次。

AMDOF 使用未受增强结果污染的原始输入；镜切、无效运动和预热期间不累积旧残差，重复 FG 呈现不推进历史。先修实验后端的有界退役再接 Core，模型/光流/残差/SR 历史互不覆盖。独立路线先验收，再组合检查拖影、显露区域、细节和成本。D22 独立验证兼容入口，不当作 RRFG 调度修复；不扩展独立全图 RR 后端。
