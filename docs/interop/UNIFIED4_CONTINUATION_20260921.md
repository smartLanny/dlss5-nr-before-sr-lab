# unified4：颜色入口、快捷键和运行证据

继续 #300 / #294，完整统一后继计划不变。此文记录实现，不替代最终构建回执。

## 颜色与菜单

颜色策略和颜色强度是两个独立概念，同属现有最终合成器：

- 颜色优先允许尚未确认的 HDR 输入参与颜色合成；新配置默认 0.5。
- 保守颜色只允许已有证据接受的输入；新配置默认 1.0。
- 已知 SDR 等已允许输入，在保守模式下仍采用颜色强度。
- 强度 0 关闭所有输入的颜色贡献，因此不等价于旧 HDR 许可关闭。
- 两种策略分别保存强度。明确保存的旧值与旧 HDR 许可保留；没有
  ColourLabMode 的旧 INI 仍按其明确保存的旧许可解释，不自动变成颜色优先。
- 总开关下方为左右策略按钮及一个强度入口；旧 HDR 许可不另设重复控件。
- Developer 中可分别修改 NR、当前图采集、文字报告快捷键，范围 F1–F12
  或关闭；拒绝重复。新绑定松开后才启用，F8 默认生成文字报告，不录视频。

原有五页、独立五层、统一尺寸、每层原生 mask/UI、新层 1.5/0.4 和
关闭的独立人脸后端均保留。本批不修改模型、颜色 shader 或工作量。

## #254 同帧真实投影候选

修前证据是线性 RR 深度缺少当前 NGX ViewToClipMatrix，不能套用另一游戏
的固定近裁面或深度单位。候选在已有 Streamline Constants/ Evaluate 观察器
中复制公开 cameraViewToClip 前缀，只支持已核对的 ABI 1/2。

准入必须同时满足同一 provider/frame/view/历史代次、缓存年龄不超过 1 秒、
当前 RR Evaluate、完全相同的命令列表指针，以及其内层 NGX 参数/Feature
代次。仅原生矩阵缺失时尝试；原生矩阵不可读、非有限或不支持时继续拒绝。
没有 wrapper 别名猜测，没有额外原生 RR 调用，没有 GPU 工作或历史的跨帧借用。

转换仍使用原有合法格式、设备、有效区域、状态与私有输出保护。失败维持
原生 RR；旧默认关闭的缺投影后置实验仍是独立候选，不自动开启。

F8 新增 projectionSource、slScopeMatches、slCommandMismatches、
slProjectionSelected。Selected 只表示选择到可解析的矩阵；实际转换和 NR
仍须同时看 depthAdapter.recorded、lastReject、decision.reason、nrSuccess
及 RR 后置成功计数。不能把有矩阵或单测通过宣称鸣潮已修复。

## 4080S 显存和省电

F8 在专用 worker 读取运行设备的 adapter LUID，查询该进程在该适配器 node 0
的 DXGI local/nonlocal CurrentUsage 与 Budget，间隔约 750ms 两次采样。
无身份或查询失败明确未知；不记录为零，不混同辅助纹理账目，不冒充峰值。
Present 只复制身份，无每帧 DXGI 预算查询、GPU 等待或额外采集纹理。

保存的两项省电设置现在在 Present 初始化，不再等首个 FG 暂停信号或打开
实验页才能加载。此项只修正配置可观察性；没有可信暂停信号的菜单仍不能
宣称已自动节能。默认仍均关闭，暂停证据与实际阻止 NR 分别显示。

## 继续实施，不得遗忘

1. 同工作量 Q/Q+P，4080S 进程显存预算、双层电影反馈与 FG 输出分别核对。
   原有报告不能证明爆显存，也不能证明另一位用户的 FG 失效原因。
2. 99%/100% 的 P/N/E/O 同源帧证据与非零修改连续性；不能靠降强度或
   更改算法默认掩盖。颜色新默认是 UI 决策，不是该色差已修。
3. 菜单省电继续补真实来源证据；不凭静止图、ReShade 菜单开启或 FG 关闭猜暂停。
4. 共享后台与生命周期后依次接重建后低分残差 SR、#259、#258；再独立验收
   AMDOF 最终残差累积/累积+和低频重建。它们尚未接 Core，当前菜单不展示空开关。
5. 每条实验先有资源安全退役、真实源帧和无效运动拒绝，再测组合拖影与成本。
