## 交界修正

- 0.5 光影占用 flag bit18/19，累计存储诊断也曾使用这些位。D14 保留光影 ABI，
  存储格式改用 bit20–22，PRE 参考偏移改用 bit23；新增真实 WARP 合成/读回组合回归。
- 源分支新增的 `RecordNrUseLocked` 槽全退休条件会挡住 D13 同队列不可变表复用。
  已先用真实 ReShade/WARP 阻塞队列复现，再将有稳定队列历史且属于同一槽队列的
  只读追加与一次性队列的完整退休准入区分；未 signal、异队列、未知和设备移除仍拒绝。
- 不可变 descriptor plan 的统计 UAV 必须覆盖 48-word 头部及全部 2-word 稀疏点记录，
  与实际 CPU Clear 描述符长度一致。
- 恢复账本的 Descriptor 阶段在真实合成所选表消费时记录。只读计划在物化之前不算成功；
  不可变 packet、现有表和成功复制的 F8 表分别核对实际 source/result 与 typed views。
- 第二层 Evaluate 增加私有 NR 操作及 NGX 层作用域；Create/Release 继续复用已合入的共享入口。
- 保留 D13 不透明 NR2 失败的资源隔离与禁止继续录制语义；自动后置不能越过 fatal recording。
