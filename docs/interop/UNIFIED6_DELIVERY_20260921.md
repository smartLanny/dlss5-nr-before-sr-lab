## 实际功能与范围

- 实验页提供关闭、原生运动、AMDOF；首次配置关闭。
  稳定范围默认整链，也可明确选择后续层；不自动替换模型导引。
- B 为同源未增强基底。整链处理 `B + T(Z-B)`；后续层处理
  `P1 + T(Z-P1)`。P1 使用已完成 NR1 和实际现有合成规则，
  不重新推理 NR1；仅后续层范围增加 P1 合成与目标纹理。
- 当前生产入口限 DX12 原生 Feature1 SR 后置、可证 SDR、
  同设备/已证明队列。前置、RR、HDR、Present 和外部 Provider 路线
  尚未采用这个稳定器。缺锚点、运动证据、槽或预算时保留当前候选，
  不静默换范围、开关或比例。
- 原生 MV 消费 Core 已准备的真实导引，拒绝未证相位/单位；
  AMDOF 从未增强图取运动，GPU 判断预热和切镜，没有当帧 CPU 读回等待。
- 时间权重为 `exp2(-dt/(60ms*0.65))`，有效半衰期 39ms；
  超过 250ms 重种，重复源帧不推进光流或历史。开发者固定 0.5 对照保留。
  当前基础拒绝依赖原图匹配，不是深度遮挡或双向光流置信度。

## 生命周期、预算与修正

同一稳定上下文使用三组描述符/输入租期，复用同时要求 GPU 完成和命令列表
不能再重放。更新最后消费者 fence 后才退休；重复提交会退休不再准确的历史。
记录、提交采用、完成分开，不能将录制成功当作 GPU 完成。提交计数也不代表每个像素都采用了历史。游戏主动重放已有命令会再次执行其中的指令；处理器更新最后 fence 并退休历史，不把这种重放算作新的源帧。

实际 Core 检查补出未提交 Reset 接线缺口：只有 lifecycle 记录证明未提交、
无在途提交且无未证明执行尝试时，才取消 pending 稳定事务。证据不足仍隔离。
旧完整 Core 在同一个取消断言上失败，修正后通过，F8 新增 cancelledUnsubmitted。

四个有界上下文，不按在途帧复制整套 AMD 历史；创建前检查自有纹理估算、
SDK 保守余量及 DXGI 预算，创建后核对 SDK 实际分配。预算不足拒绝新增防闪，
不降低 NR 尺寸/层数。整链五张、后续层六张 FP16 工作/历史纹理，加上 AMD
自身资源，属于新增成本。高分辨率可能因保守预算被拒绝；并非显存优化成绩。

修复了官方固定 SDK 外部编译副本的 EffectContext 对齐：实际内存统计查询
会在不满足 32 字节对齐的地址执行 movaps。补齐布局和余量，不修改官方检出、
算法/着色器或外部 ABI。独立外部 SDK 及许可证不混入公共源码。
