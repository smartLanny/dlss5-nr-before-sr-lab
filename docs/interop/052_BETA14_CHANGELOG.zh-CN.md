# 0.5.2 Beta 14

Beta14作为后续开发基线。保留Beta13的简短功能说明、悬浮详情和可见状态计数；公开DLL ABI、渲染算法和保存设置不因本轮诊断改动而变化。

- F8增加有界Esc/菜单过渡记录，帮助区分主画面与独立预览上下文。
- F8增加插件自建资源的分类分配账目，区分已知分配下界、未知模型内存及整个游戏进程用量。这不是显存优化或完整驻留显存统计。
- 维护者在异环开启原生RR的测试中接受Esc过渡表现；单层→双层→单层的已知分配回到初值。该验收不覆盖所有UI/模型同屏场景、长期泄漏或其他显卡。
- 私有SR已在部分游戏配置实际执行，但61%对照出现碎边/颗粒，维护者报告闪烁，质量仍未通过。继续默认关闭，普通恢复为建议基线；不宣称全面降噪或整游戏帧成本合格。
- 已有路线为原生RR→后置NR。低分辨率NR→一次原生RR、第二套私有RR及跨API传输仍属于后续研究。

本OTA只更新Core与配套nrchain，不包含NR/SR/RR/FG运行库或人脸资源，不写INI，不自动启用实验。保留既有安装、运行库和回退包。
