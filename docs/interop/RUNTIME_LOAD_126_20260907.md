# Runtime load Win32 126 分类（#152）

基于 `origin/main@ba71b45`。这是加载诊断与有界回退，不是宣称解药或其它游戏 NR 已实机修好。云端未编 Windows OTA。

## 根因

`EnsureNrApi` 用 `LoadLibraryExW(..., LOAD_LIBRARY_SEARCH_DLL_LOAD_DIR | LOAD_LIBRARY_SEARCH_SYSTEM32)` 加载插件目录下的 `nvngx_dlssnr.dll` / `nrchain_nvngx.dll`。Win32 **126**（`ERROR_MOD_NOT_FOUND`）既可能是目标文件不在该目录，也可能是文件在、依赖不在这两个搜索位置。旧日志只报 `signedWin32=126`，无法区分。

不把 PATH 或任意目录加入搜索。

## 修改

- 加载前 `GetFileAttributesW` 判断常规文件是否存在。
- `signedClass` / `bridgeClass`：`loaded` / `file-absent` / `dependency-missing`（文件存在且 126）/ `other-failure`。
- 仅当**插件目录文件不存在**时，用同样受限标志尝试游戏 exe 目录同名文件；文件存在但 126 不换路径。
- F8 增加 `*Present` / `*Class` / `search`，不写本机路径。

## 验收

待玩家用已发布 multiapi-dev3 或后续含本补丁的包复测。需要 F8 的 `runtime.signedPresent` / `signedClass` / `signedWin32` / `search`。未宣称安装布局已修好。

Refs #152, #80。
