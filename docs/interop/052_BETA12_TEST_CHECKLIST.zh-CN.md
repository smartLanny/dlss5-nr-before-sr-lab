# Beta 12 实机测试单

先确认界面版本为 **0.5.2-beta.12**。本单供维护者手动测试；代理不启动或控制游戏。安装是否完成以交付回执为准。

## 先分清这些选项

| 选项 | 本批状态 | 看什么 |
|---|---|---|
| 普通恢复、均衡、精细 | 已有功能 | 保留作基线，不是新降噪 |
| 去除暗噪／暗部彩点保护 | 已有保护 | 只处理特定暗部彩点，不代表全面降噪 |
| 引导恢复 | 新空间实验，默认关闭 | 颗粒是否减少；细线、文字是否变弱 |
| 局部抑噪 | 新空间实验，默认关闭 | 孤立颗粒是否减少；头发和细小纹理是否变软 |
| 私有 SR | 保留对照 | 与同档普通恢复比较，不保证更清晰 |
| 残差防闪／运动历史 | 现有时域实验 | 必须有实际采用记录，不能只看已打开 |

两个新实验只处理当前帧的 NR 修改，不是新 NR 模型，也没有加入新的运动历史算法。引导恢复已有细线减弱的受控反证，保留供人工比较，不列为推荐默认值。先以普通恢复为日常基线。

## 1．比较两个新算法（约五分钟）

1. 游戏先用原生 SR。NR 使用后置、单层、50% 工作比例；关闭私有 SR、残差防闪。固定模型、强度、旧恢复与暗部保护，不在三种方式之间改动它们。
2. 找同一处同时有暗墙、头发或树枝、招牌文字的场景。在实验区的“降噪对照”依次选 **关闭 → 引导恢复 → 局部抑噪 → 关闭**。每次等待画面稳定，静止看一次，再缓慢转动镜头。
3. 每种方式按一次 F8；只需反馈“更干净／没区别／更糊／细线断了”，并注明大致时间。状态显示“未生效”时记下那句短原因；不要把未采用算作算法无效。
4. 再用双层重复。游戏原生 RR 由你手动打开后另做一轮；两轮分别记录，不混成同一个结论。

“已提交”证明处理已交给 GPU，并不等于画质更好。关闭应恢复普通结果；已用资源会在 GPU 完成后释放，不要求占用瞬间归零。

## 2．私有 SR 与旧九组（独立比较）

先关闭新“降噪对照”和残差防闪，再对照同档普通恢复与私有 SR。重点看发丝、文字笔画、暗部结构和镜头运动中的碎边。私有 SR 与两个新空间方式互斥，设置冲突会保留请求并显示未采用原因。

九组按钮继续用于既有基线：每组 180 个有效源帧预热、600 个有效样本、三张截图，20／60 秒上限；结束或取消恢复原设置。**九组执行时强制关闭两种新空间方式**，所以比较它们要用上面的手动切换和 F8，不能从九组图片推断它们的效果。

## 3．Esc 与切菜单

固定同一场景，缓慢进入 Esc 菜单三次。观察 UI 出现、镜头推进、完全展开、返回游戏四个阶段。只要看到 NR 突然消失或像重新加载，就在当次结束后马上按 F8，记“刚刚第几次、哪个阶段”。本批有自动 Esc 时间标记帮助对齐；**目前没有证据宣布闪变已经修复**。

## 4．与 0.5 D13 比显存和性能

使用随附的本地“D13 对照”工具；原版 D13 已保留。只比较共同支持的 **单层对单层、双层对双层**，先测原生 SR、后置、每层 100%。两版固定分辨率、场景、NR 模型与强度、实际 NR 工作尺寸、游戏画质、帧率上限和垂直同步，关闭帧生成。新版额外实验全部关闭。

双击“开始对照采集”，选择层数，按提示切回游戏，保持同一场景。采集结束立即按 F8。它记录目标游戏进程显存与帧时间；有锁帧时，帧率不变不能说明额外 GPU 成本为零。

切换 D13 必须先退出游戏，成对切换 Core 与对应 nrchain；保留设置和原生运行库，并留回退。工具默认只核验，明确执行才替换。推荐按 **新版单层 → 新版双层 → 退出并切 D13 → D13 单层 → D13 双层 → 退出并切回新版**，最后保留新版。RR 对照须先确认 D13 的实际采用；不支持就单列原因。

维护者无需计算：把两版采集目录和对应 F8 留在本地，由代理核对后给出显存中位数／最高样本、帧时间中位数／P95、GPU 工作指标及样本数。缺数据、NR 未采用、后台运行或条件不同的组不算优化收益。旧版和新版配套 chain 不同，因此这是完整包对照，不是单个 Core 改动的因果证明。
