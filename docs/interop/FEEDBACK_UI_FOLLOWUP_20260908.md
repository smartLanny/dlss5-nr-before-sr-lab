# 0.4.6 反馈界面与效果默认值补正

本批接续 PR #166 和已发布的 `9087a9e`，不重新实现 RR 恢复、F8/F7 后端或
Manager 兼容桥接。原发布包仍保留，本文件区分新候选与原发布结果。

## 已确认的界面缺陷

主设置页用 `NR_HAS_F8_SEQUENCE` 包围 F8/F7 控件，但生产源码和编译参数都未
定义它。采集后端和 Present 热键一直存在，设置页的按钮却被预处理排除。
原离屏 fixture 人工定义了这个宏，未覆盖真实 Release 的这个缺陷；原有
“UI 实绘通过”只适用于当时的 fixture，不能证明发布包主面板入口存在。

另一个独立缺陷是注册 `DLSS5 F8 Capture` ReShade overlay 后，其回调又
`ImGui::Begin` 一个反馈窗口。ReShade 已经负责外层窗口，这使额外标签空白、
内部窗口闪现。两者不是采集后端被删除。

修正包括：

- F8 单 TXT、F7 图像补充与七组对照、取消、采集时禁止编辑无条件编译，
  不受语言、Release 或 NDEBUG 切换影响。
- 只保留“装机宅DLSS 5”窗口，反馈与诊断合成一页；F8/F7 在 Present 请求
  采集并打开 ReShade，页面请求保留至主 tab bar 实际绘制，再消费一次。
- 删除独立 F8 overlay 及嵌套窗口；后台采集、超时、恢复和剪贴板交接保留。
- 渲染比例实验放在画质底部默认收起的开发者选项中。它仍只是下一次引擎
  查询的建议，不宣称可以实时改变 2077 渲染分辨率。
- “NR 效果倍率”控制最终整体混合；“NR 色调跟随”控制模型色相与饱和度
  修改的跟随程度。主要控件常展开，说明在悬浮提示中。
- 新装、缺失配置的回退和“恢复推荐”统一效果倍率 1.0。已保存的明确数值
  不被升级覆盖，模型内部强度、HDR 规则及大于 1 的颜色预算保持独立。

因此，这些报告没有复现“遮罩开关未传递”或“NR 停止”；它们也不能证明模型
正确识别了动漫人脸。当前 AutoMask/SkinStructure 是模型内部皮肤结构参数，
不是提供给最终合成着色器的逐像素人脸豁免区域。皮肤结构 0 不等于脸部所有
影调、风格和模型强度修改均为 0。最终整体倍率仍会处理模型已经改过的人脸。

准确的脸部独立合成需要经验证的面部 mask 输出及坐标/时序契约，或新增独立
分割路径。仅凭肤色阈值、把皮肤参数除以倍率、或把全画面倍率暗中限为 1，都
不能实现“只维护人脸、其他区域继续放大”。本批不把这些近似当成人脸修复，
#162 继续保留画面验收和独立 mask 方案评估；不清空生命周期保护冒充恢复。

## 色调跟随的最小 GPU 对照

复用生产 `CombineCS` 与 `CombineV2CS`，在 50%/100% 模型网格测试颜色系数
0、0.5、1。已知颜色残差下输出色差随系数单调增加，亮度保持约 0.5；仅明暗
残差的对照三档 RGB 相同。这个结果说明滑块控制的是颜色残差，模型只改变
明暗时调节可能很不明显；不以额外饱和度曲线制造效果。

这是确定性生产 HLSL WARP 对照，不包含真实 NVIDIA Feature 18 推理，也不
等于异环人脸已验证或当前游戏输入必然有明显颜色残差。
