# dev16：双路线选择块与默认光照保护

维护者确认鬼武者dev15配合官方REFramework通过后，要求把处理模式改为
左右选择块，并将光照保护默认设为0、模型强度保持1.2。本版只调整菜单与默认值，
保留前代首轮录制、RR深度和菜单ABI修正。

## 最终行为

- 左侧NR→SR、右侧SR→NR，当前选择高亮，点击通过原配置提交和历史重置路径生效。
- RR生效时显示并禁用后置选择块，保存的个人模式不被改写；关闭RR后恢复选择。
- 新配置、缺失/非有限光照值和一键恢复使用光照保护0；已有有效个人值继续生效。
- 模型默认1.2、前后置NR默认100%、三块风格和开启的色彩保护保留。
- 布局宽度使用已修正的ImVec2返回适配，未重新直接调用不兼容的主机返回接口。
