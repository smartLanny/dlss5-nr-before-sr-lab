# unified10 菜单与短测试

画面页：NR开关 → AI色彩范围 → 处理顺序 → 工作量 → 最终增强 → 各层参数。

## AI色彩范围

新配置与恢复默认画质为0.5。0不采用额外NR色彩，NR明暗/细节仍处理；1请求完整
采用颜色变化，仍受置信度、色域及消费者保护，并不保证等于原始模型图。
它不是全画面饱和度，也不改变模型强度。调整即采用原颜色优先的调色许可，包含
内部HDR输入；不用另开HDR许可。颜色范围不决定防闪是否运行；防闪单独开启并核验输入。

明确保存的旧颜色规则先保留，面板会提示。首次调整此滑条或恢复默认画质才切换
新规则；新键AIColorRange拥有许可与强度，旧字段保留供回退。0不在所有路线都
等同旧保守颜色。光影预设仍不修改颜色范围。

## 省电与验收

两个省电仍默认关，读取游戏FG信号，不根据菜单外观或ReShade面板自动暂停。
新增状态能区分未收到FG观察、游戏明确继续渲染及来源未匹配；F8记录观察计数。
配置开启不等于NR已暂停；NR暂停也不保证整张显卡功耗按同样比例下降。
没有菜单内开启省电的修后F8，不将功耗问题标为解决。

集中验收单独记录预热期间NR活动与防闪状态，避免把未开始计时的0读成NR停止。
颜色对照会临时采用新的颜色范围，结束恢复原配置，不写INI。

## 短测试

1. 退出游戏后替换同语言Core和配套文件，保留INI与旧包；每条加载链只有一份Core。
2. 同场景调整颜色范围0/0.5/1，松手后观察实际采用值；重启核对保存值。
3. 省电开启后进游戏菜单，生成一次F8，再离开菜单核对NR恢复。只需补这段，
   不重录此前完整验收。F8是文字采集，不是功耗测量。

## HDR 防闪

AMDOF 新接入已声明线性 HDR 且同帧预曝光有效的原生 SR 前置整链、SR 后置及成功 RR 后置。
支持 FP16，以及异环使用的 R11G11B10 浮点输入；只读取有效区域，忽略纹理末尾的对齐填充。
历史修改量除以本帧预曝光保存，合成时乘回当前预曝光。只有光流识别图进行有界压缩，
最终 HDR 输出不截到 0～1。不把显示器 HDR 开关当作内部画面颜色域。

异环本轮只需保持原设置，补测“防闪关闭 / AMDOF 整链”。前置原生运动、单层后续层范围
仍不适用，不必再跑。F8 的 temporal.submitted 应增长；lastPreparedDomain=2 表示最近
准备使用线性 HDR 历史，单独这个字段不是已提交或画质通过。观察运动拖尾、高光和切镜。
未知/PQ编码、无效曝光仍保留当前 NR 结果；私有重建尚未接入。
