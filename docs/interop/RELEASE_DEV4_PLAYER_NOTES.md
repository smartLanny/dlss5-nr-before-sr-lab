# dev4：主线统一、反馈精简与稳定性维护

本轮将已发布dev3中的fix2、DX11兼容、RR后置和50–100%后置NR工作精度统一进main，保留main上的历史BUG资料。dev4使用独立版本名；已发布dev3文件与Tag保持原样。

F8仍生成一个命名TXT。改进目标是保留当前设置、版本/文件身份、首次关键错误、最近状态和重复次数，减少大量重复日志。具体大小上限、采集稳定性修复和实测结果见仓库MAIN_CONSOLIDATION.md；未取得的证据会明确标缺失，不等于所有日志被完整保留。

安装时退出游戏，备份原组件，中文/英文选一个，使用同包的核心、nrchain和dev4 carrier，保留旧INI。完整安装、回退和测试方法见README.md。

本轮没有扩展游戏支持，也未宣称异环、HDR/FG、运动画质或长时稳定全部修复。自动Windows与WARP验证不替代真实NVIDIA/游戏测试。请在原场景用F6对比前后置，需要反馈时按F8，视觉异常方便时再F7。
