# PR303：0.5.1 Beta 集成审查

## 固定范围与结论

审查范围为 unified9 `101bc75f11cb99a793e83668880ec6ae25e6afc0` 至
PR303 `1874a22a35376b6efa70cf15541cf6ebbcf1fb0d`。运行安全与功能合同各进行一次
独立审查，未发现需要阻止该候选整合的 P0/P1/P2。此结论不是游戏性能或显存收益证明。

实际合入 HDR 后继的构建源码为 `d36dc7712d2683ed944ae98562afffbb3cebc47c`。
保留双方提交历史；OpenNR 仅为研究记录，不进入 Core 或 OTA 的执行代码。

## 合并时完成的必要适配

- 缓存根签名保留 HDR 后继的 20 DWORD、4 UAV 和每槽 13 个描述符。
- 保留同帧预曝光、R11G11B10 与底部填充、NextOriginal 写入及最后消费者约束。
- 预编译覆盖快照和原地变体；增加“预编译＋默认快照”独立 GPU 路线，避免只测实验变体。
- CPU 的旧路径一致性参考更新为实际合并前 HDR 源码 `f57fed40`，不再拿 SDR 版本比较 HDR 算法。
- 无快照 FP16 仍默认关闭；缓存、格式查询缓存和快照增量记账进入默认生产路径。

## 专项验证

- 10,061 项实际缓存/准入代码检查，四个编译后负控能够发现错误。
- 实际 Core Record 包装函数覆盖分配成功/拒绝/隔离后的字节、峰值及退休账目。
- 29 项预编译消费、缺件拒绝、哈希和接线检查。该部分合成容器不冒充 HLSL/GPU 验证。
- RTX 5090 D、驱动 616.92：动态无缓存、动态缓存、动态原地、预编译快照、预编译原地
  五路均通过。SDR/HDR、两种范围的 28 张对照图在五路间逐字节一致。
- 每路运行真实时域探针和错误方向、丢锚点、跳过预热、HDR 截白、忽略曝光等负控。
- 完整 Windows/双语/WARP 和最终包状态以同目录交付记录为准，不能沿用 PR 的 Mac 测试冒充。

## 保留的实际边界

受控 GPU 不等于游戏内 NGX 推理与画质验收。尚无本候选的游戏 FPS、总显存收益或菜单功耗结论。
GPU 调试层不可用，未记为通过。原地实验未完整覆盖所有前置 UAV 写入和 GPU 故障注入组合，
继续默认关闭；不能根据一张纹理的理论大小宣布玩家的模型创建峰值问题已解决。
缓存是同设备不可变流水线缓存，模型、光流、残差的历史和寿命仍分别保留。
