# 异环测试单：先确认生效，再比较效果

适用：Beta 11 候选；安装身份和验证结果以最终交付回执为准。游戏由维护者启动、选择 SR/RR；保留现有配置和运行库。以下先做必要项，实验可以分次做。

## 目前能测什么

| 功能 | 当前结论 | 测试目标 |
|---|---|---|
| 普通 NR，包括游戏 RR 后增强 | 最近 F8 中持续执行 | 比较画面变化，检查 Esc 过渡是否丢失 |
| 低分辨率恢复：关闭／均衡／精细 | 已有空间恢复选项，不是新的全面降噪 | 同工作量比较发丝、文字和细线；无明显收益就保持关闭 |
| 暗部彩点保护（原“去除暗噪”） | 已有近黑色度保护；本次 F8 中关闭 | 只检查近黑处的彩色杂点；不要用纯黑亮度颗粒判断它是否有效 |
| 私有 SR | 以前 50%／25% 对照有执行证据；本次 4K、100% 未执行 | 先确认实际生效，再与同档普通恢复比较；默认不推荐 |
| 原生运动／光流防闪、低频模式 | 已有实验，真实游戏九组的时域采用仍未过门 | 未生效记为不支持；不能靠切换后“感觉平滑”判定采用 |
| NR → 私有 RR | 未交付 | 本轮没有可测试开关；游戏 RR → NR 是另一条路线 |
| 新四点恢复 | 细线不达标，未加入产品 | 不需要在游戏里找它 |
| 显存复用、降层后回收 | 自动机制，无单独开关；节省量尚无版本对照证明 | 由本地报告记录和分析，不要求维护者盯任务管理器 |

## 必要项一：NR 与 Esc（约 2 分钟）

1. 固定一个能看清 NR 效果的场景。先用 **1 层、100% 工作量**，关闭私有 SR 和防闪实验，确认普通 NR 开关的画面差别。
2. 保持人物和视角不动，打开、关闭 Esc 菜单两次。分别看“UI 开始出现／镜头推进”“菜单完全展开”“返回游戏”。
3. 若过渡中失效，动画结束后按 F8 并保留同进程日志即可。Beta 11 会通过前台游戏窗口的 Esc 输入自动留下时间标记，不要求在闪变瞬间按键。标记只代表按键附近的状态，仍需维护者确认看到的画面。
   如果使用旧 Beta 10，请额外记下发生时刻；旧版没有这个时间标记。
4. 提供该次反馈目录及一句话，例如：“14:25:32，RR 开，菜单推进时恢复原画，菜单完全展开后 NR 回来。”短视频有助于核对画面，但不是每次必需。

通过：过渡、完整菜单及返回游戏均保留预期 NR；无重新加载般的闪回。未通过：即使几百毫秒后自行恢复，也记失败。

## 必要项二：自动对照和显存（每种游戏模式一次）

1. 选择可重复的静止场景；记下分辨率、游戏 SR 或 RR、NR 层数。由维护者在游戏设置中切换 SR/RR。
2. 点击九组对照按钮一次，等待完成。不在组间改设置、开地图或切换菜单。结束和取消均应恢复原设置。
3. 发整份反馈目录即可；九组按钮在“反馈”页。代理核对：各组实际采用、有效计时样本、截图、显存采样范围及拒绝原因。

九组为：原生无 NR、普通 100%、普通 50%、私有 SR 50%、普通 25%、私有 SR 25%、原生运动防闪、光流防闪、低频防闪。每组仍是 180 个有效源帧预热、600 个有效样本、3 张图；不支持的组记录原因后继续。

显存由报告给出进程采样值。空白或“未采到”不是 0。连续组的缓存和游戏变化会影响结果，不能据此声称新版本节省了固定百分比。需要证明版本优化时，代理再给出同版本身份、同场景、同工作量的旧新对照；不要在没有回退准备时自行替换旧 DLL。

## 可选项：每次只比较一种实验

| 对比 | 设置与操作 | 看什么 | 停止条件 |
|---|---|---|---|
| 普通恢复 | 1 层、50% 工作量；依次关闭／均衡／精细，其余不变 | 文字边缘、连续电线、头发；同时看暗部颗粒 | 效果不明显记“无明显收益”；不要提高锐化来掩盖结果 |
| 暗部彩点保护 | 固定暗处，保留实际 AI 色彩修改；只切这个开关 | 彩色杂点有无减少，暗部有效颜色是否被抹掉 | 对纯亮度黑点无改善不等于接线失败；保留同场景 F8 让代理确认采用 |
| 私有 SR | 后置 NR 工作量设为 50%，防闪关闭；普通恢复与私有 SR 二选一 | **先由状态/F8 确认生效**，再比较细线、发丝、文字、暗部碎点 | 未生效不评价画质；更碎、更糊或成本更高且无收益就关掉 |
| 防闪实验 | 私有 SR 关闭；保持相同工作量，分别测现有模式 | 静止颗粒、缓慢转镜头、人物移动、遮挡后露出的区域、反射、HUD | 状态不支持就保留报告；有拖影、文字残留或显露污染就关掉 |
| 降层回收 | 同场景，先记录稳定 3 层，再持久改为 1 层，稳定后分别采 F8 | 代理核对退休资源与进程显存；维护者只看是否卡顿或丢效果 | 不人为耗尽内存；卡住或 NR 消失即停止并保留日志 |

反射、显露区域正确拒绝旧画面后仍有当前帧颗粒，是已知局限；低频防闪也不等于去除全部颗粒。截图只能判断空间细节，拖影需要连续观察。

版本：____；游戏 SR／RR：____；分辨率：____；NR 层数／工作量：____。

测试项：____；界面状态文字（采用由代理核对）：____。

看到的问题或收益：____；发生时刻：____；反馈目录：____。

不需要手工抄计数、GPU 毫秒或显存数字；这些由代理从报告整理。当前 GPU 报告只覆盖部分插件区间，不能代替整游戏帧成本。
