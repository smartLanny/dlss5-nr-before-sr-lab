## 独立实验：已推进，但未进入基础包菜单

### 私有 SR / 跨 RR

已把最终 colour 生成链和统一实验页接到独立 overlay；验证基线 `4976ca48`，
完整人脸后端双语编译通过，6 个改动文件外的 219 个生成文件保持一致。
真实 NVIDIA Feature1 私有 SR 显示：中性 0.5 载体可能有输出偏移，原合成会
把偏移放大加回原图。本次复用现有量化尾差的有效标记，显式最近偶数 FP16 编码，
修正零修改偏移及微小负修改的不对称量化；没有新增纹理或 pass。

实际 320×192→640×384 SR 的零修改、+1/1024、-1/2048 最终 FP16 结果通过，
冻结旧 shader 在同一真实 GPU 输入下失败；另有 CPU 生命周期、六 shader WARP
和完整源保存检查。受控输入不是实际 Feature18 编辑，没有运动/遮挡游戏验收。
优先的“重建后低分最终修改量”路线、最新版五层/桥接集成和完整 RR 组合仍待接入；
这不等于提供独立全图 RR 后端。源码：`experiments/nr-edit/README.md`。

当前是 SDR 固定权重累积，尚无动态时间权重、累积+、低频重建、HDR 映射及
