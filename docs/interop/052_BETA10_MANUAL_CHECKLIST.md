# Beta 10 最短游戏检查

由维护者安排异环实测，2077 最后。代理只准备与部署，不启动游戏。保留已保存设置和回退；此前两套完整 SR/RR 九组已收到，不用先重复录制。

1. 新进程先确认 Beta 10，使用普通恢复检查 SR/RR 正常输出；再恢复原有多层配置。不要人为耗尽系统内存。若提交余量不足，允许后续层延后；确认主层仍可工作且没有持续 `lifecycle-isolation`。
2. 固定场景进入 Esc 菜单，记录 UI 浮现、镜头推进时 NR 消失的本地时间；菜单完全展开并恢复 NR 后立即按 F8，保留同进程日志。已知症状是进入动画短暂消失，并非整个菜单无 NR；静态九组不能代替此检查。
3. 若多层始终不完整，查看后续层延后原因、当前请求/实际采用和可提交余量。不要把旧配置的 historical-success 当作当前生效，也不要把低余量降级视为性能改善。
4. 继续保留 Present、切镜、地图省电和多层暗部检查。画质与拖影需要连续帧；整帧新增成本 ≤3% 仍需独立实机计时，局部插件时间不能替代。

真实厂商不透明失败后若进入隔离，反复开关不会解除；先保存 F8，再正常退出游戏重新开始。切勿在游戏运行中替换 Core。新包未声称解决全部菜单闪烁、所有内存增长或全面时域降噪。
