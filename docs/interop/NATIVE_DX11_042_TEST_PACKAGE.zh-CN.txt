beta0.4.2 原生 DX11 载体实验版

这不是正式版，也不是一键安装包。它只是给有 DX11 原生 DLSS 的游戏做小范围测试。

包内文件

- 中文或英文 DLSS 5 addon：二选一
- nrchain_nvngx.dll：0.4.2 核心桥
- dlss5-native-carrier-exp1.addon64：DX11 原生 DLSS 载体
- nr_before_sr.ini：实验配置
- PACKAGE_MANIFEST.json：每个文件的大小和 SHA-256
- source-manifest.json：固定源码身份

怎么测试

1. 完全退出游戏和 ReShade，先备份原来的插件文件。
2. 只保留一份本实验版 addon，同时放入核心桥、原生载体和配置文件。不要与旧版桥、其他 NR 插件一起启用。
3. 只在游戏自己的 DLSS 确实能工作的 DX11 模式下测试。
4. 进入游戏后看日志：Feature 18 成功次数和 transfer-submitted 应该持续增加。只出现加载而没有持续提交，不算生效。
5. 如果游戏闪退、黑屏、原生 DLSS 失效或画面异常，立即退出并恢复备份；反馈时附上日志和版本信息。

目前明确不支持

- 没有原生或模组 DLSS 的 DX11 游戏
- DX12、Vulkan 或纯合成输入
- 任何需要把原生载体伪装成其他桥的安装方式
- 一键安装助手自动部署

这个实验包没有经过真实游戏验收，也没有签名。自动构建通过只代表源码、CPU 路由测试和 Windows 编译通过。
