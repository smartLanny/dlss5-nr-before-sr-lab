beta0.4.2 原生 DX11 载体实验版（给愿意帮忙测试的人）

这是一套“手动安装”的实验包，不是正式版，也不是一键安装包。它的目标是让一部分 **本来就能在 DX11 下使用原生或模组 DLSS 的游戏**，尝试进入 beta0.4.2 的 NR→SR 链路。它不会把一个没有 DLSS 的游戏变成 DLSS 游戏，也不会强制开启 DLAA。

请先记住三件事：

1. 只在游戏原本的 DLSS 能正常工作时测试；先在不装本包的情况下确认一次。
2. 中文和英文 addon 只选一个，旧版桥和其他 NR 插件也只保留一套。
3. 这是实验版。看到插件加载不等于画面已经处理，必须确认日志里有持续的 Feature 18 成功和 `transfer-submitted`。

## 你应该下载哪个包

发布页会提供两个完整包：

- `RTX50`：RTX 50 系列显卡使用。
- `RTX30-40`：RTX 30 或 RTX 40 系列显卡使用。

两个包的区别只有 DLSSNR 运行库版本。不要把两个运行库混用，也不要把两个包解压到同一个目录后让旧文件残留。

## 包内文件是做什么的

- 中文 addon：ReShade 里显示中文；和英文 addon 二选一。
- 英文 addon：ReShade 里显示英文；和中文 addon 二选一。
- `nrchain_nvngx.dll`：beta0.4.2 的 NR 核心桥。
- `dlss5-native-carrier-exp1.addon64`：把 DX11 原生 DLSS 输入转交给实验链路的载体。
- `nvngx_dlssnr.dll`：Feature 18 运行库，必须和显卡系列匹配。
- `nr_before_sr.ini`：实验默认配置。
- `Collect-Feedback.cmd`：普通画面或“没有生效”问题的反馈采集器。
- `Collect-Crash-Feedback.cmd`：闪退、黑屏、启动失败时的反馈采集器。
- `PACKAGE_MANIFEST.json`：每个文件的大小和 SHA-256，方便确认没有拿错文件。
- `source-manifest.json`：本包对应的源码身份。
- `说明.txt`：这份说明。

## 安装步骤（手动）

1. 退出游戏、ReShade 和其他可能正在使用插件的程序。
2. 找到 ReShade 的 Add-on 目录。通常是 ReShade.ini 中 `[ADDON] AddonPath` 指定的目录；找不到时，查看 ReShade.log 里的插件目录。不要凭感觉复制到游戏根目录的任意子文件夹。
3. 先把原来的 addon、`nrchain_nvngx.dll`、`nvngx_dlssnr.dll` 和配置文件复制到一个备份文件夹。文件名相同就覆盖前，务必保留备份。
4. 从本压缩包中复制所有文件到同一个 Add-on 目录。
5. 中文用户只保留中文 addon，英文用户只保留英文 addon；另一份 addon 要移走或改名，避免两个界面同时加载。
6. 如果目录里还有旧版 `dlss5-native-carrier`、旧版 `nrchain_nvngx.dll` 或其他 NR 桥，先移走。实验目录只保留一套桥接文件。
7. 启动游戏，先确认游戏自己的 DLSS 仍然能正常工作，再观察本插件日志。

## 怎样判断“真的生效”

正常情况是：

- `nr-before-sr.log` 能看到当前游戏、输入尺寸和 Feature 18 身份；
- `Feature18-success` 在进入游戏后不止出现一次，而是随帧持续增加；
- `transfer-submitted` 也持续增加；
- 游戏原生 DLSS 没有变成黑屏、静止画面或完全失效。

只有“ReShade 显示了插件”或“出现了一次 Create 成功”不能算生效。如果日志显示载体已加载但 `transfer-submitted` 长时间为 0，请按未生效反馈。

## 出现问题怎么办

- **闪退、黑屏、启动失败**：立即退出游戏，恢复刚才的备份；不要继续反复启动。然后双击 `Collect-Crash-Feedback.cmd`。
- **画面正常但效果没变化**：先确认游戏确实是 DX11 和原生 DLSS，再确认 AddonPath、显卡包、日志和是否有旧桥重复加载。然后双击 `Collect-Feedback.cmd`。
- **只有某个场景无效**：记录场景、分辨率、HDR/SDR、游戏 DLSS 档位和日志，再运行普通采集器。

采集器只把本机日志、版本信息和有限的诊断摘要打成 ZIP，不会自动上传，也不会主动创建转储。崩溃转储可能包含内存、用户名和本机路径；发送前请自己打开 ZIP 检查隐私。

## 明确不支持的情况

- DX12、Vulkan 或没有原生/模组 DLSS 的 DX11 游戏；
- 仅有合成输入、无法提供真实 DLSS Feature 1 的游戏；
- 把实验载体伪装成其他桥、复制第三方虚表或替换未知注入器；
- 一键安装助手自动部署。本实验载体未经签名，当前安装助手会拒绝它；
- 期待它自动把游戏变成 DLAA，或保证和其他后处理插件逐像素一致。

## 卸载与恢复

退出游戏后，移走本实验包中的文件，再把备份文件复制回原 Add-on 目录。不要在游戏运行时替换 DLL 或 addon。生成的日志和反馈 ZIP 可以在确认不再需要后自行删除。

## 给反馈时请写什么

请一并写明：游戏名、DX11/DX12、显卡型号、驱动版本、HDR/SDR、游戏 DLSS 档位、是否原版 DLSS 正常、问题发生的场景，以及 `Collect-Feedback` 或 `Collect-Crash-Feedback` 生成的 ZIP。若能看到日志，请说明 `Feature18-success` 和 `transfer-submitted` 是否持续增加。

## 验证边界

本包的自动构建、CPU 路由测试和 Windows 编译会在发布前核对；这不等于在你的游戏和显卡上已经验收。当前实验版仍需要玩家实机复测，尤其是 DX11 游戏的载体兼容性、HDR、动态分辨率、切场景和长时间运行。
