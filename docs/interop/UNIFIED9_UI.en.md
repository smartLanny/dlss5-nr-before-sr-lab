# unified9 menu and short checks

A common read-only header shows version, actual activity, route and dimensions.
Picture order: NR toggle, processing order, colour policy, AI colour amount,
workload, final enhancement, then independent layer controls. Saved values remain.
Native skin/UI masks default on, skin 0.4, model strength 1.5 for new layers.

All lighting gains live on Lighting. Three methods remain exclusive. Ordinary
lighting displays the existing Broad*(1-Glow) product as one broad-brightening
control. Merely viewing never changes saved factors; an edit replaces them with
one effective gain. Presets and undo never change AI colour. An enabled legacy
component combination remains visible here; explicit exit can be undone.

Developer explanations distinguish spatial RGB sampling, compatibility-only
motion-unit conversion, extra-gain protection and mandatory numeric/gamut bounds.
These are not temporal denoising backends or guaranteed multi-layer saturation
protection. Missing RR projection fallback defaults on only for new/missing
preferences; explicit OFF survives. Unknown-depth Reset and all admission checks
remain. Unsupported/unreadable projections still bypass; native RR is retained.

Check all five tabs, narrow/high-DPI layout, slider release, saved masks, preset
colour independence and legacy exit/undo. Guided acceptance should link complete
text reports without requiring an image archive. No claim of new game-quality,
VRAM, private SR or temporal route improvements accompanies this UI update.
