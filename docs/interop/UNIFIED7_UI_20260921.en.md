# unified7: safe switching, native motion, and 25% post processing

The five pages and independent model settings remain. Post-SR, post-RR and
standalone Present accept 25–100%; pre-reconstruction remains 50–100%.
One working scale applies once to all layers. Read the actual aligned dimensions.
25% does not mean one-sixteenth of total time or memory. Saved settings are kept;
the new-configuration scale remains 100%.

## Experimental residual stabilization

OFF remains the default. Choose native motion or AMDOF explicitly, and choose
whole-chain or later-layers scope. Later-layers needs at least two layers and a
valid first-layer anchor. A refusal retains the safe current NR candidate;
it does not silently change scope. Switching waits for actual resource safety.
OFF does not free submitted, replayable or quarantined work prematurely.

Stabilization still supports only proven native DX12 Feature1 post-SR SDR on the
same device and proven queue. Equal-size native motion now has a safe snapshot
path. Units, phase, region and frame identity remain mandatory. Diagnostics
distinguish missing, invalid, unsupported and used motion. AMDOF does not replace
the model's guides. Pre-SR, RR, HDR, Present and external Provider NR retain
their existing behavior but do not yet use this stabilizer. Private SR/RR,
NVOF, accumulation+ and low-frequency reconstruction are not exposed yet.

OFF stops new stabilization work. Its resource counter excludes NR motion
proxies and NGX model history; total process memory need not immediately drop.

## Short test

1. Keep model, layers, colour and FG fixed, stabilization OFF. Try post 100%,
   50%, 25%; verify persisted selection, actual dimensions and continuous NR use.
2. On a supported post-SR SDR route, switch native motion, AMD and OFF repeatedly.
   With two layers, compare both scopes. Check movement, cuts and disocclusion
   for flicker, trailing and detail, together with actual status.
3. Compare OFF/native/AMD at identical workload. Save the same-run F8, frame
   times and process memory usage/budget. Scale reductions are different work.

F8 `resetObservation` describes successful Evaluate calls and explicit Reset
reasons. Bit 64 in this schema means RR placeholder depth; delayed exposure is
separate. Reset rules are unchanged. Submission is not GPU completion or proof
that history contributed to every pixel.

## Defaults and rollback

Conservative colour defaults to 1.0; optional colour priority to 0.7. Preserve
saved choices. Independent face detection, stabilization and both energy modes
default OFF. The complete face backend remains included and independent from
the native per-layer skin mask.

Exit the game, back up files outside plugin discovery paths, replace one Core
and its matching nrchain, and keep the user's INI. The template is for first
installation only. To roll back, exit and restore unified6 with the original
INI. No automatic installation or stable release. Game evidence is still
required for #246/#254; controlled tests do not establish a fix for game flicker,
99% colour changes, RR+FG performance or total memory pressure.
