# D10：引擎导引精细分区、前后置恢复与可选人脸保护

本批承接维护者批准的0.5计划，D9完整输入实验基准保持独立冻结。
尚未形成0.5正式候选，也未获准合并稳定版。

## 已实现的候选

- 固定原始模型改动选区：宽/细增亮、宽/细压暗各自具有明暗与颜色倍率，
  另有镜面区域和纯颜色控制。增益不参与选区；中性、零增益和选区外各有GPU端点测试。
- 在原生SR/RR调用前保存可用深度、法线、镜面反照率与反射命中距离；
  两种镜面导引缺一时不宣称反射可用。导引和修改场最长边640，归入已有物理分配预算。
  最终尺寸原图亮度与低网格深度抑制跨物体恢复，不增加全分辨率分区纹理。
- 前后置共用区域增益与脸区端点；两条原有合成路线的关闭行为保持独立。
  可选亮度/颜色修改场和亮度Catmull恢复已补齐后置，需显式开启，不默认全开实验。
- 可选CPU识别后端：固定YuNet 2023mar权重、ONNX Runtime 1.23.2 CPU，单线程。
  准备脚本仅改变输入输出形状注释，验证算子和权重逐字节一致。
  后端从绝对路径加载并核对模型和运行时哈希；无依赖构建明确显示不可用。
- 独立工作线程处理NR前代理小图，游戏线程不等待推理或线程退出。
  请求和结果有帧身份；忙时替换待处理请求，过期/无效结果不能冒充当前脸区。
- GPU每帧保存低分辨率运动、深度和原输入亮度，最多追溯8帧。
  采用当前到前帧运动方向、活动区域偏移、NR绑定尺度与显式jitter适配。
  深度/亮度不一致、重置、历史断裂、合同变化或资源失败时退出选区。
- 两条既有合成核心均加入独立脸区保护：最终区域增益之后限制到同次NR的1倍编辑；
  原图明暗与颜色保护各0–100%，双100%在完整脸区精确返回该合成节点输入。
  保留Skin 0–2含义，默认关闭新脸区，原图保护默认0，不重写模型参数。
- 版本化区域输入合同区分检测脸区、模型差异和经验证的游戏语义资源。
  亮度、修改方向和粗糙度不能单独获得反射能力。

## 已有证据及边界

- 18张同一动漫人物原代理裁剪图，原生检测与OpenCV参考的归一化输出最大差约6.6e-7；
  空白未检出，人工双脸布局检出两张。192×192纯CPU中位数约0.60ms。
  这些不是独立人物、多场景或整帧GPU性能验收。
- 实际WARP跟踪测试覆盖正确位移、当前/前帧方向、深度突变、重置、过期/跨epoch拒绝、
  未提交列表、实际fence与录制所有权和资源预算回收。
- 62组实际WARP合成场景覆盖前后置、颜色域、100/75/50%模型网格、1倍锚点、
  两个原图端点、脸区外/零mask/无效mask逐字节不变；移除生产C1保护的负控被拒绝。
- 源版本 `1894a5a46a72eb27c0617cc0cbfcd292f5fb87ff` 的同源完整生成构建、
  58项本地检查全部通过；证据批次为私有 `d10-build-r5`。
- 生产引擎适配器实际WARP通过12396项检查；157组合成场景覆盖五种颜色存储、
  前后置与100/75/50%工作网格，包括固定预览、软分区守恒、原图边缘、选区外一致性和SDR高亮余量。
  补充用例先确认局部4倍增亮可能绕过柔和保护，修正后通过；中性和关闭时不改变原行为。
- 中英文实际Core菜单各通过40帧、6次真实开关；另用公开ImGui滚动API查看下部控件。
  分区和缺失镜面资源状态可读，独立脸区关闭。英文窄停靠栏的两个人脸实验滑块标签
  有截断，展开更宽面板可查看；该项不作为人脸效果或全界面无缺陷验收。
- 构建验证JSON的SHA-256为 `3e3d96097a7ceffc3217d138866f7cf11368461d77d84f51ae7b75a751033cc0`。
  中文Core为 `79f128d65901b4cfac329f40faaac146258df9a3d8b9f9052c903cd1cd902aa6`；
  英文Core为 `8a8cc6553c65ea9f47c87e9711493f1bf98d83828ea1213fd223f03b47ff8218`。
  `validate-050-acceptance.ps1 -RunWarp` 的完整参数、日志、依赖和源清单随私有证据保留；
  测试包括实际WARP，未运行真实游戏或完成整帧性能资格。

## 仍未完成

维护者最新决定由其自行验收独立人脸实验，停止扩展人脸画质样本。
正常默认路径保持模型原有人脸控制，独立检测不加载。
真实游戏反射/物体边界和相同NR设置下整帧GPU中位数与P95增幅均≤5%的实测尚未完成。
独立脸区在后置且MV包含jitter时退出跟踪，因为当前后置适配器不保留原始jitter；
不会把重置为0的值当作已验证抖动补偿。
当前检测间隔3次NR处理只是实验值，不是已验证性能档位。没有新增NR次数或整帧等待。

## 依赖来源

反射导引语义参照[NVIDIA Streamline RR文档](https://github.com/NVIDIA-RTX/Streamline/blob/main/docs/ProgrammingGuideDLSS_RR.md)
和本项目已有的固定v2.12.0 NGX键名合同。镜面区域表示模型在反射表面的改动，
不等于从引擎取得了单独的反射光照图层。

检测输入和解码格式参照[OpenCV实现](https://github.com/opencv/opencv/blob/4.x/modules/objdetect/src/face_detect.cpp)，
模型来自[OpenCV Zoo YuNet](https://github.com/opencv/opencv_zoo/tree/47534e27/models/face_detection_yunet)。
CPU运行时来自[Microsoft ONNX Runtime 1.23.2](https://github.com/microsoft/onnxruntime/releases/tag/v1.23.2)。
运动方向参照[NVIDIA DLSS编程指南](https://raw.githubusercontent.com/NVIDIA/DLSS/main/doc/DLSS_Programming_Guide_Release.pdf)。
发布含依赖测试包时必须附对应MIT许可及运行时第三方许可；不将私有游戏采集或模型运行时放入公共源码。
