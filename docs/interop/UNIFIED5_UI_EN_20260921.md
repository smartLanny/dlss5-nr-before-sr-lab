# unified5 controls and short checks

Research candidate only. No automatic installation or stable release. Preserve
saved INI values; replace files with the game closed and keep one language Core.

New or unselected colour policy defaults to **Conservative, strength 1.0**.
Opting into **Colour priority defaults to 0.7** when that bank has no saved value.
Each policy remembers its strength. Saved policies, strengths and legacy HDR
permission retain their compatibility semantics.

Policy controls admission; strength controls admitted model colour changes.
Both use the existing compositor. Conservative blocks unverified HDR colour
edits, while admitted SDR edits can still respond to strength. Strength zero
therefore does not reproduce the old HDR permission being off. It is not a
whole-image saturation slider. SDR presentation can still contain internal HDR.

Native skin mask and UI protection remain on per layer, skin structure 0.4 and
model intensity 1.5. Independent face detection is a separate experiment, off
by default. Off schedules no new detection or model load; submitted work retains
its completion protection. WuWa face artifacts (#302) remain unresolved.

Five flat pages remain: Picture, Lighting, Experiments, Developer and Feedback.
One WorkingScale applies once across one to five equally sized layers. Lighting
presets/reset/undo do not modify AI colour strength. Both energy experiments are
off by default; enabled does not mean paused. Developer contains key bindings.

This candidate admits only actually observed default scalar VRS state under
the existing restoration contract. Unknown/nondefault/image state stays guarded.
F8 now records observed rate/combiners. This is a narrow admission repair, not a
claim that Where Winds Meet flicker (#246) is fixed.

External provider v1 adds ownership, source identity and exact completion for
Manager Beta4 handoff. Bridge/Feeder combinations and Manager identity/config
import remain separate verification tasks. The full component manifest, not
the OTA archive, is the installation input. Private SR/RR and optical-flow work
continue in isolated experiments; unconnected features have no placeholder UI.

Short checks: preserve existing settings; verify policy strength banks survive
switching/restart. For Where Winds Meet keep the previous workload and capture
F8 when flicker occurs. Test one/two layers separately. For WuWa #254 keep native
RR and NR on with the older missing-projection experiment off; require growing
NR success and actual post-RR adoption before calling it connected.

For memory/stutter retain processMemory and contextMemory from the same process.
A short F8 window is not a peak-memory measurement. Exit the game and restore the
previous Core/nrchain/dependencies/INI to roll back. CPU/WARP/synthetic NVIDIA
checks do not establish in-game colour, ghosting, flicker or performance quality.
