# 0.5.1 Beta：相对 0.5 D21 初版的更新

基准为 D21 `cbfb3391` / `beta0.5-dline21-223fix2`。公开名称为 **0.5.1 Beta**，
内部构建标识保留 `beta0.5-dline21-unified10`，便于 F8、Manager 和旧记录追溯。
这是测试候选，不是已完成所有游戏验收的稳定版。具体源码/文件哈希见包内清单。

## 常用功能与界面

- 统一“画面 / 光影 / 实验 / 开发者 / 反馈”五页；顶部常驻版本与实际状态。
- 画面按 NR 开关、AI 色彩范围、处理顺序、工作量、最终增强、逐层参数排列。
- AI 色彩范围合为一个 0～1 滑条，新配置/重置默认 **0.5**。0 不采用新增色彩，
  仍保留明暗和细节；1 请求完整采用，仍受保护。它不是全画面饱和度或模型强度。
  显式旧颜色配置保留，首次编辑范围或重置才采用新统一许可；无需另开 HDR 调色许可。
- 光影只保留三种互斥方式；原来分散的明暗控制集中展示，旧组合有提示与退出/撤销。
  光影预设、重置、撤销均不修改 AI 色彩范围。机制参数补充悬浮说明。
- F6/F7/F8 可在开发者页改键；反馈页集中报告、画面采集与引导验收。

## 多层与工作尺寸

- 支持 **1～5 层独立参数**，风格横排选择，参数松手后提交，减少拖动重建。
- 整链只有一个 WorkingScale，各层同尺寸；前置按游戏 SR/RR 输入、后置按输出计算。
- 前置 50～100%，后置含 RR/兼容入口 25～100%；显示实际对齐尺寸，比例只乘一次。
- 新/重置层：模型强度1.5、结构1、色调1、皮肤结构0.4，原生皮肤遮罩和UI保护开。
  最终增强1；原始光照保护和边缘保护的新默认0。旧保存值与已配置层保留。
- 原 D21 的低分辅助层改成同尺寸会增加辅助工作量，不能把不同工作量当作优化对照。

## 性能、显存和接入

- 累计 Perf 优化减少关闭态与无关录制/提交的 CPU 成本、重复查询及部分锁开销。
- 同合同历史变化复用辅助实例并 Reset；父实例退休时，相关辅助进入自己的安全退休。
  每个实例继续等待自身录制、重放和 GPU 完成条件；F6 不强制清空可复用模型。
- 修复连续切换的配置提交与防闪资源回收接线；增加活动/退休/隔离/预算诊断。
- 九个辅助 shader 及本次三个残差稳定 shader 构建期预编译；PSO/模型创建仍有成本。
- 吸收 #303：同设备不可变流水线缓存、三种格式能力查询缓存、延迟快照正确记账。
  FP16 无快照路径仍为默认关闭的开发实验；不能把理论省一张纹理当作实际总显存降幅。
- 保留合法格式、资源状态、来源/队列和完成凭据检查。燕云接入和鸣潮 RR 投影适配
  有候选修正，**#246/#254 尚需各自修后 F8**；不声称所有闪烁、爆显存或 FG 问题已解决。
- RR 缺投影时的既有显式后置候选，新/缺字段默认开；原生 RR 与安全拒绝保留。

## 可关闭的防闪实验

- 支持整链，及支持入口下的后续层残差累积；不重跑第一层，不改变各层完整图像传递。
- 原生运动：目前是已证明安全快照的 DX12 原生 SR 后置 SDR。
- AMDOF：原生 SR 前置整链、SR 后置及成功 RR 后置；支持 SDR，以及同帧预曝光明确的
  线性 HDR。补齐异环的 R11G11B10 与底部对齐填充；最终高光不会被截成 SDR 白位。
- 历史按源帧推进，重复 FG 呈现不重复推理；预热、切镜、错帧和无效输入保留当前候选。
- 防闪、独立人脸检测和两个省电模式均默认关闭。原生皮肤遮罩不等于独立人脸检测。
- 省电依赖 FG 暂停/源帧信号。新增“没收到 / 游戏仍渲染 / 来源未匹配”状态和 F8 计数；
  菜单外观本身不触发暂停，当前没有对应开启态证据，不能宣布功耗问题已修复。

## 本包不宣称已完成

私有残差 SR/RR、NVOF、前置/RR/HDR 原生 MV、前置后续层范围尚未接通。
99%/100% 色差、RGB 亮边、所有游戏的 RR+NR+FG 调度与显存收益仍分别跟踪。
现有两套 NR 运行库按显卡适配使用，不做模型 DLL A/B；包不附 NVIDIA 私有模型/DLL。

## 使用与回退

退出游戏后备份旧 Core 和 nrchain 到插件搜索目录外，每条链只加载一份 Core。
保留已有 INI；D3D12 不复制 DX11 carrier。独立人脸资源保持默认关闭。
新包未由开发工具安装到游戏。回退时退出游戏后恢复备份；unified9 已交付包保留。
验收按包内“验收指南”进行，已有有效记录无需重录。
