## 本包改动

1. 顶部 NR 总开关下保留颜色优先／保守颜色双按钮及唯一 AI 色彩强度入口。
   新优先默认 0.5，保守默认 1.0，两者分别保存。明确保存的旧值保留。
   策略决定颜色准入；强度决定准入后的采用量。强度 0 不等于旧 HDR 许可关闭。
2. 开发者页可改 NR、当前图采集、文字报告快捷键，F1–F12 或关闭，拒绝重复。
   修改绑定后必须先松开按键。默认 F6/F7/F8；F8 生成文字报告，不录视频。
3. 保留五个平铺页面、整链统一尺寸、一至五层独立参数和直接展开的模型控件。
   保留新层 1.5 强度、0.4 皮肤结构、原生 mask/UI 开、独立人脸关。
4. 缺少原生当前投影时，尝试严格同源帧、同视图、同历史代次、同命令列表的
   Streamline 当前投影。仍走原深度转换和安全边界；失败保留原生 RR。
   旧缺投影后置尝试仍默认关闭，不作为自动修复路径。
5. F8 按需读取准确运行适配器的进程显存 Usage/Budget，两次约 750ms 采样；
   不增加逐帧预算查询。缺身份或查询失败记为未知。
6. 两项省电配置在 Present 初始化，避免没有首个 FG 信号或没有打开实验页时
   一直显示未加载。没有新增猜测菜单检测，不宣称无信号菜单已经能够暂停。

26 个最终着色器与 unified3 的完整构建逐项哈希相同。此包的颜色默认值、
UI 整理和兼容输入变化不构成 99%/100% 色差已修复的证据。
