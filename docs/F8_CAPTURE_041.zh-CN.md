# F8 标准对比采集

F8 会打开一次本地、可取消的标准对比会话。默认顺序为：关闭插件的原生
SR、Mode 2（渲染分辨率 NR → SR）、Mode 1（SR → NR）。每组会保存当前
显示截图，并在等待配置实际应用和预热后记录最多 16 个连续成功的 NR 评估。

会话开始时保存内存中的配置；组间切换只作用于当前进程，使用完毕、取消、
超时或打包失败前都会尝试恢复它，不调用 INI 写入。游戏的 DLSS 挡位、HDR
和曝光资源不会被改写。打包在后台执行，渲染锁不会跨越文件读取、哈希或 ZIP
写入。

每帧元数据包括 frame、instance、config generation、reset、尺寸、jitter、
MV scale、曝光有效性及四个诊断平面摘要。只有同一实例、同一配置代数和同一
尺寸的样本才会进入连续段。Reset、尺寸变化或实例变化会结束当前段并记录
`partial`，不会用相邻帧伪造连续性。默认 ROI 是原始输入中心的 256×256；
当前版本若未提供逐像素区域保护字段，会写入 `unknown`，不会声称保护已生效。

显示截图由 ReShade 的 Present 回调独立保存；其身份不等于阶段样本，也不声称
是同帧最终 SR。无法证明原生输出状态时，包中只写明 `unknown`，不读取或猜测
原生 SR 输出。

ZIP 会沿用 512 MiB、64 项和单文件大小限制；缺失原因、部分序列、manifest 和
SHA-256 都写入包内。路径只用于本地读取，报告中的可识别路径会被限制在包内
允许项；不会上传数据。
