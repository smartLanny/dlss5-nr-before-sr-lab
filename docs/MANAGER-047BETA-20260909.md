# Manager dev.10 / Core 0.4.7beta

本机测试交付版：Manager `0.4.6-hotfix.7-dev.10`，Windows 文件版本 `0.4.6.10`。
原生 DX12 默认组件为 `0.4.7beta`；Vulkan 使用单独固定配套，不能将它标成 0.4.7 的游戏验收。
本次不发布稳定版，不关闭未完成的游戏兼容问题。

中文核心 SHA256：`b7bef0c7ad637ef35d2f0d327201636cb80f808a6af62cb6221f980343376dbf`。
nrchain SHA256：`46041a5ff91ae2fd907e310d132aabc3c4a1ecd48dace511b8672909d5d9c2fb`。
新安装与恢复默认的模型强度为 1.2，已有配置保留；DX11 保持独立旧版兼容配套。
交接证据包括该名称/哈希对应的 36 项 WARP 门禁和双语菜单验证。
《鬼武者》前一同代码 dev16 与官方 REFramework 组合已有维护者实测，
本管理器本轮没有再次运行游戏。DS1 的已知问题尚未解决，不宣称已修复。

## REFramework

当前仅匹配已核验的根目录 x64 `OnimushaWotS.exe`，不按发行商自动套用。
官方 01417 加载器 SHA256：`504f2eb1cf98fad0b43ed95bcc4f457afeea676912b90889ac03f797c5acf23c`。
“兼容修复”内显示“卡普空 RE 引擎兼容”，与实心 D3D12 修复按钮并列。
匹配游戏一键安装时自动准备 REFramework；提供独立撤销与中断恢复。
外部已有同版加载器复用，撤销时保留。D3D12 路线保持手动选择。
已有 `_storage_` 配置优先；缺少时只从具有主安装归属的当前配置初始化。
玩家配置、未知缓存与模组不作整目录删除。
核心升级、缓存副本和主安装使用同一文件事务，修改前检查归属与实际摘要。
