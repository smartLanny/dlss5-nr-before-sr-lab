DLSS 5 AI 超分管理器 0.4.8-beta.2

先退出旧管理器。完整 ZIP 请全部解压后运行；便携 EXE 可单独运行。
界面默认普通权限和沙箱；只有已预览的受保护目录操作才单独请求 UAC。

从游戏卡片展开设置，按三个页签使用：
1. 安装与画面：先看 API 和兼容性，再选核心并安装；NR 参数也在这里。
   API 未确认时会提示“需要手动选择”，选定实际 API 后才能继续应用。
2. 超分与补帧：新游戏按本机显卡预选模型，RTX20/30 为 K，RTX40/50 为 M。
   默认只改模型，保留游戏 DLSS 档位与输入比例；已有设置不会被默认值重置。
   K：老版兼容；M：平衡选择；L：4K 优化，主要优化 4K 超级性能档位。
   高级手选保留 K/M/L；旧 NVIDIA Recommended 请求继续按 DLSS 档位选择。
3. 高级与维护：外置目录、加载方式、DX11 桥接对照、运行验收、反馈及恢复。

更改先暂存，再预览并应用。打开或刷新页签不自动修改游戏或驱动。
游戏内 DLSS/FG 开关无法读取时，先在游戏中开启、退出并确认。
有效确认保存后不会反复要求确认；更换游戏 EXE 或读到开关关闭时需重新核对。
确认、配置读回均不代表游戏已经实际采用增强。

外置运行
DX11/DX12 原生 DLSS 路线可从原 ReShade 的默认或自定义 Add-on 目录直接建立外置配套。
首次安装使用代理加载，安装后可在“高级与维护”切换外置助手。
活动 ReShade.ini、Core、依赖、参数和日志统一记录实际位置。
图形代理方式保留游戏目录中的加载入口；助手方式移除本工具受管的图形代理，
仍保留必要的目录指向和恢复记录。已有滤镜、纹理、HDR 和个人配置按预览处理。
助手只服务绑定的普通权限游戏与受管 ReShade；游戏保护可能拒绝加载。
Vulkan/Feeder 保持各自固定配套，不套用普通 DX11/DX12 外置规则。

本轮可测
- 2077：同一 Core、同一场景，先外置图形代理，再完全退出并改用外置助手。
- BG3 DX11：使用 bg3_dx11.exe，固定“0.4.7beta + Bridge 1.4.11”对照配套实测。
  这是桥版本对照，不能仅凭进入游戏判定 NR 生效。
- RTX40：在另一台 40 系机器上，选已有原生 Streamline FG 的 x64 DX12 游戏。
  先确认普通 2× FG，再测试 MFG Unlock 0.6.1 请求 3×，分别记录 NR 关闭和开启。
  需要完整 Add-on ReShade 和匹配的现代 DLSS-G 运行库；本工具不补装 NVIDIA DLL。

每轮分别核对：助手就绪、本 Core 加载、NR 成功与提交持续增长、同场景画面变化。
MFG 另记录实际呈现遥测；倍率选项或 FPS 上涨不能单独证明 3× 已生效。
失败后在高级与维护保存反馈与验收记录，并附同次游戏日志和面板材料。
米哈游 TYPELESS 修复由独立 Add-on 线推进；HDR 或 Ready 不能当作 NR 成功。
DX9/DX10/OpenGL 桥接仍需后续实现与实测，本批不宣称已兼容。

恢复
先退出游戏，有未完成事务时先恢复。恢复 SR/FG 原设置会撤销本工具的覆盖。
每次卸载分别选择“干净移除”或“恢复安装前”，核对清单后应用。
干净移除让旧代理留在备份；恢复安装前只使用有记录且摘要匹配的原件。
HDR、其他模组和未知 Add-on 默认保留；清理隔离可撤销。

本版不把隔离测试当作实机兼容结论。BG3、米哈游、RTX40/50 补帧与 NR 共存，
以及原故障电脑启动、真实 UAC 和安装版实装，仍按各自验收记录确认。
