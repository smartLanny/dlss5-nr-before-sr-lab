# 0.5 D13 更新说明

本包供已有 0.4.7 环境的 DX12 玩家升级，游戏内版本显示为 `beta0.5-dline13`。

- 常用画质选项重新排序：画面风格、处理顺序、第一层精度、二次 AI 与比例集中在上方。
- 新增二次 AI 增强，默认关闭；第二次处理默认 50%，可直接切换 50%／75%／100%。已有合法设置继续保留。
- 增加普通亮暗、引擎分区和通用分层三种光影调节方式，常用说明改为直白中文和悬浮提示。
- 修复第二层在准备与资源等待之间反复切换的一条代码路径，补充前置引擎分区的深度读取支持。
- 两层均使用模型人脸参数；独立人脸保护继续作为默认关闭的实验功能。
- 文字与界面保护移到开发者选项，默认开启；反馈页增加更清楚的第二层状态。

完整中英文构建及 64 项本地验收通过，实际菜单的开关、比例和光影方式保存已检查。维护者本轮在异环试用后反馈“看起来没啥大问题”；这是该场景的试用反馈，不代表所有游戏或显卡都已验证。不同游戏的实际画质和开销仍需自行比较。

首次试二次 AI，建议从 50% 开始。同一场景按 F6 比较，每次只改一项。详细步骤见随包的安装说明、设置说明和新 UI 图片。
