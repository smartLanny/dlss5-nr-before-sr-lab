# 0.4.7 升级到 0.5 D13：安装说明

适用于已经装好、可以正常使用 0.4.7 的 **64 位 DirectX 12 游戏**。这次更新游戏内的 DLSS5 插件，不会把管理器本身升级到 0.5。

先退出游戏。原来的个人设置会保留，不需要先卸载整套插件，也不用删除配置。

## 用管理器安装过：从管理器升级

1. 打开管理器的“插件版本”页，找到“导入核心更新”，选择本次 **OTA.zip**。不用先解压，也不要把它当作“完整组件目录”。
2. 回到要升级的游戏，在“核心版本”中选择 **0.5 D13**，点击“应用版本”或当前版本对应的应用按钮。只导入更新包、或只更改“新安装默认核心”，不会自动更新已经安装的游戏。
3. 等待更新完成，再启动游戏。打开游戏内“装机宅DLSS 5”菜单，顶部应显示 **beta0.5-dline13**。

保持游戏原来的 DirectX 12 路线。DX11、Vulkan 及其专用配套请继续使用各自支持的版本，本包不更换这些路线。

旧版管理器会从 OTA 中安装核心和 `nrchain_nvngx.dll`，但不会自动复制新增的 `nr_face` 文件夹。常用画质、二次 AI 和菜单中的“人脸调节”不需要这个附加文件夹；只有开发者选项里的“独立人脸保护（实验）”需要它。要尝试该实验，请退出游戏，将包内整个 `nr_face` 文件夹复制到游戏实际使用的 `nr_before_sr.ini` 所在目录，通常也就是本插件所在目录。

## 以前手动安装：手动更新

1. 退出游戏，把 OTA 解压到一个临时文件夹。
2. 找到旧版 DLSS5 插件所在目录：里面应有本插件的 `.addon64` 和 `nr_before_sr.ini`。部分游戏在 `Binaries/Win64` 中，不能一律放到游戏最外层。
3. 在游戏目录外新建一个备份文件夹，把旧版 DLSS5 `.addon64`、`nrchain_nvngx.dll` 和 `nr_before_sr.ini` 复制进去；已有 `nr_face` 的，也备份整个文件夹。
4. 将旧版 **本插件** 的 `.addon64` 移出加载目录，再放入本包唯一的中文 `.addon64`。不要同时保留两个版本，也不要同时放中文和英文核心。
5. 复制本包的 `nrchain_nvngx.dll` 到同一目录，按提示替换；复制整个 `nr_face` 文件夹到这里。
6. 保留原来的 `nr_before_sr.ini`、ReShade 文件、NVIDIA DLL、游戏文件和其他 MOD。包内的说明、图片和校验清单不用放进游戏。
7. 启动游戏，打开菜单，确认顶部版本为 **beta0.5-dline13**。菜单热键以你原来的 ReShade 设置为准，通常是 Home；F6 是本插件效果对比开关。

使用 REFramework 或自定义插件目录的玩家：要更新实际加载的位置。框架若还保留旧 Core 的有效缓存，也需按原安装方式同步更新。原本通过管理器维护的安装，优先继续通过管理器更新，避免只换根目录却仍加载旧缓存。

## 升级后先做什么

沿用旧设置进入一个熟悉的场景，按 F6 比较开关效果。想试二次处理，再勾选“启用二次 AI 增强”，点击下方 **50%**，等“准备中”结束后比较。

二次 AI 默认关闭；0.4.7 升级后新增的第二次比例默认 50%。已经保存过合法第二次比例的测试版用户会保留原值。无需为了得到 50% 而重置全部画质。

## 想退回 0.4.7

- 管理器安装：退出游戏，在该游戏中重新选择原来的 0.4.7 核心并应用。导入版本若已被移除，需要重新导入原包。
- 手动安装：退出游戏，移出 D13 核心，放回备份的旧核心和配套 DLL。原有 `nr_face` 如被替换，恢复它的备份。通常保留当前个人设置；只有想连设置一起回到升级前，才恢复备份的 INI。

如果更新后菜单仍显示 0.4.7，先检查是否更新了实际加载目录、是否还存在另一份旧核心或框架缓存。遇到持续不生效、异常画面或崩溃时，保存 F8 反馈，并附游戏名、处理顺序和第二次比例，便于定位。

本包包含中文 Core、自有配套 DLL、独立人脸实验的附加文件及其许可证；不包含替换个人配置、ReShade 或 NVIDIA 运行库，不是首次安装全套包。
