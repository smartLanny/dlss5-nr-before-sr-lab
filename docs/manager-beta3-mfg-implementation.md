# beta3 MFG 与自动资格实现记录

## 版本与恢复

组件目录固定提供 0.7 中文版、0.7 官方原版、0.6.1 官方回退版。
代码和资源清单同时固定每个版本的 SHA-256；选择未知 ID、缺失或变更资源会阻止
写入。活动布局只部署一个 `renodx-mfgunlock.addon64`，不要求先安装 NR。
配置应用未指定版本时保留现有已知版本；显式版本选择才会升级或降级。

预览提供真实路径、写入前后摘要、创建/采用/替换动作与阻止原因。写入前重新检查
游戏关闭、活动布局、文件摘要和资格。旧 0.6.1 v2 收据继续可恢复；新 v3 收据
区分管理器创建、原样采用和替换原件。跨版本切换保留最初原件的独立摘要快照；
恢复时管理器创建的文件移除，采用文件保留，替换文件恢复最初原件。
外部修改、损坏原件或归属不符均保留现场。版本写入与原件快照同属可恢复文件事务。

## 实际设置与自动资格

MFG 实际请求来自已确认活动 `ReShade.ini`。游戏内合法修改由 ReShade 保存，
管理器刷新显示实际值；只读启动不把已应用收据的旧请求写回去。
新草稿仍需重新预览。多次合法变更保持最初恢复基线，预览后又发生的外部修改
仍由写入前摘要检查保护。

SR/FG 不再接受“我已确认游戏支持”作为资格证据，旧确认文件保留但不参与读取
或决策。正面静态证据必须绑定所选 EXE、实际导入/引用的引擎、可信 NVIDIA
签名与摘要、运行库版本和 API。单独放入 DLSS DLL、扫描布尔值、驱动 setting
枚举都不足以证明某游戏支持。Luma 等模组只有固定、经过检查的游戏/模组/驱动
覆盖契约才可进入可信模组目录；当前无此目录条目。

支持资格与游戏开关状态分开。开关 unknown/off 只给提示，不能自行证明支持。
40 系 MFG 兼容能力与 50 系官方倍数能力分开；未知倍数/Dynamic 能力不开放
对应模式。实际生成帧输出仍需游戏内验证，静态支持与插件加载不算运行时验收。

## 验证边界

针对组件部署、跨版本原件恢复、旧 v2 收据、事务中断和外部变化的 49 项测试通过；
另有设置、自动资格、配置编译与工作流测试。真实隔离 DX12 场景确认 ReShade API 18
可加载中文面板、字体正常、下拉列表正确，面板修改 3× 立即保存到活动 INI。
这次测试没有原生 FG 输入，不声称验证了 40 系 MFG 倍率、画质或 NR+MFG 联用。
