DLSS 5 AI 超分管理器 0.4.8-beta.7 · 本地测试版

本版接续 beta.6，修正“已经安装，但启动前仍需处理设置”的状态和操作入口。
完整 ZIP 请全部解压后运行；便携 EXE 可单独运行。升级前正常退出旧管理器。

旧设置迁移
“文件已安装”只表示已有安装记录；旧 SR、旧补帧和未完成事务会单独提示。
例如 33 号远征队保留旧版 M 模型记录时，点击启动前提示的设置入口，
进入“超分与补帧 / DLSS 超分”，保留当前模型，点击“预览当前超分设置”，再确认应用。
也可以预览“恢复原设置”。恢复完成前不要手动删除旧记录或备份。
确认应用仍由用户操作；打开页面和点击启动不会自动迁移或覆盖驱动设置。
仅尚未读回的正常设置显示“启动时检查设置”，不要求重复应用。
历史失败记录保留在诊断中，不代表当前仍然失败。

两套内置测试 Core
在普通游戏或米哈游设置的“增强版本”中可选择：
  0.5 D13 · 测试
  0.4.7 Corefix8 · 测试
它们只更新已有的原生 DX12 安装，使用各自配套的 Core 和 nrchain。
新安装仍默认使用 0.4.7beta；先完成 DX12 基础安装，再预览切换测试版本。
切换前退出游戏。现有 NR 配置、ReShade、NVIDIA Runtime 和游戏自带 DLSS 保留。
两套测试 Core 没有 DX11 carrier，不用于 DX11、Vulkan 或 Feeder 配套。
Corefix8 原始 ZIP 是核心验收包，不能当作通用 OTA 导入；本版内置了单独核验的更新入口。

0.5 D13 设置
管理器“恢复默认”使用 D13 的模型强度 1.2、颜色强度 1.0。
自定义工作比例支持 0.5～1；前置和后置额外强度支持 1～4。
二次 AI、光影等 D13 专用选项仍在游戏内 Core 面板调整，切换版本保留原有明确配置。
新配置的二次 AI 默认关闭；第二次处理比例默认 50%。

画面与反馈
修改参数后先预览，再确认应用。常用控件与“细节、性能与更多设置”继续保留。
点击“反馈本次体验”可填写能否游玩、画面和流畅度，并保存本地 ZIP。
诊断日志按需勾选；管理器不会自动上传。没有证据时保留“不确定”。
文件已安装、Core 已加载、NR 已处理和最终画面分别记录。

启动与恢复
新 ReShade 配置默认 Home；已有自定义面板键保留。
米哈游先准备加载助手，再通过已绑定的启动器开始游戏；取消等待不会关闭游戏。
未完成操作须从提示的对应入口恢复。不要用未知 .bak 文件替代原始备份。

验证边界
本地功能测试与文件校验不等于真实游戏的画面对照、NVIDIA NR 或性能验收。
0.5 D13 和 Corefix8 均为测试候选，未据此声明真实游戏稳定或画面问题已解决。
Batman: Arkham Asylum GOTY 的既有 DX9 R3 卡住问题仍是独立的未解决事项。
